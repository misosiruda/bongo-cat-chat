채팅 차단

게임의 고양이 숨김과 별개입니다. 차단은 이 기기의 현재 Steam 계정에 저장되며, 다른 로비와 앱 재실행 후에도 유지됩니다.

    차단한 사용자가 없습니다.

    차단한 상대의 대화·검색·알림·반응 효과를 숨기고 새 메시지는 저장하지 않습니다. 해제하면 기존 기록은 다시 보이지만 차단 중 대화는 복구되지 않습니다.

    고양이 반응 효과

    고양이와 함께 올라오는 이모티콘·야옹 효과를 표시합니다. 끄면 표시 중인 효과도 사라지고, 다시 켠 뒤 새로 받은 반응부터 표시합니다.

    새 메시지 알림

    다른 앱을 사용하거나 창을 최소화했을 때 새 상대 메시지를 알려 드려요.

    알림 센터에는 이름이나 대화 내용 없이 새 메시지 안내만 남깁니다. 연속 알림은 5초 간격으로 제한하며, Windows의 알림·방해 금지 설정을 따릅니다.

    앱 업데이트

    허용하면 새 버전을 내려받고 30초 안내 후 자동으로 재시작해 적용합니다. 입력·전송 중에는 기다리며 초안을 저장합니다. 끄면 자동·수동 확인과 자동 재시작이 중지됩니다. 이미 준비된 업데이트는 다음 실행에 적용될 수 있습니다.

    업데이트 상태를 확인하고 있어요.

    받은 대화와 초안을 이 기기에 30일 보관합니다. 게임에서 숨긴 고양이의 채팅도 저장하며, 앱에서 차단한 상대의 새 대화는 저장하지 않습니다. 기록을 삭제해도 차단 목록은 유지됩니다.

    삭제한 기록은 되돌릴 수 없습니다.

    테마·사이드바·반응 효과·알림 설정은 이 기기에 저장돼요.
