# 로비 복복 알림

2026-11-16 [이슈 #66](https://github.com/misosiruda/bongo-cat-chat/issues/66)의 합의와 슬림 배너 시안을 구현해 dev34에 공개했다. 1.0.0 후보는 같은 기능을 유지한다. 다른 참가자 PC·순정 환경·장시간 실행의 실게임 인수와 구분한다. [1.0.0 준비 상태](release-1.0.0-validation.md)를 참고한다. 시안 이미지 5장과 인터랙티브 HTML 원본은 이슈에 첨부되어 있다.

## 사용과 표시

**설정 → 로비 복복 알림 → 복복 알림 표시**는 기본 ON이다. 같은 로비의 사람 간 복복을 로비 헤더 아래 최대 3줄로 표시한다. `두부가 모카를 복복복 하고 있습니다. ×7`처럼 방향과 횟수를 구분하며, 긴 문장은 말줄임하고 횟수 배지를 유지한다. 밝은/어두운 테마와 최소 400 × 500 창을 지원한다.

표시 이름 대신 계정 ID 쌍 `(행위자, 대상)`으로 묶는다. 같은 이름의 다른 사람과 역방향은 별개다. 표시 이름과 이 PC의 별명은 현재 값을 사용한다. 행위자나 대상 중 한 명이라도 차단하면 배너와 초과 요약에서 제외한다. 자신의 고양이를 직접 누르는 동작은 게임이 로컬에서만 처리하여 이번 수신 방식으로 표시하지 않는다.

| 조건 | 동작 |
| --- | --- |
| 재수신 간격 1초 미만 | 같은 줄에서 +1, 줄 순서 유지 |
| 추가 입력 없이 1초 경과 | 연속 묶음 종료, 마지막 숫자를 유지하며 1초 페이드 |
| 추가 입력 없이 2초 경과 | 제거 |
| 재수신 간격 1초 이상 | ×1로 새 묶음 시작. 페이드 중이라면 같은 DOM 행에서 즉시 정상 불투명도로 복원 |

3줄이 차면 페이드 중인 줄을 우선하고, 그다음 마지막 수신이 가장 오래된 줄을 교체한다. 숨겨진 활성 쌍은 `+N쌍도 복복 중`으로 요약한다. 숨겨져도 1초 미만의 연속 횟수는 유지하며, 빈자리가 나면 가장 최근의 활성 쌍을 올린다. 만료된 쌍을 순서대로 재생하는 대기열은 없다.

배너로 영역 높이가 바뀌면 읽던 메시지의 상대 스크롤 위치 또는 맨 아래 상태를 보존한다. 입력 초안은 건드리지 않는다. 검색·보관 로비·숨겨진 창에서는 표시하지 않으며 다시 보일 때 아직 유효한 현재 상태만 표시한다. 로비·계정·연결 세대 변경 또는 연결 공백에는 집계를 비운다. 설정 OFF는 즉시 표시를 지우고 이후 입력을 폐기한다. 다시 ON으로 바꾼 시각보다 앞선 지연 이벤트도 폐기한다. 설정 저장 실패는 이전 값을 유지한다.

## 수신과 수명

`CatPatter.Pat → SteamMultiplayer.SendPat(target) → SendMessageToLobby`에서 나온 channel 8의 대상 ID 문자열을 해석한다. 행위자는 `GetLobbyChatEntry`가 제공하는 송신자다. 콜백 수명 안에서 본문을 복사하고, 행위자와 대상이 모두 현재 로비 구성원인지 검사한다. 자기 자신을 대상으로 하는 패킷과 비정규 uint64 문자열은 거절한다. 하트·선물 애니메이션 개수로 횟수를 추정하지 않는다.

시간 기준은 **Chat 작업자가 콜백을 읽은 monotonic 시각**이다. 원래 클릭 시각은 패킷에 없으며, 기존 작업자의 약 150ms 조회 주기와 IPC 지연 때문에 실제 클릭 시각 또는 다른 PC의 숫자와 완전히 일치한다고 보장하지 않는다. 같은 내용도 서로 다른 수신 ID이면 각각 센다. 같은 수신 ID의 중복 전달만 제거한다. IPC 큐가 절반 이상 차면 복복을 폐기하여 채팅·연결 상태·전송 결과가 사용할 여유를 남긴다. 이 과부하 구간의 복복 횟수는 누락될 수 있다.

`PatTracker`는 메모리의 쌍별 카운트·시각·표시 순서를 관리한다. 서비스는 수신과 조회 때 연결·차단·멤버십·설정·유효기간을 다시 검사한다. 대상이 나가면 상태에서 제거한다. 게임에는 추가 메시지나 복복을 송신하지 않는다.

UI는 기존 메시지 조회 600ms와 별도로 `pat_view`를 약 100ms마다 요청한다. 이 경로는 DB를 조회하지 않으며 최대 3행과 숨겨진 활성 쌍의 남은 시간만 반환한다. 한 번에 하나만 요청한다. 요청 시작 시각으로 응답 지연을 보수적으로 차감하고, 화면에서는 절대 만료 시각으로 불투명도를 계산한다. 늦은 응답이나 이전 페이드 종료 콜백이 새로운 묶음을 되살리거나 제거하지 않는다.

## 호환성과 개인정보

기존 채팅 호환성 검사는 유지한다. 별도 `pat-contract.json`은 channel 8 수신 분기·패킷 구조·`SendPat`과 그 호출 의존성을 기존 메타데이터 검사기로 확인한다. 복복 기능의 미확인 변경이나 검사 실패는 **복복만 비활성화**하고 기존 채팅은 유지한다. 설정에서 지원 확인이 필요하다는 안내를 표시한다. 파일 변경 감시는 기존 연결 검사를 따른다. 게임 파일 패치·DLL 주입·새 내부 연결 모듈은 없다.

현재 확인한 build 26538670의 `Assembly-CSharp.dll` SHA-256은 `8F75DF923B6F36F45633F27823AD8D9C63DFA5D42759635D9918857361AF31A2`, 복복 기능 지문은 `16aa68171ffd543a615a333e94692f36d7c266048951a1d8ada14c5f13fd8835`다. 지문 계산은 게임 코드를 실행하지 않는다. 전체 DLL 해시나 build 번호만으로 기능 지원을 허가하지 않는다.

설정 bool `pats_enabled`만 기존 SQLite settings에 저장한다. 복복의 행위자·대상·이름·횟수는 메모리에서만 사용하고 대화·입퇴장 DB, 검색, Windows 토스트, 새 메시지 배지, 진단 파일로 보내지 않는다. DB 스키마와 기록 보관 정책은 바뀌지 않는다.

## 검증 구분

구현 전 실게임에서는 사용자 직접 입력의 channel 8 이벤트 239건, 대상 8명, 사용자가 확인한 7회 클릭과 7건 수신의 일치를 확인했다. 7건은 3회 → 약 3.105초 공백 → 3회 → 약 4.439초 공백 → 1회였다. 다른 참가자가 시작하는 입력은 협조 시험을 하지 못했으며, 로비 전체 전달 계약과 코드 분석으로 가능성을 확인한 상태다. 원본 ID·채팅·바이너리·개인 로그는 공개하지 않는다.

제품 코드 검증은 합성 이벤트·오프스크린 Qt·헤드리스 Edge로 수행한다. 재현 명령:

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:QTWEBENGINE_CHROMIUM_FLAGS='--disable-gpu'
python -m pytest -q tests/test_pats.py tests/test_pat_worker.py tests/test_pat_desktop.py tests/test_reaction_desktop.py tests/test_environment.py tests/test_localization.py --tb=short
python tests/browser_pat_check.py
```

합성 이벤트는 정확한 1초 경계, 양방향 식별, 중복 수신 ID, 숨겨진 쌍 누적과 만료, 차단 양끝점, 설정 실패·재실행, 연결 공백, 늦은 응답 폐기를 확인한다. 실제 Qt Controller/QWebChannel/DOM을 통해 누적·페이드 재진입·초안·스크롤을 확인한다. Edge 화면 검사는 1240 × 840 및 400 × 500의 밝은/어두운 테마에서 3줄·초과 요약·횟수 배지·만료·스크롤과 입력을 확인한다. 그림과 로컬 검사 결과는 Git 제외 경로 `artifacts/pat-alerts/`에 둔다.

2026-11-16 전체 회귀는 **1208 passed, 19 subtests passed / 344.45초**였다. 이후 표시 가드·빈 화면 처리와 추가 집계/작업자 회귀를 보완하여 위 집중 검사를 최종 소스로 다시 실행했고 **115 passed / 29.98초**였다. 두 실행은 겹치므로 합산하지 않는다. 최종 Edge 4종 화면 검사는 모두 통과했다. 새 작업 폴더에서 컴파일한 메타데이터 검사기로 설치된 게임을 읽어 복복 지문 일치와 `verify_pat_compatibility=True`를 확인했다. 자세한 실행 범위는 [제품 검증 기록](product-validation.md#2026-11-16--이슈-66-로비-복복-슬림-배너)에 있다.

구현 후 실제 다른 참가자 → 나 및 제3자 간 입력, 서로 다른 PC·순정 설치, 새 설치본 업데이트·장시간 실행은 별도 인수로 남는다. 자동 게임 클릭·실사용 로비 시험 송신·아이템 소비는 이 구현 검증에 포함하지 않는다.

복복복 알림과 검색 결과 안내는 채팅 위에 겹쳐 표시한다. 표시·갱신·만료로 채팅 스크롤 영역의 위치나 높이를 바꾸지 않으며, 복복복 알림 높이에 따른 스크롤 보정은 하지 않는다.
