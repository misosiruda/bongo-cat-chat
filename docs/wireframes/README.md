# 채팅 화면 와이어프레임

2026-10-13 기준 설계 예시다. 실제 Steam·Bongo Cat 연결, 이름·고양이 외형 조회, 게임 숨김 상태 조회, 메시지 저장소는 구현하지 않았다. 표시 이름·고양이 아이콘·메시지는 모두 가상 데이터다.

## 열기

저장소를 내려받은 뒤 [bongo-chat-wireframe.html](bongo-chat-wireframe.html)을 브라우저에서 연다. GitHub 파일 화면에서는 HTML 소스가 보이므로 로컬 파일을 사용한다. 별도 빌드나 앱 설치는 필요하지 않다. 아이콘과 툴팁 라이브러리는 `unpkg.com`에서 읽으므로 해당 리소스에는 네트워크 연결이 필요하다.

편집 원본은 [bongo-chat-wireframe.fragment.html](bongo-chat-wireframe.fragment.html)이다. 실행 파일은 원본을 샌드박스 iframe으로 감싼 HTML이며 실제 게임에 메시지를 보내는 코드는 없다. 대화에서 제공한 원본을 유지하면서 독립 실행용 문서로 내보냈다.

## 확인할 화면과 동작

| 화면 | 확인할 내용 |
| --- | --- |
| 메신저형 | 좌우 말풍선, 게임 이름·고양이 프로필 자리, 대화 검색·예시 메시지 입력 |
| 디스코드형 | 한 줄 흐름으로 정렬한 이름·본문·시각, 같은 검색·입력 동작 |
| 로비 전환 | 보내기 비활성화, 이전 방 초안 보존. 새로고침을 누르면 새 로비 연결 예시로 전환 |
| 게임 숨김 반영 | 게임에서 특정 사용자를 숨긴 상황을 가정하고 그 사용자의 기존·새 대화와 검색 결과에서 제외 |

- 왼쪽 위 버튼으로 사이드바를 접거나 펼친다. 선택한 방·검색어·초안은 유지한다.
- 보관한 대화는 읽기 전용이며 현재 로비만 예시 메시지를 입력할 수 있다.
- 숨김·해제 버튼이나 독립적인 숨김 목록은 없다. 제품에서는 Bongo Cat에서 설정한 값을 자동 반영해야 한다.
- 시안의 검색·입력·화면 상태 전환은 브라우저 내부에서만 동작한다. 예시 입력은 실제 전송이나 대화 DB 저장이 아니다.
- 브라우저가 허용하면 사이드바 접힘과 방별 짧은 초안 등 일부 UI 상태를 로컬에 보관한다. 추가한 예시 메시지는 메모리에만 있으며 새로 열면 복원하지 않는다.

## 검증 범위

UI 확인과 실제 게임 연동 검증은 구분한다. 이 시안으로 사이드바 동작, 예시 검색·입력, 로비 경계, 숨김 반영 후 표시를 검토할 수 있다. 게임의 숨김 상태·표시 이름·고양이 외형을 읽는 기술 검증은 [개발·검증 계획](../roadmap.md)의 미완료 항목이다. 알림·읽지 않은 수·내보내기·영구 저장도 제품 구현 전이다.

## 원본 수정과 내보내기

원본은 본문을 `textContent`로 표시하며 게임·Steam 요청을 수행하지 않는다. 독립 실행 HTML은 함께 동기화해야 한다. 내보내기에 사용한 `visualize` 도구가 설치된 환경에서는 해당 도구의 `scripts/render.py`에 원본과 출력 경로를 전달한다.

```powershell
python <visualize-skill-path>/scripts/render.py `
  docs/wireframes/bongo-chat-wireframe.fragment.html `
  docs/wireframes/bongo-chat-wireframe.html --force
```

`render.py`와 도구 런타임은 이 저장소의 의존성이나 게임 배포 파일이 아니다. 검토자는 이미 내보낸 HTML만 열면 된다. 재생성할 때는 원본·출력의 동작을 비교하고 실제 계정 식별자·채팅 원문·로컬 경로가 추가되지 않았는지 확인한다.
