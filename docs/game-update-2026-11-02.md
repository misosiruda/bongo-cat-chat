# 2026-11-02 게임 업데이트 호환성 복구 — dev21

## 원인과 변경

실행 중인 게임 build `26364842`에서 dev20의 채팅 연결 차단을 실제 앱 화면으로 재현했다. 기존 기능 계약과 비교해 lobby·profiles 지문은 같고 chat·privacy·reactions 지문이 변경됐다. 현재 게임 메타데이터를 Mono.Cecil로 읽어 패킷 `Channel: Int32`, `Message: String`, 채팅 채널 3과 반응 채널 6, UTF-8 JSON 전송, 현재 로비·참여자 검사, 숨김 필드와 접근 경로를 확인했다. 새 코드에는 이모티콘 소유 검사와 추가 로비 채널 등이 포함된다. 앱의 채팅 차단 정책 D-031은 유지한다. 앱 반응은 게임 화면 표시 결과의 복제나 소유권 인증을 보장하지 않는다.

기존 계약을 삭제하거나 검사기를 느슨하게 만들지 않고 조사한 다섯 지문 전체를 별도 프로필로 추가한다. Mono 런타임과 Steam 네이티브 파일 해시 제한, 송신 직전 검사, 파일 변경 감지는 유지한다.

자동 합성은 기존 12개 파일 중 8개가 바뀌었다. 보관한 10월 29일 IL과 현재 코드를 대조했다. TryExchange·ExchangeRoutine, 보호 옵션, 교환 10개, 그룹·중복 조회와 SteamItemRuntime 접근은 유지된다. SlotDuplicates 관련 컴파일러 생성 클래스 번호 변경과 UpdateInteractable·SlotItem의 안내 갱신, 탭 강조 변경을 검토했다. 실제 연결 준비에서 `DOTween` 참조 누락(CS0012)도 재현했고 고정 참조와 해시 검사를 추가했다.

자동 합성 계약 schema 4는 **13개 파일 전체의 프로필**을 비교한다. 이전 파일 프로필과 새 파일 프로필을 섞어 허용하지 않는다. 이전 Auto Chest 두 변형은 이전 프로필 안에서만 유지하며 새 프로필은 이번 PC에서 확인한 Auto Chest 한 파일만 허용한다. DOTween은 두 프로필에 같은 확인 해시로 제한하므로 이전 설치가 다른 DOTween을 갖는 경우 연결을 보류한다. 이전 빌드의 실행 인수는 이번에 수행하지 않았다. 배포 생성기와 패키지 검증기도 동일한 profiles 계약을 확인한다.
