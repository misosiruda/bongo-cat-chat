# Windows 설치 안내

일반 이용자는 설치 파일 하나로 설치한다. Python, Git, 명령어 입력이나 관리자 권한은 필요하지 않다. Windows 10/11 64비트(x64), Steam 및 Bongo Cat을 준비한다.

[최신 릴리스](https://github.com/misosiruda/bongo-cat-chat/releases/latest)에서 `BongoCatChat-<버전>-windows-x64-Setup.exe`를 받는다. `Source code` ZIP과 `bongo-cat-chat-windows-x64.zip`은 일반 설치 파일이 아니다. 후자는 앱 업데이트용이다. [dev17 릴리스 노트](releases/0.1.0.dev17.md)에 설치 파일 직접 링크와 한국어·영어 시작 안내가 있다.

## 설치와 시작

1. 기존 Bongo Cat Chat을 종료하고 다운로드한 Setup.exe를 더블클릭한다.
2. 한국어 설치 안내에서 **다음**을 누르고 개인정보 안내를 읽는다. **GitHub 업데이트 확인 및 다운로드 허용**은 선택 사항이며, 끄더라도 Steam 채팅을 사용할 수 있다.
3. 설치 위치를 확인하고 **설치 → 마침**을 누른다. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이다. 기존 설치를 갱신할 때는 같은 폴더를 사용한다.
4. 시작 메뉴에서 **Bongo Cat Chat**을 실행한다. Steam에 로그인하고 Bongo Cat을 실행한 뒤 게임에서 로비에 참여한다.
5. 앱의 연결 상태와 로비를 확인한 뒤 채팅한다. Enter로 전송하고 Shift + Enter로 줄을 바꾼다. 입력창의 길이 제한을 따른다.

앱은 Windows 표시 언어가 한국어이면 한국어, 그 외에는 영어로 시작한다. **설정 → 언어 / Settings → Language**에서 즉시 변경할 수 있다. 설치 프로그램의 한국어는 별도다.

설치 파일에는 Windows 코드 서명(Authenticode)이 아직 없다. Windows가 확인되지 않은 게시자나 실행 경고를 표시할 수 있다. 공식 저장소의 다운로드 출처와 파일명을 확인하고, 실행이 차단되면 보안 설정을 끄지 말고 경고 내용을 확인한다. 앱의 Ed25519 업데이트 서명과 Windows 게시자 인증은 별개다.

## 업데이트와 연결 문제

설정의 **앱 업데이트**에서 GitHub 통신을 허용하면 새 정식 GitHub 릴리스를 내려받는다. **업데이트 확인**으로 수동 확인할 수도 있다. dev10 이후 자동 재시작을 지원하는 실행기는 준비 완료 후 30초 안내를 거쳐 재시작한다. 입력·전송 중에는 기다리고 초안을 저장하며, 저장에 실패하면 현재 창을 유지한다. 이전 실행기는 다음 실행에 적용한다. 통신을 끄면 자동·수동 확인과 자동 재시작이 중지되며 이미 준비된 업데이트는 다음 실행에 적용될 수 있다. [자동 업데이트](automatic-updates.md)를 참고한다.

직접 업데이트하려면 앱을 종료하고 최신 Setup.exe를 기존 설치 폴더에 실행한다. 먼저 제거할 필요 없이 대화·초안·설정을 보존한다. 실행 중인 앱이 있으면 종료 안내가 나오고, 더 오래된 설치 파일로 덮어쓰기는 거절한다. 설치 위치를 바꾸려면 먼저 제거한다.

연결되지 않으면 Steam 로그인, Bongo Cat 실행, 게임 내 로비 참여를 확인한다. 게임 업데이트 후 호환성을 확인할 수 없으면 연동을 보류한다. 대응 앱 업데이트를 확인하고, 아직 없으면 기다려야 한다. 앱은 게임을 패치하지 않는다. 지원 범위는 [게임 업데이트 대응](game-update-compatibility.md)을 참고한다. 설치 성공만으로 실제 게임 연동이 검증된 것은 아니며 순정 게임·다른 PC·장시간 실행 인수는 남아 있다.

## 채팅 차단과 입·퇴장 안내

dev17은 게임의 고양이 숨김과 채팅 차단을 분리한다. 게임에서 숨겨 둔 상대도 앱에서 보일 수 있으며 기존 게임 숨김 목록을 자동 이전하지 않는다. 상대 채팅을 숨기려면 상단 참여자 목록의 **⋯ → 채팅 차단** 또는 **설정 → 채팅 차단**을 사용한다. Steam ID 기준으로 같은 PC의 로그인 계정별 차단을 유지한다. 해제하면 보관 중인 기존 기록만 다시 표시하며 차단 중 버린 내용은 복원하지 않는다. 차단은 수신 정책이고 상대가 내 로비 메시지를 받는 것을 막지 않는다. [채팅 차단](chat-blocking.md)을 참고한다.

연결 중 관찰한 로비 입·퇴장을 대화 사이에 안내한다. 첫 연결·재연결의 기존 참가자는 안내하지 않고, 새 메시지 알림·배지나 로비 전송을 발생시키지 않는다. [입·퇴장 안내](lobby-presence.md)를 참고한다.

## 알림과 개인정보 선택

설정에서 **작업 표시줄 깜빡임**과 **Windows 알림**을 각각 끌 수 있다. 다른 앱 사용·최소화 중의 새 상대 메시지에만 알리며 Windows 알림에 대화 내용·이름을 넣지 않는다. OS의 알림·방해 금지 설정에 따라 실제 표시가 제한될 수 있다. [알림 동작과 검증 범위](notifications.md)를 참고한다.

설치 중 개인정보 안내와 GitHub 업데이트 통신 선택을 제공한다. 재설치 때 기존 선택을 유지하며 앱 설정에서 변경할 수 있다. 앱 설정에서 개인정보·오픈소스 고지·대응 소스를 열람할 수 있다. [Privacy policy](privacy-policy.md) · [Code signing policy](code-signing-policy.md) · [대응 소스](licensing/SOURCES.md).

## 제거와 기록

Windows **설정 → 앱 → 설치된 앱 → Bongo Cat Chat → 제거**를 사용한다. Windows 10에서는 **앱 및 기능**에서 찾는다.

제거해도 대화 기록과 설정은 남는다. 대화 기록까지 지우려면 제거 전에 앱 설정에서 선택한 로비 또는 현재 계정의 기록을 삭제한다. 대화·초안·입퇴장 안내의 기본 보관 기간은 30일이며 앱 실행 중 정리한다. 차단 목록은 기록 삭제나 30일 정리로 지워지지 않고 직접 해제해야 한다. 앱을 꺼 둔 동안의 채팅을 복원하지 않는다.

개발자의 빌드·검사 절차는 [Windows 개발판](windows-app.md), 실제 시험 범위는 [설치 검증 기록](installer-validation.md)에 구분한다.
