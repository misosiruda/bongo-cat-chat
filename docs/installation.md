# Windows 설치 안내

일반 이용자는 설치 파일 하나로 설치한다. Python, Git, PowerShell 명령어 입력이나 관리자 권한은 필요하지 않다.

[최신 개발판 릴리스](https://github.com/misosiruda/bongo-cat-chat/releases/latest)에서 `BongoCatChat-<버전>-windows-x64-Setup.exe`를 받는다. `Source code` ZIP과 `bongo-cat-chat-windows-x64.zip`은 일반 이용자용 설치 파일이 아니다. 후자는 기존 앱의 자동 업데이트용이다. `0.1.0.dev7`에는 [고양이 프로필 모자 위치 수정](releases/0.1.0.dev7.md)이 포함된다.

## 설치와 시작

1. 릴리스에서 받은 `BongoCatChat-<버전>-windows-x64-Setup.exe`를 더블클릭한다.
2. 한국어 설치 안내에서 **다음 → 설치 → 마침**을 누른다. 설치 위치는 바꿀 수 있으며, 기본값은 현재 사용자의 프로그램 폴더다.
3. 시작 메뉴에서 **Bongo Cat Chat**을 실행한다.
4. Steam과 Bongo Cat을 실행하고 게임에서 로비에 참여한다. 앱의 연결 상태를 확인한 뒤 채팅한다.

Windows 10 이상 64비트 환경을 대상으로 빌드한다. dev6부터 채팅·숨김·로비·프로필 관련 구조와 처리 코드가 유지되는 게임 업데이트는 자동으로 연결한다. 관련 구조나 숨김 상태를 확인할 수 없는 환경에서는 대화 표시·송신을 보류한다. Mono·Steam 기반의 지원 범위는 [게임 업데이트 대응](game-update-compatibility.md)에 기록한다. 설치 성공만으로 게임 연동까지 검증된 것은 아니며 순정 게임·다른 PC 인수는 진행 전이다.

설치 파일에는 Windows 코드 서명이 아직 없다. Windows에서 출처 확인이나 실행 차단을 표시하는 경우에 대한 배포 경험도 검증 전이며, 일반 배포 전에 해결할 항목이다.

## 업데이트

새 정식 GitHub 릴리스가 있으면 앱이 자동으로 내려받고 **다음 실행 때 적용**한다. 사용 중인 채팅을 강제로 끊지 않는다. 설정의 **업데이트 확인**으로도 확인할 수 있다. GitHub의 소스 코드 변경만으로 설치된 앱이 바뀌지는 않는다.

게임 업데이트 후 호환성을 확인할 수 없으면 연동을 보류하고 대응 앱 업데이트를 확인한다. 준비됐다는 안내가 나오면 앱을 닫았다가 시작 메뉴에서 다시 실행한다. 대응 릴리스가 아직 없으면 기다려야 하며, 앱이 게임을 패치하지 않는다.

기존 개발판 이용자도 이 설치 파일을 한 번 실행하면 된다. 같은 설치 폴더를 선택하면 기록을 보존하며 교체한다. 실행 중인 앱이 있으면 먼저 닫으라는 안내가 나온다. 더 오래된 설치 파일로 설치된 앱을 덮어쓰지는 않는다.

## 제거와 기록

Windows **설정 → 앱 → 설치된 앱 → Bongo Cat Chat → 제거**를 사용한다. Windows 10에서는 **앱 및 기능**에서 찾을 수 있다.

제거해도 대화 기록과 설정은 남는다. 기록까지 지우려면 제거 전에 앱 설정에서 선택한 로비 또는 현재 계정의 기록을 삭제한다. 대화·초안의 기본 보관 기간은 30일이며 앱 실행 중 정리한다. 앱을 꺼 둔 동안의 채팅을 복원하지 않는다.

개발자의 빌드·검사 절차는 [Windows 개발판](windows-app.md), 실제 시험 범위는 [설치 검증 기록](installer-validation.md)에 구분한다.

## 서명 신청 준비 후보의 개인정보·고지

다음 배포를 준비하는 서명 작업 브랜치에는 설치 중 개인정보 전문 안내와 **GitHub 업데이트 확인 및 다운로드 허용** 선택이 있다. 재설치 때 기존 선택을 유지하며 무인 설치는 `/S /UPDATECHECKS=0`으로 통신을 끈다. 앱 설정에서 다시 켜거나 개인정보·오픈소스 고지·대응 소스를 열람할 수 있다. 아직 공개된 이전 설치 파일에는 이 변경이 포함되지 않는다.
