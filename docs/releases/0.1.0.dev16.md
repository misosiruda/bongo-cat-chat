# 0.1.0.dev16 개발판 / Development build

앱의 한국어·영어 UI와 영문 사용 안내를 추가한다. 기존 dev15의 반응 효과 설정과 연속 표시 개선도 포함한다.

## 변경 사항

- **설정 → 언어 / Language**에서 시스템 설정·한국어·English를 선택한다. 시스템 설정은 Windows 표시 언어가 한국어이면 한국어, 나머지는 영어를 사용한다.
- 저장 후 즉시 화면과 창 제목에 적용하며 재실행해도 유지한다. 저장 실패 시 이전 언어를 유지한다. 시작 시 설정을 읽지 못하면 저장 오류를 표시하고 시스템 언어로 연다.
- 연결·전송·검색·참여자·설정·업데이트 안내, 접근성 레이블, 날짜·시간, Windows 알림의 고정 문구를 번역한다. 영어 개인정보 안내를 앱에 동봉한다.
- 대화·초안·검색어·이용자 이름·로비 이름·게임 울음 문자열은 원문으로 유지한다. 언어 전환 시 선택 대화와 읽던 메시지 위치를 유지한다.
- [영문 README](../../README.en.md)에 설치, 사용법, 연결 방식, 개인정보, 검증 한계를 안내한다. 설치 마법사는 기존 한국어이며 영문 안내에서 버튼의 의미를 설명한다.

## English

This build adds **English and Korean UI**. Open **Settings → Language** and select **English**, **한국어**, or **System default**. The choice applies immediately and is saved on this device. System default uses Korean for a Korean Windows display language and English otherwise.

Connection, sending, search, participants, settings, update messages and accessibility labels are translated. Dates and times follow the selected language. The app includes an English privacy notice and an [English getting-started guide](../../README.en.md).

Your messages, drafts, search text, player names and lobby names are not translated. Switching languages preserves the selected conversation and reading position. The installer wizard remains in Korean; the English guide explains its buttons.

## 설치와 업데이트 / Installation and updates

`BongoCatChat-0.1.0.dev16-windows-x64-Setup.exe`를 사용한다. 기존 업데이트 피드·공개키·manifest와 데이터/실행기 스키마를 유지한다. `settings.language`만 추가하며 기존 기록을 변환하지 않는다. 기존 DB의 한국어 임시 이름은 실제 이름과 구분할 수 없어 치환하지 않는다.

Install `BongoCatChat-0.1.0.dev16-windows-x64-Setup.exe`, or allow the existing updater to prepare the update. Launchers from dev10 onward can restart automatically after the existing typing, sending and draft-saving checks. There is no database schema migration.

Windows Authenticode/SignPath 게시자 서명이 없는 개발판이다. 업데이트 manifest의 Ed25519 서명과 Windows 게시자 인증은 별개다. This development build does not have Windows publisher code signing; update authenticity is verified separately.

## 검증 범위

번역표의 문구·자리표시자, 시스템 언어 판정, 설정 저장·실패·재실행, Qt bridge/SQLite/렌더러와 토스트 XML 생성을 검사한다. Chrome 합성 화면에서는 한국어·영어 전환, 초안·검색·스크롤 보존, 3개 창 크기와 라이트·다크 설정창을 확인했다. 실제 실행 결과는 [한·영 지원 검증](../localization.md#검증)과 [제품 검증 기록](../product-validation.md)에 구분한다.

PR의 CI, 최종 설치 파일, 서명·공개 배포와 기존 설치본 업데이트는 각각 확인해야 한다. 실제 로비 송신·상대 화면·순정 게임·다른 PC·장시간 실행은 이 자동 검사에 포함되지 않는다.
