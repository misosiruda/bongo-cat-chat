# 0.1.0.dev9 개발판

고양이와 보라색 말풍선으로 Bongo Cat Chat의 아이콘을 통일한다. 원작의 양손 든 고양이를 참고한 새 투명 아이콘을 앱 왼쪽 위, Windows 창과 실행 파일, 설치·제거 프로그램, 브라우저 파비콘과 디자인 미리보기에 적용했다.

- Windows 아이콘은 16~256px의 10개 해상도, 파비콘은 16·32·48px를 포함한다.
- 라이트·다크 테마에서 같은 그림을 사용한다. 로고 파일은 앱에 동봉하며 원격 이미지를 받지 않는다.
- 채팅·프로필·숨김·로비 연결·기록 형식과 업데이트 공개키는 dev8에서 변경하지 않았다.

## 설치와 업데이트

[릴리스 페이지](https://github.com/misosiruda/bongo-cat-chat/releases/tag/v0.1.0.dev9)의 `BongoCatChat-0.1.0.dev9-windows-x64-Setup.exe`를 사용한다. 자동 업데이트를 허용한 기존 앱은 업데이트를 내려받은 뒤 다음 실행에 적용한다. Windows가 이전 바로가기 아이콘을 캐시한 경우 표시 갱신이 늦을 수 있다.

업데이트 ZIP·manifest·Ed25519 서명, 설치 파일, SHA-256 목록과 제3자 고지·대응 소스를 함께 제공한다. GitHub의 일반 최신 릴리스 채널을 사용하지만 제품 상태는 개발판이다. `data_schema=1`, `bootstrap_schema=1`과 기존 공개키를 유지한다. 데이터 마이그레이션은 없다.

## 검증 범위

아이콘 원본·규격·생성 프롬프트는 [디자인 기록](../design/app-icon.md), 소스 UI 검사 결과는 [제품 검증 기록](../product-validation.md#2026-10-15-앱-아이콘과-파비콘)에 있다. 릴리스 검증은 격리된 설치 및 합성 대화로 수행하며 실제 이용자의 대화나 게임에 테스트 메시지를 보내지 않는다. 게시 결과와 최종 검사 결과는 릴리스 페이지에 기록한다.

로컬 전체 검사의 최초 결과는 372개 통과·NSIS 관련 5개 실패였다. 테스트용 임시 프로젝트가 새 아이콘을 복사하지 않아 컴파일하지 못한 것으로 확인해 fixture에 아이콘을 추가했고, 실패한 5개를 재실행해 모두 통과했다. 기존 Qt·Chrome 화면 검사, 아이콘의 다중 해상도·라이트/다크 확인도 통과했다. Windows CI와 배포 후보 검사는 최종 head 기준으로 별도 확인한다.

Windows Authenticode/SignPath 게시자 서명은 없으며 Windows 경고가 남을 수 있다. 업데이트의 Ed25519 서명은 Windows 게시자 인증과 별개다. 이번 아이콘 변경은 순정 게임·다른 PC·장시간 안정성 인수 또는 게임 개발사의 승인을 의미하지 않는다.
