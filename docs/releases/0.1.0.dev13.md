# 0.1.0.dev13 개발판

캐릭터 아이템을 해제하면 사용자 프로필의 고양이 그림이 사라지던 문제를 수정한다. [이슈 #32](https://github.com/misosiruda/bongo-cat-chat/issues/32)의 기본 외형 조합을 다룬다.

## 변경 사항

- 캐릭터 미착용 시 기본 고양이를 표시한다. 모자가 남아 있으면 기본 고양이에 해당 모자를 합성한다.
- 양쪽 미착용은 모자 없는 기본 고양이를 표시한다. 캐릭터 착용·모자 미착용 경로도 회귀 검사한다.
- 명시적인 미착용과 슬롯·아이템 조회 실패를 구분한다. 착용·해제·재착용 시 메시지와 참여자 목록의 이미지가 갱신된다.
- dev12의 여러 줄 메시지, 새 메시지 알림, Steam 프로필 열기를 유지한다.

## 설치와 업데이트

`BongoCatChat-0.1.0.dev13-windows-x64-Setup.exe`를 사용한다. 기존 업데이트 피드와 Ed25519 공개키를 유지하며 대화·초안·설정·실행기 스키마는 변경하지 않는다. dev10 이상 실행기로 시작한 설치본은 업데이트 준비 후 기존 입력·저장 보호 절차에 따라 자동 재시작한다.

Windows Authenticode/SignPath 게시자 서명이 없는 개발판이다. 업데이트 manifest의 Ed25519 서명은 Windows 게시자 인증과 별개다.

## 검증 범위

- 설치된 게임 빌드 `25936063`의 파일을 읽어 미착용 값 `-1`과 기본 스프라이트 `CatLeft`·`CatRight`를 확인했다. 기본/착용 캐릭터와 모자 있음/없음의 네 조합을 설치 리소스로 정적 합성했다.
- 합성 데이터로 네 조합, 해제·재착용, 캐시 갱신, 조회 실패 구분, 실제 Qt/QWebChannel 화면의 메시지·참여자 이미지 갱신을 검사한다. 상세 결과는 [제품 검증 기록](../product-validation.md#2026-10-20-이슈-32-기본-아바타)에 기록한다.
- 이 PC에서는 사용자 요청에 따라 Bongo Cat을 실행하지 않는다. 실제 로비에서의 착용 변경·설치 앱과 게임 화면 대조·다른 PC·순정 환경·장시간 사용은 미검증이다.
- 서명·게시 대상은 별도 릴리스 작업이 검증한 최종 파일이다. 소스 검사·PR 병합을 공개 배포 완료로 간주하지 않는다.
