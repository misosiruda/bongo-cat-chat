# Bongo Cat Chat 0.1.0.dev20 · 자동 합성 연결 수정

Bongo Cat의 기존 로비 채팅을 별도 창에서 읽고 보내는 Windows용 서드파티 개발판입니다. **dev20은 dev19에서 같은 게임 버전인데도 자동 합성 연결이 차단되던 파일 조합을 추가 지원합니다.** 노트북에서 확인한 Auto Chest 파일 해시 하나만 추가하고 나머지 11개 게임 파일 검사는 유지합니다. 파일 조합 불일치·파일 누락·읽기 실패 안내를 구분합니다. 기존 자동 합성 사용법과 채팅 기능은 유지합니다.

## 처음 설치하시는 분

**[Windows 설치 파일 다운로드 — BongoCatChat-0.1.0.dev20-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev20/BongoCatChat-0.1.0.dev20-windows-x64-Setup.exe)**

채팅에 필요한 환경은 **Windows 10/11 64비트(x64)**와 설치된 **Steam 및 Bongo Cat**입니다. Python, Git, 명령어 입력, 별도 게임 모드는 필요하지 않습니다. 자동 합성의 지원 빌드 제한은 아래 사용법을 확인해 주세요. 설치는 현재 Windows 사용자에게 적용하며 관리자 권한을 요구하지 않습니다.

1. 위 링크에서 **Setup.exe 파일 하나**를 다운로드합니다. 아래 Assets의 `Source code`나 ZIP 파일을 풀어 설치할 필요는 없습니다.
2. 기존 Bongo Cat Chat이 실행 중이면 먼저 종료하고, 다운로드한 Setup.exe를 더블클릭합니다.
3. 한국어 설치 창에서 **다음**을 누르고 개인정보 안내를 읽습니다. **GitHub 업데이트 확인 및 다운로드 허용**은 선택 사항입니다. 끄더라도 Steam 채팅은 사용할 수 있으며, 나중에 앱 설정에서 변경할 수 있습니다.
4. 설치 위치를 확인하고 **설치 → 마침**을 누릅니다. 처음 설치할 때는 기본 위치인 `%LOCALAPPDATA%\Programs\BongoCatChat`을 사용하시면 됩니다.
5. Windows 시작 메뉴에서 **Bongo Cat Chat**을 실행합니다. **Steam에 로그인하고 Bongo Cat을 실행한 뒤, 게임에서 채팅할 로비에 참여**합니다.
6. 앱의 연결 상태와 로비를 확인합니다. 입력창에 메시지를 쓰고 **Enter**로 전송하며 **Shift + Enter**로 줄을 바꿉니다. 입력창의 `50` 한도를 따릅니다. 이모지 등은 한 글자보다 크게 계산될 수 있습니다.

앱은 Windows 표시 언어가 한국어이면 한국어, 그 외에는 영어로 시작합니다. **설정 → 언어 / Settings → Language**에서 한국어·English·시스템 설정을 선택할 수 있습니다. 설치 프로그램은 한국어이며 앱의 언어 설정과 별개입니다.

**Windows 코드 서명(Authenticode)은 아직 적용되지 않은 개발판입니다.** Windows가 확인되지 않은 게시자나 실행 경고를 표시할 수 있습니다. 다운로드 출처와 파일명이 위 공식 저장소 링크와 일치하는지 확인해 주세요. 실행이 차단되면 보안 설정을 끄지 말고 경고 내용을 확인해 주세요. 앱의 Ed25519 업데이트 서명은 Windows 게시자 인증과 별개입니다.

## 이미 설치하신 분

- **설정 → 앱 업데이트**에서 GitHub 통신을 허용하고 **업데이트 확인**을 누릅니다. dev17 등 자동 재시작을 지원하는 실행기는 다운로드·검증이 끝나면 30초 안내 후 재시작합니다. 입력·전송 중에는 기다리고 초안을 저장합니다.
- 자동 업데이트를 사용하지 않거나 적용되지 않으면 위 **동일한 Setup.exe**를 받습니다. 앱을 종료한 뒤 **기존과 같은 설치 폴더**에 설치하면 됩니다. 먼저 제거할 필요가 없으며 기존 대화·초안·설정을 보존합니다.
- 오래된 실행기에서 다음 실행에 적용한다는 안내가 나오면 앱을 종료한 뒤 시작 메뉴에서 다시 실행합니다.

## 아이템 자동 합성 사용법 — #43

1. Steam과 Bongo Cat을 실행한 상태에서 사이드바의 **아이템 자동 합성 → 게임에 연결**을 누릅니다. 게임 탭을 열어 두거나 전면에 유지할 필요가 없습니다. 수동 합성 화면은 닫아 주세요.
2. **캐릭터·모자·봉고** 또는 **이모티콘·UI 테마**를 고릅니다. 두 그룹의 재료와 가능 횟수는 합산하지 않습니다.
3. 실행 상한을 입력하거나 **최대값으로 설정**을 누릅니다. 연결·그룹 변경·최대값 입력만으로 아이템을 소비하지 않습니다.
4. **자동 합성 시작**을 누르면 원본 중복 자동 선택으로 종류별 1개를 남기고 매회 재료 10개를 선택합니다. 합성 1회의 결과를 확인한 뒤 다음 1회를 요청합니다.
5. **중지**는 다음 요청을 막습니다. 이미 접수된 합성은 취소할 수 없습니다. 패널을 닫아도 실행 상태와 중지는 사이드바·대화 상단에서 확인할 수 있습니다.

즐겨찾기 포함·이벤트 아이템 제외는 게임의 현재 설정을 따릅니다. 보호 옵션은 게임에서 바꿔 주세요. 기존 수동 선택·진행 중 교환·보호 설정 변경이 있으면 새 요청을 중단합니다. 결과가 불명확하면 성공으로 세거나 자동 재시도하지 않습니다. 앱 재실행·재연결만으로 자동 합성하지 않습니다.

**현재 자동 합성 지원 범위는 조사한 Windows x64 게임 build 25936063 + 확인된 Auto Chest 해시 2개 중 하나를 사용하는 검증된 파일 집합입니다.** 순정 설치와 다른 파일 집합은 연결이 보류될 수 있습니다. 채팅의 호환성 조건과 별개입니다. 자동 합성 연결에 한해 실행 중인 게임에 자체 모듈을 로드합니다. 게임 설치 파일이나 Auto Chest를 수정하지 않습니다. 배포본에는 자체 소스와 검사 도구만 포함하며 게임 DLL을 배포하지 않습니다. 첫 연결 시 Windows .NET Framework 도구로 모듈을 준비합니다. 해당 도구가 없거나 게임 버전이 다르면 연결을 거부하고 안내합니다.

이전 개발판의 모듈이 게임에 남아 있거나 앱 업데이트로 소스가 바뀐 경우 게임을 직접 다시 실행한 뒤 연결해야 할 수 있습니다. 앱이 게임을 종료하거나 자동 재시작하지 않습니다.

## 연결 문제와 기록 관리

- 연결되지 않으면 Steam 로그인, Bongo Cat 실행, 게임의 로비 참여 상태를 먼저 확인해 주세요. 게임 업데이트 후 호환성 확인이 보류되면 대응 앱 업데이트를 확인해 주세요. 자동 합성은 사용자가 연결할 때만 내부 모듈을 준비하며 게임 파일을 패치하지 않습니다.
- 게임에서 고양이를 숨기는 것과 앱의 채팅 차단은 별개입니다. 상대 채팅을 숨기려면 참여자 목록의 **⋯ → 채팅 차단** 또는 **설정 → 채팅 차단**을 사용합니다. 기존 게임 숨김 목록은 자동 이전하지 않습니다.
- 앱이 실제 수신한 대화·초안·입퇴장 안내의 기본 보관 기간은 **30일**입니다. 앱을 꺼 둔 동안이나 차단 중 버린 대화는 복원하지 않습니다. 차단 목록은 직접 해제할 때까지 유지합니다.
- 제거는 **Windows 설정 → 앱 → 설치된 앱 → Bongo Cat Chat → 제거**에서 합니다. Windows 10에서는 **앱 및 기능**입니다. 제거해도 기록과 설정은 남습니다. 대화 기록을 지우려면 제거 전에 앱 설정에서 기록 삭제를 사용해 주세요.

## English — install and start chatting

Bongo Cat Chat is a third-party Windows development app for Bongo Cat's existing lobby chat. **dev20 fixes an Auto merge connection rejection found on a laptop running the same game build as dev19's supported environment.** It adds one specifically inspected Auto Chest file hash, retains the other eleven pinned game file hashes, and distinguishes unsupported file combinations, missing files and unreadable files. Existing chat and auto merge controls remain.

**[Download the Windows installer — BongoCatChat-0.1.0.dev20-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev20/BongoCatChat-0.1.0.dev20-windows-x64-Setup.exe)**

Requirements: **Windows 10/11, 64-bit x64**, plus installed **Steam and Bongo Cat**. No Python, Git, command-line setup, game mod, or administrator permission is needed.

1. Download **Setup.exe** above. You do not need the source-code or update ZIP files in Assets.
2. Close any running Bongo Cat Chat window and double-click Setup.exe.
3. The installer is in Korean: **다음 = Next**, **설치 = Install**, **마침 = Finish**. Read the privacy notice. **GitHub 업데이트 확인 및 다운로드 허용** means **Allow update checks and downloads from GitHub**. This is optional and can be changed later in Settings; Steam chat works with it off.
4. Keep the default folder for a first installation, then choose **설치 → 마침**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Open **Bongo Cat Chat** from the Windows Start menu. Sign in to Steam, launch Bongo Cat, and **join a lobby in the game**. Check the app's connection status and lobby. **Enter** sends; **Shift + Enter** adds a line. Follow the displayed `50` length limit; some characters such as emoji count as more than one unit.

The app defaults to English unless the Windows display language is Korean. Choose **Settings → Language** for English, 한국어, or System. The installer remains Korean.

**This development installer is not Windows Authenticode-signed.** Windows may show an unknown-publisher or execution warning. Verify the official repository link and filename above; do not disable security controls to run it. Ed25519 update signatures do not provide Windows publisher certification.

### Updating an existing installation

In **Settings → App updates**, allow GitHub checks and select **Check for updates**. Launchers such as dev17 can restart after a 30-second notice once the download is verified, waiting for typing/sending and saving the draft. If automatic updating is disabled or does not apply, close the app and run the same Setup.exe into the **existing installation folder**. Uninstalling first is unnecessary; conversations, drafts and settings are preserved. Older launchers may ask you to close and reopen the app from the Start menu.

### Auto merge items

Open **Auto merge items → Connect to game** in the sidebar. Keep Bongo Cat running with its manual merge screen closed; no game tab needs to stay open or foregrounded. Choose **Characters / hats / bongos** or **Emotes / UI themes**, enter a limit or select **Set to maximum**, then press **Start auto merge**. Connecting and setting a maximum never consume items. Each request uses the original duplicate selector, preserves one per type, consumes ten materials for one exchange, and waits for its correlated result before continuing. Stop prevents the next request; it cannot cancel an accepted exchange. Closing the panel does not stop the run. Unknown outcomes are not retried or counted as successful, and reopening the app never resumes automatically.

Favorite/event protection follows the current game settings. **Auto merge currently accepts only the verified Windows x64 build 25936063 file set with either of the two explicitly inspected Auto Chest hashes.** Other installations, including an unverified clean installation, may be refused. Chat compatibility is separate. Explicit connection loads an app-owned module into the running game, without modifying game files or Auto Chest. Only our source and preparation tools are distributed; Windows .NET Framework tools compile the module against verified local game metadata. Missing tools or unsupported files block connection. After an app update, you may need to restart the game yourself before reconnecting.

The deployed dev19 connection failure was reproduced on the laptop. A patched local packaged EXE was checked through its actual UI for connection, both group counts, maximum limits, reconnection and enabled/blocked Start states. **No Start click or additional live exchange was performed.** Limits, Stop, duplicate requests and unknown outcomes were tested with a simulated game. The two previously authorized exchanges on another PC remain separate evidence. The real packaged UI reused the same-source module already connected in this game lifetime. First attachment by the package in a new game lifetime, rewards/inventory reconciliation, long-running operation, minimized windows, manual-interaction races, clean installations and other file combinations remain unverified.

### Troubleshooting and removal

Check Steam sign-in, Bongo Cat, and in-game lobby membership if disconnected. In-game cat visibility and app chat blocking are separate; use the participant menu or **Settings → Chat blocking** to hide chat. Received conversations, drafts and join/leave notices are kept locally for 30 days by default; offline or discarded messages cannot be recovered. Uninstall through **Windows Settings → Apps → Installed apps** (Windows 10: **Apps & features**). Records and settings remain after uninstalling; use the app's history deletion controls first if needed.
