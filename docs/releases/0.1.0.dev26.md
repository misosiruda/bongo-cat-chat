# Bongo Cat Chat 0.1.0.dev26

**dev26은 상자·합성 연결의 호환성 검사를 실제 기능 기준으로 바꿉니다.** 게임 파일 전체 해시가 달라졌다는 이유만으로 연결을 차단하던 경로와 상자 내부의 중복 제한을 정리했습니다.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev26/BongoCatChat-0.1.0.dev26-windows-x64-Setup.exe)** · [English](#english)

## 설치와 업데이트

Windows 10/11 x64에서 Setup.exe 하나를 받아 실행하세요. Steam에 로그인하고 Bongo Cat에서 로비에 참여한 뒤 시작 메뉴의 Bongo Cat Chat을 엽니다. Python이나 개발 도구는 필요 없습니다. 설치 중 개인정보 안내와 GitHub 업데이트 허용 여부를 확인하세요.

기존 사용자는 **설정 → 앱 업데이트 → 업데이트 확인** 후 안내에 따라 앱을 다시 시작하거나, 앱을 닫고 Setup.exe를 기존 폴더에 실행하세요. 대화·초안·설정은 보존합니다. 적용된 버전은 **v0.1.0.dev26**입니다. 자동화 진행·결과 대기·미확인 상태에는 자동 업데이트 재시작을 보류합니다.

이전 연결 모듈이 이미 게임에 올라가 있으면 앱이 교체하지 않습니다. 이 경우에만 결과를 확인하고 자동화를 중지한 뒤 사용자가 게임을 직접 다시 실행해야 합니다. 호환성 검사 단계에서 실패해 연결 모듈이 로드되지 않았던 경우에는 새 앱으로 다시 연결할 수 있습니다. 저장한 상자 자동 시작 설정은 유지됩니다.

## 변경 내용과 검증

- 합성·상자·인벤토리의 관련 함수, 보호 필드, 비동기 결과 콜백과 의존 코드를 함께 검사합니다. 무관한 게임 코드나 메타데이터 변경은 연결을 막지 않습니다.
- 상자에 따로 있던 전체 DLL 해시 제한을 제거하고 공통 계약을 사용합니다. Mono·Steam·외부 의존성과 기존 도우미의 검증은 유지합니다.
- 검사한 파일과 실행 중인 게임의 모듈이 다르면 차단합니다. 기능 미지원·검사 실패·게임 파일 변경 오류를 상자와 합성 화면에서 구분합니다.
- 현재 게임 build 26431657의 정적 검사와 컴파일, 독립 합성 DLL과 모의 게임/IPC를 검증했습니다. 실제 상자·아이템·포인트 소비, 게임 파일 변경과 게임 재시작은 수행하지 않았습니다. 장시간·최소화 상태의 실제 사용 인수는 남아 있습니다.

[검사 범위와 근거](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/automation-feature-compatibility.md) · [상자 사용법](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/auto-chest.md) · [합성 사용법](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/item-auto-merge.md)

이 개발판은 Windows **Authenticode 미서명**입니다. 공식 GitHub 릴리스에서 받은 파일인지 확인하세요. 자동 업데이트는 별도 Ed25519 서명을 검증합니다. 받은 대화는 기본 30일간 이 PC에 저장하며 앱 제거 후에도 기록·설정은 남습니다. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/privacy-policy.md). 문제 제보에는 오류 문구와 버전만 포함하고 대화 원문·Steam ID·로비 코드는 제외하세요.

## English

**dev26 checks chest and merge compatibility by the behavior the features use.** It removes the whole-game-DLL restriction and the duplicate chest allowlist that blocked otherwise unchanged automation after a game update.

**[Download the Windows x64 installer](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev26/BongoCatChat-0.1.0.dev26-windows-x64-Setup.exe)**

Use Windows 10/11 x64. Run Setup.exe, review the privacy and optional GitHub update choices, sign in to Steam, join a lobby in Bongo Cat and open Bongo Cat Chat from the Start menu. No developer tools are required. Existing users can use **Settings → App updates → Check for updates**, or close the app and install into the existing folder. History, drafts and preferences are preserved. Confirm **v0.1.0.dev26** in Settings.

If an older bridge is already loaded in the game, the app does not replace it: check outstanding results, stop automation and manually restart the game. A connection previously rejected before loading a bridge can be retried with the new app. Saved automatic chest-start preferences remain in effect. Active or unresolved automation postpones update restart.

The common contract covers merge, chest and inventory methods, protection fields, callbacks, iterators and dependencies. Unrelated game-code or metadata changes can pass; native runtimes and external dependencies remain pinned. Validation is bound to the modules in the running game. Unsupported behavior, failed verification and changed game files have distinct messages.

Validation covers metadata from game build 26431657, compilation/member resolution, synthetic assemblies and mock game/IPC behavior. No real items, chests or points were consumed; no game files were changed and the game was not restarted. Live minimized-window and endurance acceptance remain pending. See the [validation scope](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/automation-feature-compatibility.md).

This development installer is **not Windows Authenticode-signed**; download it from the official GitHub release. Automatic updates verify separate Ed25519 signatures. Received messages are stored locally for 30 days by default; uninstalling preserves local data and preferences. [Privacy policy](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev26/docs/privacy-policy.en.md). Exclude chat text, Steam IDs and lobby codes from issue reports.
