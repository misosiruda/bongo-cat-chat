# Bongo Cat Chat 0.1.0.dev25

Bongo Cat의 로비 채팅을 별도 창에서 읽고 보내는 Windows 앱입니다. **dev25는 상자 자동 개봉·아이템 자동 합성의 연결 끊김 예방과 자동 복구를 개선합니다.**

**[Windows 설치 파일 다운로드 · BongoCatChat-0.1.0.dev25-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev25/BongoCatChat-0.1.0.dev25-windows-x64-Setup.exe)**

처음 설치하거나 직접 업데이트할 때는 이 파일 하나만 받으세요. GitHub의 **Assets**에도 같은 이름으로 표시됩니다. [English instructions](#english)

## 처음 설치하고 연결하기

1. **Windows 10 또는 11 64비트(x64)** PC에 Steam과 Bongo Cat을 준비하세요. Python이나 Git은 필요 없습니다.
2. Bongo Cat Chat이 열려 있다면 닫고, 내려받은 Setup.exe를 더블클릭하세요.
3. **다음 → 개인정보 처리 안내 → 다음**을 누릅니다. **GitHub 업데이트 확인 및 다운로드 허용**은 선택 사항이며 앱 설정에서 바꿀 수 있습니다.
4. 기본 폴더에 **설치 → 마침**을 누르세요. Steam에 로그인하고 Bongo Cat을 실행한 뒤 **게임 안에서 로비에 참여**하세요.
5. 시작 메뉴에서 **Bongo Cat Chat**을 실행합니다. 로비 이름과 참여자 수가 표시되고 입력창이 활성화되면 **Enter**로 보내고 **Shift + Enter**로 줄을 바꿉니다. **설정 → 언어**에서 한국어와 English를 고를 수 있습니다.

## 기존 사용자가 업데이트하는 방법

- **설정 → 앱 업데이트 → 업데이트 확인**에서 다운로드·검증 후 앱의 재시작 안내를 따르세요. 자동화가 실행 중이거나 결과 대기·미확인 상태이면 업데이트 재시작이 보류됩니다. 먼저 게임에서 결과를 확인하고 자동화를 중지하세요.
- 직접 설치하려면 Bongo Cat Chat을 닫고 위 Setup.exe를 기존 설치 폴더에 실행하세요. 대화·초안·설정·별명은 보존됩니다. 적용 후 설정에서 **v0.1.0.dev25**를 확인하세요.
- **상자·합성 연결을 사용하던 분은 업데이트 후 Bongo Cat도 직접 종료하고 한 번 다시 실행해 주세요.** 실행 중인 게임에는 이전 연결 모듈이 남아 있습니다. 앱이 게임을 종료하거나 모듈을 교체하지 않습니다.

## 이번 버전에서 바뀐 연결 동작

- 최초 연결 후 상태 갱신을 화면 렌더링에서 분리하고, 연결 유지 신호가 일반 명령 응답을 기다리지 않게 했습니다. Windows 상태 파일 읽기·교체 충돌과 상자 실행 중 불필요한 합성 재고 집계도 줄였습니다.
- 같은 게임·계정에서 이미 시작한 실행은 인벤토리 갱신이나 일시적인 연결 장애에 **복구 대기 중**으로 표시되고, 상태를 다시 확인한 뒤 남은 작업을 이어갑니다.
- 사용자 중지·앱 종료·게임/계정/보호 설정 변경·소비 결과 미확인에는 자동으로 재개하지 않습니다. 이미 전달됐을 수 있는 개봉·합성 요청도 다시 보내지 않습니다.
- 새 게임이나 새 앱 실행에 이전 자동화를 인계하지 않습니다. 저장한 **앱 실행 시 자동 개봉 시작**은 기존대로 기본 OFF이며, 켠 경우의 새 실행과 기존 도우미 전환 확인 절차는 유지됩니다.

상자 자동 개봉과 아이템 자동 합성은 선택 기능입니다. 사이드바에서 해당 기능을 열어 **게임에 연결**하고 설정을 확인한 뒤 시작하세요. 실제 최소화·장시간 사용 인수는 남아 있으며 PC 절전이나 게임 전체 정지까지 무중단으로 보장하지 않습니다. [상자 사용법](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev25/docs/auto-chest.md) · [합성 사용법](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev25/docs/item-auto-merge.md)

## 연결 문제와 로컬 기록

- 로비가 보이지 않으면 Steam 로그인·게임 실행·게임 내 로비 참여를 확인하고 앱의 연결 상태를 새로고침하세요. 업데이트 후 자동화 연결이 계속 실패하면 게임을 한 번 직접 재실행했는지 확인하세요.
- 이 개발판의 Windows 설치 파일은 **Authenticode 미서명**입니다. 게시자를 확인할 수 없다는 안내가 나오면 위 GitHub 릴리스에서 받은 파일인지 확인하세요. 앱 자동 업데이트는 별도의 Ed25519 서명을 검증합니다.
- 받은 대화는 기본 30일간 로컬에 보관합니다. 설정에서 로비·계정 대화를 지울 수 있고, 별명은 참여자 메뉴에서 입력란을 비우고 저장하면 해제됩니다. **Windows 설정 → 앱 → 설치된 앱**에서 제거해도 로컬 기록과 설정은 남습니다. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev25/docs/privacy-policy.md)
- 문제가 계속되면 앱·Windows 버전, 실패한 단계와 오류 문구를 알려 주세요. 대화 원문·Steam ID·로비 코드는 제외해 주세요. [문제 제보](https://github.com/misosiruda/bongo-cat-chat/issues)

## English

Bongo Cat Chat lets you read and send Bongo Cat lobby messages in a separate Windows window. **dev25 improves connection stability and automatic recovery for chest opening and item merging.**

**[Download the Windows installer · BongoCatChat-0.1.0.dev25-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev25/BongoCatChat-0.1.0.dev25-windows-x64-Setup.exe)**

### Install and connect

1. Use a **Windows 10 or 11 x64** PC with Steam and Bongo Cat installed. No developer tools are required.
2. Close Bongo Cat Chat and open the installer. Select **다음 (Next)**, read the privacy notice and select **다음** again. Choose whether to allow GitHub update checks and downloads.
3. Keep the default folder, then select **설치 (Install) → 마침 (Finish)**. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**.
4. Open **Bongo Cat Chat** from the Windows Start menu. When the lobby appears and the message field is enabled, press **Enter** to send or **Shift + Enter** for a new line. Select English under **Settings → Language**.

### Update and use the connection fixes

- Use **Settings → App updates → Check for updates**, then follow the restart prompt. Active automation or pending/unknown results postpone app restart. Check the result in the game and stop automation first. Alternatively, close the app and run Setup.exe into the existing folder. Your history, drafts, settings and nicknames are preserved. Confirm **v0.1.0.dev25** in Settings.
- **If you used chest or merge connections, manually close and restart Bongo Cat once after updating.** A running game still holds the previous bridge. The app does not restart the game or replace its running module.
- State updates after connection no longer depend on rendering. Heartbeats no longer wait for command replies, concurrent state-file access is more reliable, and unused merge inventory scans are skipped during chest automation.
- A previously started run waits through temporary connection or inventory refresh problems, then continues after validating the same game and account. User stops, app exit, target/protection changes and unknown consumption results never resume automatically. Potentially delivered consuming requests are not resent.
- Chest and merge automation are optional sidebar features. Automatic chest start on app launch remains an opt-in setting, with the existing helper takeover confirmation preserved. Live minimized-window and endurance acceptance are still pending; sleep or a fully paused game cannot be guaranteed uninterrupted.

### Troubleshoot and manage data

Check Steam sign-in, the running game and in-game lobby membership if no lobby appears. Refresh the connection and, for automation after this update, confirm that you restarted the game once. This development installer is **not Windows Authenticode-signed**; verify the GitHub download source if Windows shows an unknown-publisher warning. The app verifies automatic updates with a separate Ed25519 signature.

Received chat is kept locally for 30 days by default. Delete chat in Settings and remove nicknames from the participant menu. Uninstall from **Windows Settings → Apps → Installed apps**; local data is preserved. [Privacy policy](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev25/docs/privacy-policy.en.md)

Validation uses synthetic game/IPC fixtures, an offline Qt renderer and compilation against supported game metadata. No real chests, points or items were consumed during this work. Update ZIPs, manifests, hashes and corresponding-source archives under **Assets** support the updater and source distribution. [Validation record](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev25/docs/product-validation.md)
