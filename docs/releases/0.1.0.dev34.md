# Bongo Cat Chat 0.1.0.dev34

**같은 로비에서 누가 누구를 복복하는지 채팅 상단에서 볼 수 있어요.** 슬림 배너를 최대 3줄로 표시하고, 같은 사람이 같은 대상을 연속으로 복복하면 한 줄에서 횟수가 올라가요.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev34/BongoCatChat-0.1.0.dev34-windows-x64-Setup.exe)** · [English installation guide](#english)

## 복복 알림 사용하기

- **설정 → 로비 복복 알림 → 복복 알림 표시**는 기본으로 켜져 있어요.
- 같은 쌍의 입력 간격이 1초 미만이면 횟수를 올려요. 1초 동안 입력이 없으면 1초에 걸쳐 사라져요. 사라지는 중 다시 복복하면 같은 줄에서 `×1`로 시작해요.
- 3줄을 넘는 활성 쌍은 **`+N쌍도 복복 중`**으로 표시해요. 긴 이름은 줄여 표시하고 횟수는 유지해요.
- 행위자나 대상 중 차단한 사람이 있으면 표시하지 않아요. 복복은 대화 기록·검색·Windows 알림에 남지 않아요.
- 자기 고양이를 직접 누르는 동작은 게임이 로컬에서만 처리해서 표시하지 않아요. 연결이 끊기거나 로비가 바뀌면 이전 알림은 지워져요.

횟수는 앱에서 받은 이벤트를 기준으로 해요. 복복이 한꺼번에 몰려 수신 큐가 혼잡하면 채팅과 연결 상태 전달을 우선하고 일부 복복은 생략할 수 있어요.

## 기존 설치를 업데이트할 때

1. 상자나 합성을 사용 중이면 중지하고 진행 중인 요청의 결과를 게임에서 확인해요.
2. **설정 → 앱 업데이트 → 업데이트 확인**에서 받아 앱을 재시작해요. 개봉·합성이 진행 중이거나 결과가 미확인이면 앱의 자동 재시작이 보류돼요. 설치 파일을 사용할 때는 앱을 닫은 뒤 기존 설치 폴더에 설치해요.
3. 시작 메뉴에서 Bongo Cat Chat을 열고 설정의 **v0.1.0.dev34**와 게임 로비 연결을 확인해요. 대화·초안·별명·설정은 보존돼요. 저장한 상자 자동 시작 옵션은 계속 적용돼요.

## 처음 설치할 때

Windows 10/11 x64, Steam과 Bongo Cat이 필요해요. **`BongoCatChat-0.1.0.dev34-windows-x64-Setup.exe`** 한 개를 받으세요. ZIP은 앱 업데이트용이에요.

1. Setup.exe를 실행해 **다음**을 누르고 개인정보 안내를 읽어요. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요.
2. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
3. Steam에 로그인하고 Bongo Cat에서 로비에 참여해요. 시작 메뉴에서 Bongo Cat Chat을 열고 연결된 로비를 확인해요. **Enter**로 채팅을 보내고 **Shift + Enter**로 줄을 바꿔요.
4. 상자 자동 개봉과 아이템 자동 합성은 선택 기능이에요. 사이드바에서 설정한 뒤 직접 연결·시작할 수 있어요. 다른 사람의 상자를 열면 내 포인트가 사용돼요.

## 연결이나 표시가 안 될 때

Steam 로그인, 게임 실행, 로비 참여와 앱의 연결 상태를 확인해요. 복복 알림 설정이 켜져 있는지도 확인해요. 게임 업데이트로 복복 지원 확인이 필요하면 설정에 안내가 표시돼요. 문제가 반복되면 앱을 닫기 전에 **버그 제보 → 수집한 진단 보기**에서 확인한 내용을 복사하거나 GitHub에 등록할 수 있어요.

Windows 설치 파일은 Authenticode 미서명 개발판이며 앱은 자동 업데이트의 Ed25519 서명을 검증해요. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev34/docs/privacy-policy.md) · [문제 제보](https://github.com/misosiruda/bongo-cat-chat/issues)

## English

**Lobby pats now appear as slim banners above the chat.** Up to three directional pairs are visible, with consecutive pats counted on the same row.

**[Download BongoCatChat-0.1.0.dev34-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev34/BongoCatChat-0.1.0.dev34-windows-x64-Setup.exe)**

### Using pat alerts

Open **Settings → Lobby pat alerts → Show pat alerts**. The option is on by default. A gap below one second adds to the count. After one second without input, the row fades for one second. A new pat during the fade restores the same row at `×1`. Extra active pairs appear in a summary. Blocking either participant hides the pair. Pat activity is not saved to chat history or sent to Windows notifications. Directly clicking your own cat is a local game action and does not produce a lobby alert. Under heavy receive-queue load, some pats may be dropped to keep room for chat and connection updates.

### Updating

Stop active chest opening or merging and check any pending result in the game. Use **Settings → App updates → Check for updates**, then restart the app. Pending automation can postpone an automatic restart. To use Setup.exe, close the app and install into your existing folder. Open Bongo Cat Chat from Start, confirm **v0.1.0.dev34** in Settings and check the lobby connection. History, drafts, nicknames and preferences are preserved; saved automatic chest startup options still apply.

### First installation

Use Windows 10/11 x64 with Steam and Bongo Cat. Download the Setup.exe linked above; the ZIP is for automatic updates.

1. Choose **다음 (Next)**, read the privacy notice and choose whether to allow GitHub update checks and downloads.
2. Confirm the folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
3. Sign in to Steam, join a Bongo Cat lobby and open Bongo Cat Chat from Start. Press **Enter** to send and **Shift + Enter** for a new line. Change language under **설정 → 언어 / Settings → Language**.
4. Chest opening and item merging are optional sidebar features. Configure them, then connect and start. Opening another player's chest spends your points.

If alerts are missing, check the lobby connection and **Show pat alerts**. Settings will show a notice when a game update needs pat compatibility verification. For recurring problems, open **Report a bug → View collected diagnostics** before closing the app. Copy the diagnostics or submit them on GitHub.

This Windows development installer is Authenticode-unsigned. The app verifies Ed25519 signatures for updates. [Privacy policy](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev34/docs/privacy-policy.en.md)

## 검증 범위 / Validation scope

실제 Qt UI와 합성 이벤트로 연속 횟수·페이드 재진입·초과 요약·차단·스크롤·초안을 검사했어요. 밝은/어두운 테마와 최소 400 × 500 창을 확인했어요. 구현 전 사용자의 실제 클릭과 이벤트 수신은 대조했지만, 구현 후 타인이 시작하는 복복·서로 다른 PC·순정 설치·장시간 실행은 별도 실게임 인수로 남아 있어요.

Synthetic events and the real Qt UI covered counts, fade revival, overflow, blocking, scroll and drafts. Light/dark themes and a 400 × 500 window were checked. Pre-implementation live observations matched the user's clicks to received events; post-implementation pats initiated by other participants, multiple PCs, a clean game installation and long-running use remain separate acceptance checks.
