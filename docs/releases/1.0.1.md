# Bongo Cat Chat 1.0.1

**[Windows 설치 파일 다운로드 — BongoCatChat-1.0.1-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.1/BongoCatChat-1.0.1-windows-x64-Setup.exe)**

연결 복구 안내가 잠깐 나타났다 사라질 때 채팅 영역이 줄어들며 스크롤이 움직이던 문제를 수정했어요.

## 달라진 점

- 복구 상태와 **복구 대기 취소**는 **설정 → 무인 복구**, 필요한 연결 안내는 **설정 → 문제 해결**에서 확인해요.
- 채팅 위의 고양이 숨김·채팅 차단 상시 설명은 제거했어요.
- 복복복 알림, 검색 결과 안내, 업데이트 안내와 합성 진행 표시는 채팅 위에 겹쳐 표시돼요. 표시와 해제로 채팅 영역 높이가 바뀌지 않아요.
- 복복복 알림 높이에 따른 스크롤 보정을 제거했어요. 복구·개봉·합성 동작, 설정과 저장 기록은 그대로예요.

## 처음 설치하기

Windows 10/11 x64, Steam과 Bongo Cat이 필요해요. 위 **Setup.exe**를 받으세요. ZIP은 자동 업데이트용이며 Python이나 개발 도구는 필요하지 않아요.

1. Setup.exe를 실행하고 **다음 → 개인정보 안내 확인 → 설치 → 마침**으로 진행해요. GitHub 업데이트 확인·다운로드 허용 여부를 선택할 수 있어요.
2. 기본 설치 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이며 현재 Windows 사용자용으로 설치돼요.
3. Steam에 로그인하고 게임 로비에 들어간 뒤 시작 메뉴에서 **Bongo Cat Chat**을 실행해요. 연결된 로비를 확인하고 Enter로 보내거나 Shift+Enter로 줄을 바꿔요.
4. 설정에서 언어와 기능을 선택해요. 받은 대화와 초안은 이 PC에 30일 보관하고 받지 못한 대화는 복원하지 않아요.

## 기존 사용자 업데이트

자동화를 중지하고 처리 중인 결과를 확인한 뒤 **설정 → 앱 업데이트 → 업데이트 확인**에서 내려받고 앱을 다시 시작하세요. 결과가 미확인인 작업이 있으면 재시작이 보류될 수 있어요. 업데이트 통신을 꺼 두었다면 앱을 닫고 위 Setup.exe를 기존 위치에 설치하세요. 설정에서 **v1.0.1**을 확인할 수 있어요.

기존 기록·초안·별명·차단·설정과 상자 자동 시작 선택은 보존돼요. 1.0.0에서 이번 패치로 업데이트할 때 게임 연결 모듈 변경이나 게임 재시작은 필요하지 않아요. 무인 복구는 기존 선택을 따르며 새 사용자는 기본 OFF예요. 자동 개봉 시작을 켜 두었다면 앱 재실행 후 저장된 선택으로 시작할 수 있어요.

## 문제 해결과 검증 범위

연결 문제는 Steam 로그인과 게임 로비를 확인하고 **설정 → 문제 해결**의 안내를 확인하세요. 버그 제보에서는 수집된 진단을 먼저 검토하고 개인 채팅·계정·로비 정보는 공개하지 마세요. [사용 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.1/README.md) · [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.1/docs/privacy-policy.md)

Windows 실행 파일은 **Authenticode 미서명**이에요. 자동 업데이트는 기존 **Ed25519 서명과 파일 해시**로 검증해요. 실제 복구 대기 안내의 표시·해제 시 스크롤과 채팅 높이 변화가 없는 것을 한 PC에서 확인했어요. 게임 종료·재시작을 포함하는 전체 무인 복구와 다른 PC·장시간 인수는 이번 UI 수정 검증과 구분해요.

**[Download Windows Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.1/BongoCatChat-1.0.1-windows-x64-Setup.exe)**

This patch fixes chat scrolling when brief recovery notices appear or disappear. Recovery status and cancellation are in Settings → Unattended recovery; connection details are in Settings → Troubleshooting. Pat alerts, search summaries, update notices and merge progress overlay the chat without resizing it. The permanent cat-hiding/blocking explanation is removed. Automation behavior and saved data are unchanged.

Use Windows 10/11 x64 with Steam and Bongo Cat. Run Setup.exe, read the privacy notice, choose whether to allow GitHub update checks/downloads, then install and launch from Start. Join a game lobby and confirm the connected room. Enter sends; Shift+Enter inserts a line break. Python is not required. Received chat and drafts are stored locally for 30 days; missed messages cannot be recovered.

Existing users: stop automation and verify pending results, then use Settings → App updates → Check for updates and restart Chat. If update communication is disabled, close Chat and install Setup.exe into the existing location. Verify v1.0.1 in Settings. History, drafts, nicknames, blocks and saved startup choices remain intact. Updating from 1.0.0 requires no game module change or game restart. Saved automatic chest startup may resume opening after Chat starts.

Windows executables remain Authenticode-unsigned; app updates retain Ed25519 signature and file-hash verification. The actual brief recovery-status transition was observed without scroll or viewport movement on one PC. Full game-restart recovery, other PCs and long sessions are separate acceptance scopes.
