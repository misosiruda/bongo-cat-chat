# 0.1.0.dev12 개발판

Windows 줄바꿈이 포함된 메시지의 수신 누락을 수정하고, dev11 이후 병합된 새 메시지 알림과 Steam 프로필 열기를 포함한다.

## 변경 사항

- **여러 줄 메시지:** LF·CRLF·CR을 허용한다. Windows 줄바꿈의 CR을 금지 문자로 판단해 메시지 전체를 버리던 문제를 수정했다. 원문은 저장·자기 에코 비교에 유지하고 화면에서만 LF로 통일해 빈 줄과 검색 강조를 표시한다. 과거에 거부되어 저장되지 않은 대화는 복원하지 않는다.
- **새 상대 메시지 알림:** 앱이 비활성일 때 작업 표시줄 깜빡임과 Windows 알림을 제공한다. 설정에서 각각 켜고 끄며 저장한 선택을 유지한다. 알림에는 이름·대화 내용을 넣지 않는다. Windows 알림 설정·방해 금지는 그대로 따르며 앱 종료 중에는 수신하지 않는다.
- **Steam 프로필 열기:** 현재 로비의 참여자 목록과 상대 메시지의 이름·고양이에서 Steam 프로필을 열 수 있다. 친구 추가는 열린 Steam 창에서 직접 진행한다. 숨김·참여·연결 상태가 확인된 상대만 허용한다.
- **릴리스 운영:** 별도 릴리스 저장소에서 빌드·파일 검사·승인 후 서명하고 기존 저장소의 업데이트 피드에 게시한다. 기존 이용자의 업데이트 공개키와 피드 주소는 유지한다.

## 설치와 업데이트

`BongoCatChat-0.1.0.dev12-windows-x64-Setup.exe`를 사용한다. 기존 dev10 이상 실행기로 시작했고 업데이트 통신이 허용된 앱은 다운로드 완료 후 30초 안내와 입력·저장 상태 확인을 거쳐 자동 재시작한다. dev9 이하에서는 다운로드 후 앱을 직접 다시 실행해야 한다.

기존 대화·초안·테마와 데이터·실행기 스키마를 유지한다. 알림 설정이 없는 프로필은 두 알림이 기본 ON이며 설정에서 변경할 수 있다. 신규 알림 설정은 기존 settings 테이블을 사용한다. Windows 알림 등록을 확인할 수 없으면 앱에서 상태를 안내하며, 기본 시작 메뉴 바로가기는 재설치로 복원할 수 있다.

Windows Authenticode/SignPath 게시자 서명은 없는 개발판이다. 업데이트 manifest의 Ed25519 서명은 Windows 게시자 인증과 별개다.

## 검증 범위

- 줄바꿈 수정의 [PR #29 CI](https://github.com/misosiruda/bongo-cat-chat/actions/runs/38864956615)와 [병합 소스 `3fa3e9a` CI](https://github.com/misosiruda/bongo-cat-chat/actions/runs/38865551050)가 성공했다. 후자는 **611개 테스트**, 앱 빌드·동결 오프라인 화면·고지 확인·NSIS 설치 파일 컴파일을 포함한다. 이는 버전을 dev12로 올리기 전 소스의 결과이며 dev12 후보 빌드 결과로 대체하지 않는다.
- 줄바꿈 합성 패킷·저장소 재열기·검색·정확한 에코 병합, Qt의 빈 줄·검색 강조, 다른 제어문자·잘못된 JSON 차단을 확인했다. [제품 검증 기록](../product-validation.md#2026-10-16-줄바꿈-메시지-수신-누락-수정)을 따른다.
- 알림과 프로필 기능의 합성 검사·실제 Windows API 시험·제품 화면 인수는 각각 [알림 검증](../product-validation.md#2026-10-16-이슈-24-제품-알림-연결), [프로필 검증](../product-validation.md#2026-10-16-이슈-23-steam-프로필-열기)에 구분한다.
- 이 버전의 승인 대상은 별도 릴리스 작업에서 새로 빌드한 파일과 해시다. 설치본의 실제 게임 송수신·제보 원본 패킷 대조·다른 PC·순정 설치·장시간 실행을 자동 검사 통과로 대신하지 않는다.
