# Bongo Cat Chat 0.1.0.dev29

**연결 초기화 실패를 별도로 안내하고, 버그 제보에 실패 단계와 제한된 예외 종류를 담아요.** #56에서 확인한 초기화 예외를 응답 지연과 구분해요. 해당 사용자 PC의 원인은 아직 확인 중이며, 이 버전만으로 연결이 해결됐다고 보장하지 않아요.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev29/BongoCatChat-0.1.0.dev29-windows-x64-Setup.exe)** · [English installation guide](#english)

## 처음 설치할 때

- **Windows 10/11 64비트(x64), Steam, Bongo Cat**이 필요해요. Python·개발 도구·관리자 권한은 필요하지 않아요.
- 다운로드할 파일은 **`BongoCatChat-0.1.0.dev29-windows-x64-Setup.exe`** 하나예요. `Source code` ZIP은 소스이고, `bongo-cat-chat-windows-x64.zip`은 앱 업데이트용이에요.

1. 실행 중인 Bongo Cat Chat이 있으면 종료하고 Setup.exe를 실행해요.
2. **다음 → 개인정보 처리 안내 확인 → 다음**으로 진행해요.
3. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요. 해제해도 Steam 채팅과 수동 버그 제보는 사용할 수 있어요.
4. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
5. Steam에 로그인하고 Bongo Cat을 실행해 **게임 안에서 로비에 참여**해요. 시작 메뉴에서 **Bongo Cat Chat**을 실행해요.
6. 앱의 연결 상태와 로비를 확인하고 채팅해요. **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿔요.

앱 언어는 **설정 → 언어 / Settings → Language**에서 한국어·English를 선택할 수 있어요. 설치 마법사는 한국어로 표시돼요. 상자 자동 개봉과 아이템 자동 합성은 선택 기능이며 채팅을 쓰기 위한 필수 설정이 아니에요.

## 기존 설치를 업데이트할 때

**설정 → 앱 업데이트 → 업데이트 확인**을 누르고 준비 완료 안내에 따라 앱을 다시 시작해요. GitHub 업데이트 통신을 꺼 뒀다면 켜거나, 앱을 종료하고 위 Setup.exe를 **기존 설치 폴더에** 실행해요. 먼저 제거할 필요 없이 대화·초안·설정·별명을 보존해요. 적용 후 설정에 **v0.1.0.dev29**이 표시되는지 확인해요.

자동화 진행 중이거나 결과를 기다리는 동안, 버그 제보 창을 열어 둔 동안에는 자동 업데이트 재시작을 보류해요. 저장한 **앱 실행 시 자동 개봉 시작** 설정은 유지되며, 켜 둔 경우 앱을 다시 열면 저장된 시작 동작이 적용될 수 있어요.

**상자·합성의 새 초기화 진단을 사용하려면 업데이트 후 게임과 앱을 한 번 완전히 종료하고 다시 실행해 주세요.** 진행 중인 개봉·합성 결과는 먼저 게임에서 확인해요. dev29는 앱 자체 연결 모듈을 변경하므로 실행 중인 구버전 모듈을 교체하지 않아요. 게임 설치 파일과 기존 Auto Chest 설정은 보존해요. 새 버전에서도 같은 오류가 나면 재실행을 반복하지 말고, 앱을 닫기 전에 아래 방법으로 제보해 주세요.

## 버그를 제보할 때

1. 오류가 나타난 뒤 앱을 종료하기 전에 **상자 자동 개봉 / 아이템 자동 합성 → 버그 제보**, 또는 **설정 → 문제 해결 → 버그 제보**를 눌러요.
2. **수집한 진단 보기**를 펼쳐 전송할 내용을 확인해요. 미리보기를 여는 것만으로 전송하지 않아요.
3. **GitHub에서 제보하기**를 눌러요. 기본 브라우저에 제목·진단 본문이 채워진 GitHub 이슈 작성 화면이 열리고, 이때 진단이 GitHub에 전달돼요.
4. GitHub에서 로그인하고 문제가 생긴 상황을 덧붙인 뒤 **등록(Submit new issue)**을 눌러요. 브라우저를 연 것만으로 접수가 완료되지는 않아요.

GitHub 계정이 없거나 브라우저를 열지 못하면 **진단 복사**로 같은 내용을 개발자에게 전달할 수 있어요. GitHub에 등록한 제보는 공개되므로 직접 덧붙이는 내용에도 개인 정보를 넣지 마세요.

진단에는 앱·Windows·Python 버전, 알려진 연결 상태·오류, 이번 앱 실행 중 최근 연결 실패 3회의 단계·초기화 결과와 확인 가능한 오류 번호가 들어가요. 초기화 세부 단계, 허용 목록에 있는 예외 종류 최대 3개와 고정된 실패 분류도 포함해요. 임의 예외 메시지는 제외해요. 확인된 게임 build 번호가 현재 상태에 있으면 함께 담아요. `attach_not_confirmed_no_retry`의 `status`·`stage`·`managed_exception` 등도 확인 가능한 범위에서 자동으로 담아요. 대화·초안·이름·Steam/로비 ID·파일 경로·프로세스 ID·연결 토큰·원본 로그·스택·소비 기록은 제외해요.

제보 버튼은 게임에 다시 연결하거나 상자·합성을 시작하지 않아요. 이전 앱 실행에서 사라진 상세 진단은 복원하지 못하므로, 업데이트 뒤 오류가 다시 발생하면 앱을 종료하기 전에 제보해 주세요. 연결 폴더나 `session.json`을 따로 찾거나 공유할 필요가 없어요. 기록이나 ledger를 삭제해 연결 제한을 해제하지 마세요.

## 변경 내용과 확인 범위

- 초기화 예외가 확인되면 `bridge_initialization_failed`로 안내하고 버그 제보를 요청해요. 이전 기록을 다시 읽을 때도 같은 분류와 진단을 유지해요.
- 모듈 연결 콜백 등록이 실패하면 초기화 완료로 표시하지 않도록 보완했어요.
- 민감 정보 제외, 초기화 오류 분류, 기존 기록 보존, 미확인 모듈 재로드 방지, 제보 중 업데이트 보류를 모의 연결·오프라인 Qt 검사로 확인했어요.
- 실제 사용자 PC의 연결 실패 원인은 아직 확정하지 않았어요. 이 기능은 원인 조사에 필요한 진단을 전달하기 위한 기능이에요.
- 실제 상자 개봉·합성·포인트 소비, 실행 중 게임/기존 설치 변경, 실제 GitHub 제보 등록은 검사에서 수행하지 않았어요.

## English

**dev29 distinguishes initialization failures from delayed responses and reports allowlisted failure stages and exception types.** Issue #56 confirmed an initialization exception, but its root cause on the reported PC remains under investigation. This release does not claim that PC's connection is fixed.

**[Download BongoCatChat-0.1.0.dev29-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev29/BongoCatChat-0.1.0.dev29-windows-x64-Setup.exe)**

### First installation

You need **Windows 10/11 x64, Steam and Bongo Cat**. Python, developer tools and administrator privileges are not required. Download only the Setup.exe above; the source ZIP is source code, and `bongo-cat-chat-windows-x64.zip` is for the app updater.

1. Close any running Bongo Cat Chat and launch Setup.exe.
2. The installer is in Korean. Choose **다음 (Next)**, read the privacy notice, then choose **다음 (Next)**.
3. Choose whether to allow **GitHub 업데이트 확인 및 다운로드 허용 (GitHub update checks and downloads)**. Chat and manual bug reporting still work if you turn this off.
4. Confirm the install folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**. Open **Bongo Cat Chat** from the Start menu.
6. Check the connection and lobby, then chat. **Enter** sends; **Shift + Enter** inserts a line break. Choose English in **설정 → 언어 / Settings → Language** if needed.

Automatic chest opening and item merging are optional and are not required for chat.

### Updating an existing installation

Use **Settings → App updates → Check for updates**, then follow the app restart prompt. If GitHub update access is disabled, enable it or close the app and run Setup.exe into the **existing install folder**. Uninstalling first is unnecessary. History, drafts, preferences and nicknames are preserved. Confirm **v0.1.0.dev29** in Settings.

Active automation, pending/unverified results and an open bug report window postpone automatic update restart. Saved **Start automatic chest opening when the app launches** consent is preserved and may start the configured automation when the app relaunches.

**To use the new chest/merge initialization diagnostics, fully close the game and app once after updating, then reopen them.** Check any pending opening/merge results in the game first. dev29 changes the app's own connection module and does not replace an older module inside a running game. Installed game files and existing Auto Chest settings are preserved. If the error returns, report it before closing the app instead of repeating restarts.

### Reporting a bug

1. After the error, before closing the app, choose **Report a bug** in the chest/merge panel or **Settings → Troubleshooting → Report a bug**.
2. Expand **View collected diagnostics** to review the content. Previewing alone does not send it.
3. Choose **Report on GitHub**. Your default browser opens a draft with its title and diagnostics filled in; diagnostics are sent to GitHub at this point.
4. Sign in, add what happened and choose **Submit new issue**. Opening the browser does not finish submission.

Without a GitHub account, or if the browser cannot open, choose **Copy diagnostics** and share the report with the developer. Submitted issues are public; do not add personal information.

The report contains app/Windows/Python versions, known connection states/errors and allowlisted initialization results from the last three failed connections during this app session. A known game build is included when available. This includes `status`, `stage`, `managed_exception`, a known initialization step, up to three allowlisted exception types and fixed failure classifications when available. Arbitrary exception messages are excluded. A confirmed initialization exception is reported as `bridge_initialization_failed`. Chat, drafts, names, Steam/lobby IDs, paths, process IDs, connection tokens, raw logs, stacks and consumption records are excluded.

The report button does not reconnect, open chests or merge items. Diagnostics lost from an earlier app session cannot be reconstructed. Report a recurring error before closing the updated app. You do not need to find or share the connection folder or `session.json`. Do not delete records or ledgers to bypass connection guards.

Validation uses synthetic connections and offline Qt tests. No real items/chests/points were consumed, no running game or existing user installation was changed, and no live GitHub issue was submitted. The reported user's root cause remains unconfirmed. [Validation](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev29/docs/product-validation.md)

This development installer is **not Windows Authenticode-signed**. Download it from the official GitHub release. Automatic updates verify separate Ed25519 signatures. Received messages are kept locally for 30 days by default; uninstalling preserves records and settings.
