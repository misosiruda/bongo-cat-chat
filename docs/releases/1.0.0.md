**[BongoCatChat-1.0.0-windows-x64-Setup.exe 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.0/BongoCatChat-1.0.0-windows-x64-Setup.exe)**

채팅·상자 자동 열기·아이템 자동 합성을 정식 기능으로 포함해요. 공개 dev34의 기능과 사용 흐름을 유지하고 앱·설치기·Windows 버전 표시와 사용 안내를 정리했어요. 새 설정을 선택하거나 데이터를 옮길 필요는 없어요.

## 처음 설치할 때

Windows 10/11 x64, Steam과 Bongo Cat이 필요해요. 위 **Setup.exe 한 개**를 받으세요. `Source code`는 개발용 소스이고 `bongo-cat-chat-windows-x64.zip`은 앱 업데이트용이에요. Python이나 개발 도구를 별도로 설치할 필요는 없어요.

1. Setup.exe를 실행해 **다음**을 누르고 개인정보 안내를 읽어요. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요.
2. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요. 현재 Windows 사용자에게 설치하며 관리자 권한과 Windows 자동 시작 등록은 요구하지 않아요.
3. Steam에 로그인하고 Bongo Cat에서 로비에 참여해요. 시작 메뉴에서 **Bongo Cat Chat**을 열고 연결된 로비를 확인해요.
4. **Enter**로 채팅을 보내고 **Shift + Enter**로 줄을 바꿔요. 앱이 받은 대화와 초안은 이 PC에 30일 보관해요. 앱이 받지 못한 과거 대화는 복원하지 않아요.
5. **설정 → 언어**에서 한국어·영어·시스템 설정을 선택할 수 있어요.

## 상자와 아이템 합성을 사용할 때

- **상자 자동 개봉**: 사이드바에서 상자 종류·대기 시간을 저장하고 **게임에 연결 → 자동 개봉 시작**을 눌러요. 다른 사람의 상자는 기본 OFF이며 켜면 내 포인트를 사용해요. **앱 실행 시 자동 개봉 시작**은 기본 OFF예요. 켜고 저장하면 다음 앱 실행에서 연결이 준비된 뒤 한 번 시작해요. 기존 Auto Chest가 있으면 이번 게임 실행 동안의 전환을 먼저 확인해요.
- **아이템 자동 합성**: **게임에 연결**한 뒤 그룹·보호 옵션·최대 횟수를 확인하고 직접 시작해요. 연결하거나 최대 횟수를 입력하는 것만으로 합성하지 않아요.
- 두 자동화는 동시에 실행하지 않아요. 중지는 새 요청을 막으며 이미 게임에 전달된 요청은 취소하지 못할 수 있어요. 결과가 미확인이면 다시 소비 요청을 보내지 않고 게임에서 결과를 확인해요.
- 복복 알림·별명·채팅 차단·검색·알림 등 dev34의 기능을 그대로 사용할 수 있어요.

## 기존 개발판을 업데이트할 때

1. 상자나 합성을 사용 중이면 중지하고 진행 중인 요청의 결과를 게임에서 확인해요.
2. **설정 → 앱 업데이트 → 업데이트 확인**에서 받아 앱을 재시작해요. 진행 중이거나 결과가 미확인인 자동화는 업데이트 재시작을 보류해요. 업데이트 통신을 껐다면 직접 받은 Setup.exe로 업데이트할 수 있어요.
3. Setup.exe를 사용할 때는 앱을 닫고 기존 설치 폴더에 설치해요. 대화·초안·별명·차단·언어·자동화 설정과 업데이트 통신 선택을 유지해요. 저장된 상자 자동 시작 선택도 그대로 적용돼요.
4. 시작 메뉴에서 앱을 열고 **설정의 v1.0.0**을 확인해요. dev34 실행기로 처음 업데이트할 때 Windows 설치된 앱 목록의 버전은 정상 종료 또는 실행 후 45초가 지난 뒤 반영될 수 있어요. 초기 실행 실패로 복귀하면 이전 버전 표시를 유지해요.

## 연결이나 실행에 문제가 있을 때

Steam 로그인·게임 실행·로비 참여와 앱의 연결 상태를 확인해요. 게임 업데이트 후 호환성을 확인하지 못했다는 안내가 있으면 앱의 업데이트 상태를 확인해요. 반복되는 문제는 앱을 닫기 전에 **버그 제보 → 수집한 진단 보기**에서 내용을 검토하고 복사하거나 GitHub에 등록할 수 있어요. 공개 이슈에 대화 원문·계정 ID·로비 ID·개인 로그를 올리지 마세요.

Windows 실행 파일은 **Authenticode 미서명**이며 Windows가 게시자 경고를 표시할 수 있어요. 앱 업데이트는 기존 공개키의 **Ed25519 서명과 파일 해시**를 검증해요. 두 서명은 서로 다른 용도예요. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.0/docs/privacy-policy.md) · [문제 제보](https://github.com/misosiruda/bongo-cat-chat/issues)

Chat, automatic chest opening and automatic item merging are included as supported features in 1.0.0. The existing dev34 behavior is preserved, with updated product labels, Windows version reporting and user guides.

### First installation

Use Windows 10/11 x64 with Steam and Bongo Cat. Download **Setup.exe** above. The ZIP is for app updates and Source code is for developers. Python and development tools are not required.

1. Choose **다음 (Next)**, read the privacy notice and choose whether to allow GitHub update checks and downloads.
2. Confirm the folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`. Installation is per Windows user, without administrator access or automatic startup registration.
3. Sign in to Steam, join a Bongo Cat lobby and open **Bongo Cat Chat** from Start. Confirm the connected lobby. Press **Enter** to send and **Shift + Enter** for a new line.
4. Select a language under **설정 → 언어 / Settings → Language**. Received messages and drafts stay on this PC for 30 days. Messages the app did not receive cannot be recovered.

### Using chest opening and merging

Open the sidebar panel, choose options, then connect and start. Opening other players' chests is OFF by default and spends your points when enabled. **Start chest opening when app launches** is OFF by default; saving it as ON allows a start after connection is ready on the next app launch. Switching from an existing Auto Chest helper requires confirmation for that game lifetime.

For item merging, review the group, protection options and limit before pressing Start. Connecting or entering a limit does not merge items. The two automations cannot run simultaneously. Stop prevents new requests; a request already accepted by the game may still finish. An unverified result is not automatically retried. Pat alerts and other dev34 features remain available.

### Updating and troubleshooting

Stop automation and check any pending result in the game. Use **Settings → App updates → Check for updates**, then restart. Pending automation may postpone the restart. If update requests are disabled, download Setup.exe manually, close the app and install into the existing folder. History, drafts, nicknames, blocks, preferences and saved chest startup choices are preserved. Confirm **v1.0.0** in Settings. On the first upgrade from the dev34 launcher, Windows Installed apps may retain the old version until normal exit or 45 seconds of execution; an early failed start retains the previous version on rollback.

For problems, check Steam login, game/lobby state and the app's compatibility notice. Before closing the app, use **Report a bug → View collected diagnostics** and review the contents before copying or reporting them on GitHub. Do not include personal chat, account/lobby IDs or raw logs in public issues.

Windows executables are **Authenticode-unsigned** and may show publisher warnings. App updates use the existing **Ed25519 signature and file-hash verification**. [Privacy policy](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.0/docs/privacy-policy.en.md)
