# 0.1.0.dev10 개발판

새 버전 다운로드 후 앱을 직접 껐다 켜지 않아도 업데이트가 적용되도록 자동 재시작을 추가했다.

- 시작 15초 후와 실행 중 6시간마다 새 릴리스를 확인하고 내려받는다.
- 준비 완료 후 대화 화면과 설정에 30초 안내를 표시하고 앱을 정상 종료·재시작한다.
- 한글 조합·방 전환·메시지 전송 중에는 기다리며 마지막 입력 후 5초가 지나고 최신 초안 저장이 성공해야 진행한다. 저장 오류와 미저장 기록이 있으면 현재 창을 유지한다.
- 대화·초안·테마·사이드바 설정과 읽기 전용 실행 옵션을 유지한다. 게임·Steam을 종료하거나 결과가 불명확한 메시지를 재송신하지 않는다.
- 업데이트 통신 허용을 끄면 예약된 자동 재시작도 취소한다. 이미 준비된 패키지는 다음 수동 실행에 적용될 수 있다.
- 재시작 보조 실행기의 복사·실행이 실패하면 현재 앱을 다시 열고 해당 세션의 자동 재시작 반복을 막는다.

## 설치와 전환

`BongoCatChat-0.1.0.dev10-windows-x64-Setup.exe`로 설치하거나 기존 자동 다운로드·다음 실행 적용 경로로 갱신한다. **공개 dev9와 그 이전 버전에는 자동 재시작 기능이 없으므로 dev10으로의 첫 전환은 기존 방식으로 앱을 다시 시작해야 한다.** dev10 실행기로 시작한 이후의 업데이트부터 자동 재시작을 사용한다.

`data_schema=1`, `bootstrap_schema=1`과 기존 Ed25519 공개키를 유지한다. 데이터 마이그레이션은 없다. GitHub 최신 일반 릴리스 채널을 사용하지만 제품 상태는 개발판이다.

## 검증 범위

소프트웨어 렌더링 환경의 로컬 전체 테스트 **395개**를 통과했다. 실제 Qt에서 초안 저장·한글 조합·전송 대기·저장 실패·통신 설정 해제·정상 종료 후 DB 잠금 해제를 검사했다. 실제 NSIS 설치본에서 서명된 dev10 후보를 준비한 뒤 **30.311초 후 자동 종료·실행기 인계·새 앱 재시작**을 확인했다. 합성 DB의 대화·초안·설정·연결 기록 전후 일치, 설치·제거와 파일 보존도 통과했다. 공개 다운로드 결과는 [자동 업데이트 검증 기록](../update-validation.md)에 구분한다.

자동 재시작 시험의 이전 버전은 이번 코드에서 버전만 dev9로 지정해 만든 시험 설치본이다. 이를 기존 공개 dev9가 자동 재시작을 지원한다는 증거로 사용하지 않는다. 게임 작업자가 없는 명시적 업데이트 진단 모드와 합성 기록을 사용하며, 실제 게임 송수신·순정 설치·다른 PC·장시간 안정성 인수는 별도다.

Windows Authenticode/SignPath 게시자 서명은 없으며 Windows 경고가 남을 수 있다. 업데이트의 Ed25519 서명은 Windows 게시자 인증과 별개다. 재시작 동안 앱이 수신하지 못한 대화의 복원을 보장하지 않는다.
