# Bongo Cat Chat 1.0.2

**[Windows 설치 파일 다운로드 — BongoCatChat-1.0.2-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.2/BongoCatChat-1.0.2-windows-x64-Setup.exe)**

봉고캣을 업데이트한 뒤 Chat에 게임이 지원되지 않는다고 표시되던 문제를 고쳤어요. 게임 빌드 `26754239`에서 현재 로비를 찾아 다시 대화를 받을 수 있어요. 상자 자동 개봉과 아이템 자동 합성도 새 게임 파일을 인식해요.

## 기존 사용자 업데이트

1. 상자·합성을 실행 중이라면 먼저 중지하고 처리 중인 결과를 확인해요.
2. **설정 → 앱 업데이트 → 업데이트 확인**에서 1.0.2를 받고 Chat을 다시 시작해요. 업데이트 통신을 꺼 뒀다면 Chat을 닫고 위 설치 파일을 기존 위치에 설치해요.
3. 게임은 현재 로비에 둔 채 Chat 상단에 **게임과 연결됨**이 뜨는지 확인해요. 대화 기록과 설정은 이어서 사용해요. 상자 자동 시작을 켜 뒀다면 Chat을 다시 열 때 저장된 선택에 따라 시작할 수 있어요.

## 처음 설치하기

Windows 10/11 x64에서 위 **Setup.exe**를 실행하고 **다음 → 개인정보 안내 확인 → 설치 → 마침** 순서로 진행해요. 설치 중 GitHub 업데이트 확인·다운로드 허용 여부를 선택할 수 있어요.

Steam에 로그인해 Bongo Cat의 로비에 들어간 뒤 시작 메뉴에서 **Bongo Cat Chat**을 열어요. 상단의 로비를 확인하고 Enter로 보내거나 Shift+Enter로 줄을 바꿔요. 상자·합성은 필요할 때 선택해서 사용해요.

## 연결 확인과 문제 해결

설정에서 앱 버전이 **1.0.2**인지 확인해요. 계속 연결을 기다린다면 게임에서 로비에 참여했는지 확인한 뒤 **설정 → 문제 해결**을 열어요. 버그를 제보할 때는 진단 미리보기를 확인하고 개인 대화와 계정 정보는 제외해요. [사용 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.2/README.md) · [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.2/docs/privacy-policy.md)

이 빌드에서 실제 로비 연결과 새 대화 수신을 한 PC에서 확인했어요. 상자·합성은 게임 파일 검사와 연결 모듈 컴파일, 모의 동작으로 검증했어요. 실제 아이템 소비와 장시간 실행은 이번 검증 범위에서 제외했어요. Windows 실행 파일은 Authenticode 미서명이며, 자동 업데이트는 Ed25519 서명과 파일 해시를 확인해요.

## English

**[Download the Windows installer](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.2/BongoCatChat-1.0.2-windows-x64-Setup.exe)**

Version 1.0.2 restores lobby chat after the Bongo Cat update to build `26754239`. Chat can identify the current lobby and receive new messages. Automatic chest opening and item merging also recognize the updated game files.

If you already use Chat, stop any running automation and confirm pending results. Open **Settings → App updates → Check for updates**, download 1.0.2 and restart Chat. You can leave the game in its lobby. If you disabled update checks, close Chat and run Setup.exe in the existing installation location. Your history and preferences carry forward. Saved chest auto-start settings can start opening chests when you reopen Chat.

For a first installation on Windows 10/11 x64, run Setup.exe, read the privacy notice, choose your update preference and finish the installation. Sign in to Steam, join a Bongo Cat lobby, then launch **Bongo Cat Chat** from Start. Check the lobby shown in Chat. Enter sends a message and Shift+Enter adds a line break. If Chat is waiting for a connection, check the version in Settings and open **Troubleshooting**.

We verified live lobby connection and incoming chat on one PC. Chest and merge checks covered compatibility, compilation and simulated operations. Windows executables are Authenticode-unsigned. The updater verifies the Ed25519 signature and file hashes.
