# Bongo Cat Chat 1.0.3

**[Windows 설치 파일 다운로드 — BongoCatChat-1.0.3-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.3/BongoCatChat-1.0.3-windows-x64-Setup.exe)**

봉고캣 빌드 `26784007`로 업데이트한 뒤 Chat이 게임을 지원하지 않는다고 표시되던 문제를 고쳤어요. 로비 채팅과 상자·합성이 새 게임 파일을 인식해요. 게임이 인벤토리를 다시 조회하기로 한 경우 상자 개봉과 아이템 합성은 조회가 끝날 때까지 기다려요.

## 기존 사용자 업데이트

1. 상자·합성을 실행 중이라면 중지하고 처리 중인 결과를 확인해요.
2. **설정 → 앱 업데이트 → 업데이트 확인**에서 1.0.3을 받고 Chat을 다시 시작해요. 업데이트 통신을 꺼 뒀다면 Chat을 닫고 위 설치 파일을 기존 위치에 설치해요. 대화 기록과 설정은 이어서 사용해요.
3. 게임 로비에 들어간 상태에서 Chat 상단에 **게임과 연결됨**이 표시되는지 확인해요. 상자 자동 시작을 켜 뒀다면 저장한 설정에 따라 시작할 수 있어요. 이전 자동화 연결과 호환되지 않는다는 안내가 뜨면 진행 중인 결과를 확인한 뒤 게임과 Chat을 완전히 종료하고 다시 열어요.

## 처음 설치하기

Windows 10/11 x64에서 **Setup.exe**를 실행하고 **다음 → 개인정보 안내 확인 → 설치 → 마침** 순서로 진행해요. 설치 중 GitHub 업데이트 확인·다운로드 허용 여부를 고를 수 있어요. Steam에 로그인해 게임 로비에 들어간 뒤 시작 메뉴에서 **Bongo Cat Chat**을 열어요. Chat에 표시된 로비를 확인하고 Enter로 보내거나 Shift+Enter로 줄을 바꿔요.

## 연결 확인과 문제 해결

설정에 **1.0.3**이 표시되는데도 연결을 기다린다면 게임에서 로비에 참여했는지 확인해요. **설정 → 문제 해결**에서 진단을 미리 보고 제보할 수 있어요. [사용 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.3/README.md) · [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v1.0.3/docs/privacy-policy.md)

이 빌드의 게임 파일과 모의 상자·합성 동작을 확인했어요. 실게임을 관찰한 동안 로비 참여 상태가 아니어서 실제 대화 송수신은 확인하지 못했어요. 실제 아이템 소비 시험은 수행하지 않았어요. Windows 실행 파일은 Authenticode 미서명이며 자동 업데이트는 Ed25519 서명과 파일 해시를 확인해요.

## English

**[Download the Windows installer](https://github.com/misosiruda/bongo-cat-chat/releases/download/v1.0.3/BongoCatChat-1.0.3-windows-x64-Setup.exe)**

Version 1.0.3 recognizes Bongo Cat build `26784007` for lobby chat, chest opening and item merging. If the game schedules another inventory refresh, automation waits for it to finish.

To update, stop active automation and confirm pending results. Open **Settings → App updates → Check for updates**, download 1.0.3 and restart Chat. If you disabled update checks, close Chat and run Setup.exe in the existing installation folder. Your history and preferences carry forward. Saved chest auto-start preferences still apply. If Chat reports an incompatible automation session, confirm pending results, close both programs and reopen them.

For a first installation on Windows 10/11 x64, run Setup.exe, read the privacy notice, choose your update preference and finish installation. Sign in to Steam, join a Bongo Cat lobby and open **Bongo Cat Chat** from Start. Confirm the lobby in Chat. Enter sends a message and Shift+Enter adds a line break. For connection issues, check the version in Settings and open **Troubleshooting**.

We checked the updated game files, compiled against them and tested chest and merge behavior in a simulated game. The live game reported no active lobby during observation. Live messaging and item consumption were untested. Windows executables are Authenticode-unsigned. The updater verifies the Ed25519 signature and file hashes.
