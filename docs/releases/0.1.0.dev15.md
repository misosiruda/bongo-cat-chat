# 0.1.0.dev15 개발판

이모티콘·야옹 반응 전체를 설정에서 켜고 끌 수 있게 한다. 연속으로 받을 때 동시 표시 상한 때문에 다음 반응이 한동안 보이지 않던 현상도 수정한다. 화면에 표시할 수 있는 수를 늘리고, 가득 차면 가장 오래된 파티클을 새 반응으로 교체한다.

## 변경 사항

- **설정 → 고양이 반응 효과 → 이모티콘·야옹 효과 표시**에서 반응 전체를 켜거나 끈다. 기본 ON이며 기기에 저장하여 재실행 후에도 유지한다.
- OFF 시 표시 중인 효과와 전달 대기 목록을 지운다. 꺼 둔 동안 받은 반응은 다시 켜도 재생하지 않으며, 늦은 자원 준비·화면 조회 응답도 차단한다. 일반 채팅과 메시지 알림은 기존 설정대로 동작한다.
- 설정 저장 실패 시 이전 값을 유지하고 오류를 안내한다. 시작 시 설정을 읽지 못하면 효과를 OFF로 보류한다. 키보드로 변경한 뒤 초점을 같은 컨트롤에 유지한다.
- 대화 영역 너비에 따른 동시 표시 상한을 4~12개에서 8~24개로 늘린다. 너비 390px에서는 10개, 600px에서는 16개, 840px 이상에서는 24개다.
- 상한에 도달하면 가장 먼저 표시된 파티클과 정리 타이머를 제거하고 유효한 새 반응을 바로 추가한다. 창을 줄이면 다음 화면 조회에서 오래된 순서대로 줄인 상한에 맞춘다.
- 이미지 준비·화면 전달 목록도 최신 24개를 유지한다. 오래된 입력을 나중에 재생하는 대기열은 만들지 않는다. 순간적인 대량 입력의 모든 반응을 표시하는 것은 보장하지 않는다.
- 600ms 화면 조회 주기는 유지한다. 같은 조회에 들어온 반응은 함께 나타날 수 있지만, 상한이 찼다는 이유로 기존 애니메이션 종료를 기다리지 않는다.
- 반응의 기록·검색·읽지 않음·알림 제외와 숨김·로비 전환·만료 검사는 유지한다. dev14의 고양이 외형·아이템·닉네임 표시도 유지한다.

## 설치와 업데이트

`BongoCatChat-0.1.0.dev15-windows-x64-Setup.exe`를 사용한다. 기존 업데이트 피드·Ed25519 공개키와 대화·초안·설정·실행기 스키마를 유지한다. dev10 이상 실행기로 시작한 설치본은 기존 입력·저장 보호 절차에 따라 자동 재시작해 적용한다. 데이터베이스 마이그레이션은 없다.

Windows Authenticode/SignPath 게시자 서명이 없는 개발판이다. 업데이트 manifest의 Ed25519 서명은 Windows 게시자 인증과 별개다.

## 검증 범위

합성 입력을 사용해 최신 24개 유지, 가장 오래된 파티클 교체, 화면 축소, 만료 후 재생 없음, 기록·초안·스크롤 보존을 검사했다. 실제 Qt Controller/QWebChannel과 Edge 제품 UI에서 교체 동작을 확인했다. 600px 영역에 300ms마다 4개씩 총 80개를 넣은 검사에서는 80개 모두 새 파티클로 반영되고 동시 최대 16개를 유지했다. 상세 범위는 [반응 파티클 검증](../reaction-particles.md#2026-10-22-연속-입력-개선)에 기록한다.

설정 추가 후 관련 회귀 테스트 242개와 Edge 검사를 통과했다. 설정 저장·SQLite 재열기·화면 재로드, 양방향 저장 실패와 재시도, OFF 중 수신·재활성화 뒤 지연 반응 차단, 키보드 조작, 390px 다크 설정 화면을 확인했다. [설정 검증 기록](../reaction-particles.md#2026-10-23-반응-효과-설정)에 실제 실행 명령과 검증 한계를 구분한다.

실사용 로비로 시험 메시지나 이모티콘을 전송하지 않았다. 실제 게임 이미지의 중첩 가독성, 실제 자연 수신과 게임 화면 대조, 순정 게임·다른 PC·장시간 사용은 미검증이다. 소스 검사·PR 병합과 최종 파일의 서명·공개 배포·설치 업데이트 검증은 각각 구분한다.
