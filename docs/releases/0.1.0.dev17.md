# Bongo Cat Chat 0.1.0.dev17 · 채팅 차단과 로비 입·퇴장 안내

Bongo Cat의 기존 로비 채팅을 별도 창에서 읽고 보내는 Windows용 서드파티 개발판입니다. 상대방은 Bongo Cat Chat을 설치하지 않아도 됩니다. 이번 버전에는 **게임의 고양이 숨김과 독립적인 Steam ID 채팅 차단(#38)**, **로비 입·퇴장 안내(#37)**가 함께 들어 있습니다.

## 처음 설치하시는 분

**[Windows 설치 파일 다운로드 — BongoCatChat-0.1.0.dev17-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev17/BongoCatChat-0.1.0.dev17-windows-x64-Setup.exe)**

필요한 환경은 **Windows 10/11 64비트(x64)**와 설치된 **Steam 및 Bongo Cat**입니다. Python, Git, 명령어 입력, 별도 게임 모드는 필요하지 않습니다. 설치는 현재 Windows 사용자에게 적용하며 관리자 권한을 요구하지 않습니다.

1. 위 링크에서 **Setup.exe 파일 하나**를 다운로드합니다. 아래 Assets의 `Source code`나 ZIP 파일을 풀어 설치할 필요는 없습니다.
2. 기존 Bongo Cat Chat이 실행 중이면 먼저 종료하고, 다운로드한 Setup.exe를 더블클릭합니다.
3. 한국어 설치 창에서 **다음**을 누르고 개인정보 안내를 읽습니다. **GitHub 업데이트 확인 및 다운로드 허용**은 선택 사항입니다. 끄더라도 Steam 채팅은 사용할 수 있으며, 나중에 앱 설정에서 변경할 수 있습니다.
4. 설치 위치를 확인하고 **설치 → 마침**을 누릅니다. 처음 설치할 때는 기본 위치를 사용하시면 됩니다. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`입니다.
5. Windows 시작 메뉴에서 **Bongo Cat Chat**을 실행합니다. **Steam에 로그인하고 Bongo Cat을 실행한 뒤, 게임에서 채팅할 로비에 참여**합니다.
6. Bongo Cat Chat의 연결 상태와 로비를 확인합니다. 입력창에 메시지를 쓰고 **Enter**로 전송하며 **Shift + Enter**로 줄을 바꿉니다. 입력 길이는 창에 표시되는 `50` 한도를 따릅니다. 이모지 등은 한 글자보다 크게 계산될 수 있습니다.

앱은 Windows 표시 언어가 한국어이면 한국어, 그 외에는 영어로 시작합니다. **설정 → 언어 / Settings → Language**에서 한국어·English·시스템 설정을 선택할 수 있습니다. 설치 프로그램은 한국어이며 앱의 언어 설정과 별개입니다.

**Windows 코드 서명(Authenticode)은 아직 적용되지 않은 개발판입니다.** Windows가 확인되지 않은 게시자나 실행 경고를 표시할 수 있습니다. 다운로드 출처와 파일명이 위 공식 저장소 링크와 일치하는지 확인해 주세요. 실행이 차단되면 보안 설정을 끄지 말고 경고 내용을 확인해 주세요. 앱의 Ed25519 업데이트 서명은 Windows 게시자 인증과 별개입니다.

## 이미 설치하신 분

- 앱의 **설정 → 앱 업데이트**에서 GitHub 통신을 허용하고 **업데이트 확인**을 누릅니다. dev16 등 자동 재시작을 지원하는 실행기는 다운로드·검증이 끝나면 30초 안내 후 재시작합니다. 입력·전송 중에는 기다리고 초안을 저장합니다.
- 자동 업데이트를 사용하지 않거나 적용되지 않으면 위 **동일한 Setup.exe**를 받습니다. Bongo Cat Chat을 종료한 뒤 **기존과 같은 설치 폴더**에 설치하면 됩니다. 먼저 제거할 필요가 없으며 기존 대화·초안·설정을 보존합니다.
- 오래된 실행기에서 다음 실행에 적용한다는 안내가 나오면 앱을 종료한 뒤 시작 메뉴에서 다시 실행합니다.

## 이번 버전에서 달라진 점

### 게임에서 고양이를 숨겨도 채팅할 수 있습니다 — #38

이제 Bongo Cat에서 다른 고양이를 숨겨도 Bongo Cat Chat에서는 해당 상대의 채팅이 보입니다. 게임 화면에 내 고양이만 표시한 상태에서도 로비 채팅을 이용할 수 있습니다.

**기존 게임 숨김 목록은 앱의 채팅 차단 목록으로 자동 이전하지 않습니다.** 이전 버전에서 게임 숨김으로 보이지 않던 상대의 채팅도 이 버전에서는 표시될 수 있습니다. 채팅을 숨기려면 Bongo Cat Chat에서 따로 차단해 주세요.

- 상단의 **참여자 목록**을 열고 상대 이름 오른쪽 **⋯ → 채팅 차단**을 선택합니다. 목록은 고양이·이름·⋯ 한 줄로 정리했고, 메뉴에서 Steam ID와 Steam 프로필 열기도 확인할 수 있습니다.
- **설정 → 채팅 차단**에서 **SteamID64**를 직접 입력하거나 차단을 해제할 수 있습니다. 상대가 현재 로비에 없어도 관리할 수 있습니다.
- 차단은 **Steam ID 기준으로 이 PC의 로그인 Steam 계정별**로 저장합니다. 상대가 닉네임을 바꾸거나 다른 로비에서 다시 만나도 유지되며 앱을 다시 실행해도 남습니다. 다른 PC로 동기화되지는 않습니다.
- 차단한 상대의 기존 대화·입퇴장 안내는 숨기고, 새 메시지·안내는 저장하지 않습니다. 알림과 고양이 반응 효과도 표시하지 않습니다. 해제하면 보관 중인 기존 기록은 다시 보이지만 **차단 중 버린 메시지와 안내는 복원하지 않습니다.**
- 채팅 차단은 내가 받는 내용에 적용합니다. **차단한 상대가 내 로비 메시지를 받지 못하게 하는 기능은 아닙니다.** Steam이나 게임의 차단·고양이 표시 설정도 변경하지 않습니다.

### 누가 들어오고 나갔는지 대화 사이에서 확인합니다 — #37

- 연결 중 관찰한 참가자 변화에 따라 **“OO님이 들어왔습니다.” / “OO님이 나갔습니다.”** 안내를 표시합니다.
- 첫 연결이나 재연결 때 이미 있는 참가자 전체를 새 입장으로 표시하지 않습니다. 연결이 끊긴 동안의 활동이나 짧은 방문은 놓칠 수 있습니다.
- 안내는 일반 메시지와 함께 로컬에 보관하지만, 로비에 채팅으로 전송하거나 Windows 알림·새 메시지 배지를 발생시키지는 않습니다. 앱의 채팅 차단 정책을 따릅니다.

## 연결이 되지 않을 때와 기록 관리

- Steam 로그인, Bongo Cat 실행, 게임의 로비 참여 상태를 먼저 확인해 주세요. 게임 업데이트 후 호환성 확인이 보류되면 앱 업데이트를 확인하고, 대응 버전이 아직 없으면 기다려 주세요. 앱은 게임을 패치하지 않습니다.
- 설치 중 실행 중인 앱 안내가 나오면 Bongo Cat Chat을 종료하고 다시 시도해 주세요. 기존 설치 위치를 바꾸려면 제거 후 새 위치에 설치해야 합니다.
- 앱이 실제 수신한 대화·초안·입퇴장 안내의 기본 보관 기간은 **30일**입니다. 앱을 꺼 둔 동안의 대화나 이전 로비 활동을 복원하지 않습니다. 차단 목록은 30일 정리나 기록 삭제로 지워지지 않으며 직접 해제해야 합니다.
- 제거는 **Windows 설정 → 앱 → 설치된 앱 → Bongo Cat Chat → 제거**에서 합니다. Windows 10에서는 **앱 및 기능**입니다. 제거해도 기록과 설정은 남습니다. 대화 기록을 지우려면 제거 전에 앱 설정에서 기록 삭제를 사용해 주세요.

## 배포 파일과 검증 범위

일반 설치에는 위 **Setup.exe만** 필요합니다. `bongo-cat-chat-windows-x64.zip`과 `update-manifest.*`는 앱 업데이트용이고, 대응 소스 ZIP·`SOURCES.md`·`THIRD-PARTY-NOTICES.txt`는 소스·라이선스 고지 자료입니다. `SHA256SUMS.txt`와 `release-approval.*`는 배포 검증 자료입니다.

기능의 합성·Qt 회귀 검사와 Windows 패키징 검증은 실제 게임 인수와 구분합니다. **순정 게임 설치·다른 PC·장시간 실행 및 이번 기능의 실제 로비 인수는 남아 있습니다.** Bongo Cat 개발사의 공식 제품이나 승인된 연동으로 소개하지 않습니다.

## English — install and start chatting

Bongo Cat Chat is a third-party Windows development app for reading and sending messages in Bongo Cat's existing lobby chat. Other players do not need to install it.

**[Download the Windows installer — BongoCatChat-0.1.0.dev17-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev17/BongoCatChat-0.1.0.dev17-windows-x64-Setup.exe)**

Requirements: **Windows 10/11, 64-bit x64**, plus installed **Steam and Bongo Cat**. No Python, Git, command-line setup, game mod, or administrator permission is needed.

1. Download the **Setup.exe** above. You do not need the source-code or update ZIP files in Assets.
2. Close any running Bongo Cat Chat window and double-click Setup.exe.
3. The installer is in Korean: **다음 = Next**, **설치 = Install**, **마침 = Finish**. Read the privacy notice. **GitHub 업데이트 확인 및 다운로드 허용** means **Allow update checks and downloads from GitHub**. This is optional and can be changed later in Settings; Steam chat works with it off.
4. Keep the default installation folder for a first installation, then choose **설치 → 마침**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Open **Bongo Cat Chat** from the Windows Start menu. Sign in to Steam, launch Bongo Cat, and **join a lobby in the game**. Check the app's connection status and lobby, then type in the message box. **Enter** sends; **Shift + Enter** adds a line. Follow the displayed `50` length limit; some characters such as emoji count as more than one unit.

The app defaults to English unless the Windows display language is Korean. Choose **Settings → Language** for English, 한국어, or System. The installer language remains Korean.

**This development installer is not Windows Authenticode-signed.** Windows may show an unknown-publisher or execution warning. Verify the official repository link and filename above; do not disable security controls to run it. Ed25519 update signatures do not provide Windows publisher certification.

### Updating an existing installation

In **Settings → App updates**, allow GitHub checks and choose **Check for updates**. Launchers with automatic restart support, including dev16, apply a verified update after a 30-second notice once typing/sending finishes and the draft is saved. If you use an older launcher that asks you to relaunch, close and reopen the app from Start.

Alternatively, close Bongo Cat Chat and run the same Setup.exe **in the existing installation folder**. No uninstall is required; existing messages, drafts, and settings are preserved.

### What's new

- **#38 — Hide cats in the game while keeping chat visible.** The game's hide list no longer filters this app. **Previously hidden players may now appear in chat; the game hide list is not imported automatically.** Open the participant list and choose **⋯ → Block chat**, or enter a SteamID64 under **Settings → Chat blocking**.
- Blocks are stored per signed-in Steam account on this PC and survive nickname changes, lobby changes, and app restarts. They do not sync to other PCs or change Steam/game settings. Old stored messages and presence notices are hidden; new blocked content is discarded without notifications or reaction effects. Unblocking restores retained history, not content discarded while blocked. **Blocked players can still receive your outgoing lobby messages.**
- **#37 — Lobby join/leave notices.** The conversation shows observed joins and departures, without broadcasting messages or triggering notifications/unread badges. Initial connections and reconnections do not announce everyone already present. Activity during disconnection or brief visits may be missed. Chat blocking also applies to these notices.

### Troubleshooting, privacy, and removal

If disconnected, check Steam sign-in, Bongo Cat, and lobby membership. If a game update is unsupported, check for an app update and wait for a compatible release. The app does not patch the game. If installation reports a running app, close Bongo Cat Chat and retry.

Received messages, drafts, and presence notices are kept locally for **30 days** by default. Chats missed while the app was closed cannot be recovered. Block lists do not expire with history. Uninstall via **Windows Settings → Apps → Installed apps** (Windows 10: **Apps & features**). Uninstalling keeps data/settings; use the app's history-deletion settings before uninstalling to remove chat history.

Only **Setup.exe** is needed for installation. Other assets contain the updater archive, source/license notices, and verification data. Synthetic/Qt/package checks do not establish clean-game, other-PC, long-running, or live-lobby acceptance for these features. This is not an official or endorsed Bongo Cat product.
