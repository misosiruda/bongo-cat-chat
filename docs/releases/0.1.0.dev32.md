# Bongo Cat Chat 0.1.0.dev32

**상자 자동 개봉 때문에 합성을 시작할 수 없을 때, 시작 버튼 바로 위에 이유와 해결 방법을 표시해요.**

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev32/BongoCatChat-0.1.0.dev32-windows-x64-Setup.exe)** · [English installation guide](#english)

## 이번 업데이트에서 바뀐 점

- 상자 자동 개봉 실행·일시 정지·결과 대기 상태가 합성을 막으면 시작 버튼 바로 위에 안내해요. 작은 창에서도 안내와 버튼이 함께 보여요.
- 상자 화면에서 **중지**한 뒤 진행 중인 개봉 결과를 확인해 주세요. **일시 정지만으로는 합성을 시작할 수 없어요.**
- 이전 합성의 완료 횟수와 종료 이유는 유지하고, 지금 시작할 수 없는 이유를 별도로 표시해요. 합성 가능 횟수도 중지·결과 확인 후 조회할 수 있다고 안내해요.
- 한국어·영어 안내를 제공해요. 차단이 풀려도 합성을 자동으로 시작하지 않아요.
- dev31의 게임 build 26538670 지원은 유지해요. 이번 수정은 앱의 상태 해석과 화면 안내이며 게임 연결 모듈·소비 명령은 바꾸지 않아요.

## 처음 설치할 때

**Windows 10/11 64비트(x64), Steam, Bongo Cat**이 필요해요. Python·개발 도구·관리자 권한은 필요하지 않아요. 받을 파일은 **`BongoCatChat-0.1.0.dev32-windows-x64-Setup.exe`** 하나예요. `Source code`는 소스이고 `bongo-cat-chat-windows-x64.zip`은 앱 업데이트용이에요.

1. 실행 중인 Bongo Cat Chat이 있으면 종료하고 Setup.exe를 실행해요.
2. **다음 → 개인정보 처리 안내 확인 → 다음**으로 진행해요.
3. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요. 해제해도 Steam 채팅과 수동 버그 제보는 사용할 수 있어요.
4. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
5. Steam에 로그인하고 Bongo Cat을 실행해 **게임 안에서 로비에 참여**해요. 시작 메뉴에서 **Bongo Cat Chat**을 실행해요.
6. 앱의 연결 상태와 로비를 확인하고 채팅해요. **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿔요.

언어는 **설정 → 언어 / Settings → Language**에서 한국어·English를 선택할 수 있어요. 상자 자동 개봉과 아이템 자동 합성은 선택 기능이에요.

## 기존 설치를 업데이트할 때

**설정 → 앱 업데이트 → 업데이트 확인**을 누르고 준비 완료 안내에 따라 앱을 다시 시작해요. GitHub 업데이트 통신을 꺼 뒀다면 켜거나, 앱을 종료하고 위 Setup.exe를 **기존 설치 폴더에** 실행해요. 먼저 제거할 필요 없이 대화·초안·설정·별명을 보존해요. 설정에서 **v0.1.0.dev32**가 표시되는지 확인해요.

자동화 진행 중이거나 결과를 기다리는 동안에는 자동 업데이트 재시작을 보류해요. 저장한 **앱 실행 시 자동 개봉 시작** 선택은 유지되므로 켜 둔 경우 앱 재실행 후 저장된 시작 동작이 적용될 수 있어요.

이번 안내 수정만을 위해 게임을 다시 시작할 필요는 없어요. 다른 연결 오류나 게임 재실행 안내가 나온다면 해당 안내를 따라 주세요.

## 문제가 계속될 때

앱 버전이 dev32인지 확인해요. 상자 화면에서 중지하고 진행 중인 결과를 확인한 뒤 합성 화면을 다시 확인해요. 계속 문제가 있으면 **앱을 닫기 전에** 상자·합성 화면의 **버그 제보**, 또는 **설정 → 문제 해결 → 버그 제보**를 눌러요.

**수집한 진단 보기**로 내용을 확인하고 **GitHub에서 제보하기**를 눌러요. 브라우저에서 로그인하고 상황을 덧붙여 **등록**해야 접수가 완료돼요. GitHub 계정이 없으면 **진단 복사**로 전달할 수 있어요. 공개 제보에는 개인 정보를 추가하지 마세요. 진단 미리보기만으로 전송하지 않으며 제보 버튼은 자동화를 시작하지 않아요. 연결 폴더·토큰·원본 로그를 공유하거나 ledger를 삭제할 필요가 없어요.

## 확인한 범위

상자 차단 상태 해석·합성 상태·상자 동작·화면·번역 관련 로컬 테스트 **155개**를 통과했어요. 최종 안내 위치와 접근성 수정 후 화면·번역 **24개**를 다시 통과했으며 두 수치는 중복돼요. 일시 정지·결과 대기·이전 완료 기록 유지·작은 창·한국어/영어·차단 해제 후 자동 시작 방지를 확인했어요. 공개 후보는 별도 Windows CI와 배포 절차를 거쳐요.

실제 상자 개봉·합성·포인트 소비, 실행 중 게임 파일 변경·모듈 교체는 수행하지 않았어요. 모의 게임과 격리 환경 검증을 실제 게임의 장시간 동작이나 다른 PC의 인수로 보지는 않아요.

[합성 사용법과 검증 근거](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev32/docs/item-auto-merge.md) · [상자 사용법](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev32/docs/auto-chest.md)

이 개발판은 Windows **Authenticode 미서명**이에요. 공식 GitHub 릴리스에서 받은 파일인지 확인해요. 자동 업데이트는 별도 Ed25519 서명을 검증해요. 받은 대화는 기본 30일간 이 PC에 저장되며 앱 제거 후에도 기록과 설정은 남아요. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev32/docs/privacy-policy.md)

## English

**dev32 explains why chest automation prevents merging, directly above the Start button.**

**[Download BongoCatChat-0.1.0.dev32-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev32/BongoCatChat-0.1.0.dev32-windows-x64-Setup.exe)**

### What changed

A notice explains chest-related blocks while automation is running, paused or awaiting a result. Stop it in the chest panel and confirm pending results; **pausing alone does not release the block**. Previous merge completion counts and stop reasons remain visible, with the current start restriction shown separately. The notice stays with the disabled button even in a small window, in Korean or English. Releasing the block never starts merging automatically.

Game build 26538670 support from dev31 remains. This update changes app-side state interpretation and guidance, without changing the game bridge or consumption commands.

### First installation

You need **Windows 10/11 x64, Steam and Bongo Cat**. Python, developer tools and administrator privileges are not required. Download only Setup.exe above; `Source code` is source, and `bongo-cat-chat-windows-x64.zip` is for the app updater.

1. Close any running Bongo Cat Chat and launch Setup.exe.
2. The installer is in Korean. Choose **다음 (Next)**, read the privacy notice, then choose **다음 (Next)**.
3. Choose whether to allow **GitHub 업데이트 확인 및 다운로드 허용 (GitHub update checks and downloads)**. Chat and manual bug reporting still work if this is disabled.
4. Confirm the install folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**. Open **Bongo Cat Chat** from the Start menu.
6. Check the connection and lobby, then chat. **Enter** sends; **Shift + Enter** inserts a line break. Select English in **설정 → 언어 / Settings → Language** if needed.

### Updating

Use **Settings → App updates → Check for updates** and follow the app restart prompt. If GitHub update access is disabled, enable it or close the app and run Setup.exe into the **existing install folder**. There is no need to uninstall first; history, drafts, preferences and nicknames are preserved. Confirm **v0.1.0.dev32** in Settings.

Active automation and pending results postpone automatic update restart. Saved **Start automatic chest opening when the app launches** consent remains enabled if you previously selected it, and may start the configured automation after relaunch.

This guidance-only update does not itself require restarting the game. Follow the specific guidance for any separate connection error or game-restart request.

### If the problem persists

Confirm dev32 is installed. Stop chest automation and confirm pending results, then check the merge panel again. Before closing the app, choose **Report a bug** in the chest/merge panel or **Settings → Troubleshooting**. Review **View collected diagnostics**, then choose **Report on GitHub**, sign in and submit the issue. Opening the browser alone does not submit it. Without a GitHub account, use **Copy diagnostics**.

Issues are public; do not add personal information. Previewing alone does not send diagnostics. Reporting does not start automation. Do not share connection folders, tokens or raw logs, or delete ledgers to bypass safeguards.
