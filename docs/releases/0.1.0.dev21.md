# Bongo Cat Chat 0.1.0.dev21

Bongo Cat의 **게임 로비 채팅을 별도 메신저 창에서 읽고 보내는 Windows 앱**입니다. 상대방은 이 앱을 설치하지 않아도 됩니다. 앱을 실행한 동안 받은 대화는 내 PC에 보관합니다.

### [⬇ BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev21/BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe)

## 처음 설치하는 분

### 1. 준비하기

- **Windows 10 또는 Windows 11, 64비트(x64) PC**가 필요합니다. macOS·Linux·Windows ARM용 배포판은 제공하지 않습니다.
- **Steam과 Bongo Cat 게임**이 설치되어 있어야 합니다. 채팅할 때는 Steam에 로그인하고 게임을 실행해야 합니다.
- Python, Git, 개발 도구, 명령어 입력은 필요하지 않습니다. 현재 Windows 사용자에게 설치하며 관리자 권한을 요구하지 않습니다.
- **채팅을 위해 별도 게임 모드를 설치할 필요는 없습니다.** 선택 기능인 아이템 자동 합성의 지원 조건은 아래에서 따로 안내합니다.

### 2. 설치하기

1. 위 **Setup.exe 다운로드** 링크를 눌러 파일을 저장합니다. 저장 위치를 따로 선택하지 않았다면 보통 **다운로드** 폴더에 있습니다.
2. 다운로드한 **BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe**를 더블클릭합니다. 기존 Bongo Cat Chat이 열려 있다면 앱을 먼저 닫아 주세요.
3. 설치 시작 화면에서 **다음**을 누르고, **개인정보 처리 안내**를 읽은 뒤 **다음**을 누릅니다.
4. **GitHub 업데이트 확인 및 다운로드 허용**을 선택합니다. 켜면 새 버전을 확인하고 내려받습니다. 꺼도 Steam 채팅은 사용할 수 있지만 자동·수동 업데이트 확인이 모두 꺼집니다. 나중에 앱 설정에서 바꿀 수 있습니다.
5. 처음 설치한다면 표시된 **기본 설치 폴더를 그대로 두고 설치**를 누릅니다. 기본 위치는 **%LOCALAPPDATA%\Programs\BongoCatChat**이며 이 경로를 직접 입력할 필요는 없습니다.
6. 설치 완료 화면에서 **마침**을 누릅니다. 이후 **Windows 시작 메뉴에서 Bongo Cat Chat을 검색해 실행**합니다. 설치가 끝났다고 게임이나 메신저가 자동으로 실행되는 것은 아닙니다.

**Windows 실행 경고가 뜨면:** 이 개발판은 Windows 게시자 코드 서명(Authenticode)이 없어 확인되지 않은 게시자 등의 경고가 나올 수 있습니다. 위 공식 GitHub 링크에서 받은 파일인지 확인하세요. 실행이 차단되면 보안 설정을 끄거나 백신 예외를 추가하지 말고, 정확한 경고 문구와 함께 [문제를 제보](https://github.com/misosiruda/bongo-cat-chat/issues)해 주세요. 자동 업데이트 서명과 Windows 게시자 인증은 별개입니다.

### 3. 게임에 연결하고 채팅하기

1. **Steam에 로그인**하고 **Bongo Cat 게임을 실행**합니다.
2. **게임 안에서 채팅할 로비에 참여**합니다. 이 앱이 대신 로비에 들어가지는 않습니다.
3. 시작 메뉴에서 **Bongo Cat Chat**을 실행하고 연결을 기다립니다.
4. 앱에 **현재 로비 이름·참여자와 채팅 입력창**이 표시되는지 확인합니다. 연결이 확인되면 입력창을 사용할 수 있습니다.
5. 메시지를 입력하고 **Enter**로 보냅니다. 줄바꿈은 **Shift + Enter**입니다. 입력창의 **50자 한도**를 따르며 이모지는 여러 글자로 계산될 수 있습니다.

앱을 켜기 전이나 꺼 둔 동안의 대화는 불러오지 못합니다. 메시지를 전송했다고 상대방의 열람까지 확인되는 것은 아닙니다.

**언어 변경:** 앱의 **설정 → 언어 / Settings → Language**에서 한국어·English·시스템 설정을 고를 수 있습니다. 처음에는 Windows 표시 언어가 한국어면 한국어, 그 외에는 영어로 시작합니다. 설치 프로그램은 한국어입니다.

## 이미 설치한 분: dev21로 업데이트하기

**방법 A — 앱에서 업데이트**

1. **설정 → 앱 업데이트**를 엽니다. 창이 좁으면 사이드바를 열어 설정을 찾고, 설정창을 아래로 스크롤합니다.
2. **GitHub 업데이트 확인 및 다운로드 허용**을 켠 뒤 **업데이트 확인**을 누릅니다.
3. 다운로드와 검증이 끝날 때까지 기다립니다. 자동 재시작을 지원하는 실행기는 30초 안내 후 앱을 재시작합니다. 입력·전송 중에는 기다리고 초안을 저장합니다. 자동 합성이 진행 중이면 재시작이 보류될 수 있습니다.
4. 다시 실행한 앱의 **설정 → 앱 업데이트**에 **v0.1.0.dev21**이 표시되는지 확인합니다. 다음 실행에 적용한다는 안내가 나오면 앱을 정상 종료한 뒤 시작 메뉴에서 다시 실행하세요.

**방법 B — 설치 파일로 업데이트**

위의 **동일한 Setup.exe**를 다운로드하고 Bongo Cat Chat을 종료한 뒤, **기존과 같은 폴더**에 설치합니다. 먼저 제거할 필요는 없습니다. 기존 대화·초안·설정은 보존합니다. 설치 프로그램이 앱이 실행 중이라고 안내하면 앱을 닫고 다시 실행하세요.

## 이번 버전에서 달라진 점

**Bongo Cat 게임 빌드 26364842 업데이트 후 채팅과 아이템 자동 합성이 연결되지 않던 문제를 수정했습니다.** 기존 dev20에서 게임 호환성을 확인하지 못한다는 안내가 나왔다면 dev21로 업데이트해 주세요.

새 게임의 채팅·반응·로비 관련 동작을 확인해 지원을 추가하고 자동 합성 연결 준비에 필요한 참조를 보완했습니다. 확인하지 않은 게임 파일이나 서로 다른 빌드의 파일이 섞인 경우에는 계속 연결을 보류합니다. 이후 게임 업데이트까지 무조건 지원하는 것은 아닙니다.

## 아이템 자동 합성 사용하기 — 선택 기능

**채팅만 이용한다면 이 단계는 건너뛰어도 됩니다.** 자동 합성은 확인된 게임 파일 조합에서만 연결되며, 모든 순정 설치나 다른 모드 조합의 지원이 검증된 것은 아닙니다.

1. 게임의 **수동 합성 화면을 닫고**, 앱 사이드바에서 **아이템 자동 합성 → 게임에 연결**을 누릅니다.
2. **캐릭터·모자·봉고** 또는 **이모티콘·UI 테마** 중 합성할 그룹을 고릅니다.
3. 실행 상한을 입력하거나 **최대값으로 설정**을 누릅니다. **연결·그룹 선택·최대값 설정만으로 아이템을 소비하지 않습니다.**
4. 내용을 확인하고 **자동 합성 시작**을 누르면 합성을 시작합니다. 원본 중복 선택으로 종류별 1개를 남기고, 재료 10개로 한 번씩 합성하며 결과를 확인한 뒤 다음 합성을 요청합니다.
5. **중지**를 누르면 다음 합성 요청을 막습니다. 이미 접수된 합성은 취소할 수 없습니다. 패널을 닫는 것만으로는 중지되지 않습니다.

즐겨찾기 포함·이벤트 아이템 제외는 게임의 현재 설정을 따릅니다. 앱을 다시 실행하거나 재연결하는 것만으로 합성을 자동 재개하지 않습니다. 결과가 불명확하면 자동 재시도하지 않습니다.

자동 합성은 명시적으로 연결할 때 자체 모듈을 실행 중인 게임에 로드합니다. 게임 설치 파일이나 기존 Auto Chest를 수정하지 않습니다. 이전 연결 모듈 때문에 재연결 안내가 나오면 게임을 직접 다시 실행해야 할 수 있습니다. 앱이 게임을 종료하거나 재시작하지는 않습니다. [자세한 지원 범위](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev21/docs/game-update-2026-11-02.md)

## English

Bongo Cat Chat is a **Windows messenger for Bongo Cat's existing in-game lobby chat**. Other players do not need this app. It saves messages received while the app is running on your PC.

### [⬇ Download the Windows installer — BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev21/BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe)

**Download this one Setup.exe file to install or update the app** (about 208MB). You can also find that exact filename under **Assets**. You do not need a ZIP, source code, Python, Git, a terminal, or administrator access.

### First installation

**Requirements:** Windows 10 or 11 **64-bit x64**, installed **Steam**, and **Bongo Cat**. This release does not provide macOS, Linux, or Windows ARM builds. A separate game mod is not required for chat; the optional Auto merge feature has additional compatibility restrictions.

1. Download **Setup.exe** above. If your browser did not ask where to save it, check your **Downloads** folder.
2. Double-click **BongoCatChat-0.1.0.dev21-windows-x64-Setup.exe**. Close any running Bongo Cat Chat window first.
3. The installer is in Korean. Click **다음 = Next**, read the privacy notice, and click **다음** again.
4. Choose whether to allow GitHub updates. **GitHub 업데이트 확인 및 다운로드 허용** means **Allow update checks and downloads from GitHub**. Unchecking it keeps Steam chat available but disables both automatic and manual update checks. You can change it later in Settings.
5. For a first installation, keep the default folder and click **설치 = Install**, then **마침 = Finish**. The default is **%LOCALAPPDATA%\Programs\BongoCatChat**; you do not need to type this path.
6. Open the **Windows Start menu**, search for **Bongo Cat Chat**, and launch it. Setup does not automatically start the game or messenger. You do not need to open the installer each time you use the app.

**Windows warnings:** This development installer is not Authenticode-signed, so Windows may show an unknown-publisher or execution warning. First verify that the file came from the official GitHub link above. If execution is blocked, do not disable protection or add an antivirus exception. [Report the exact warning](https://github.com/misosiruda/bongo-cat-chat/issues). The app's update signature does not provide Windows publisher certification.

### Connect and send your first message

1. **Sign in to Steam** and **launch Bongo Cat**.
2. **Join a lobby inside the game.** This app does not join a lobby for you.
3. Open **Bongo Cat Chat** from the Start menu and wait for the connection.
4. Check that the app shows your current lobby, participants, and an enabled message input.
5. Type a message and press **Enter** to send. **Shift + Enter** adds a line. Follow the displayed **50-character limit**; emoji may count as more than one unit.

The app cannot retrieve messages from before it was connected or while it was closed. Sending a message does not confirm that another player has read it.

The app starts in Korean when the Windows display language is Korean, and in English otherwise. Choose **Settings → Language** for English, 한국어, or System. The installer remains Korean.

### Update an existing installation

**In the app:** Open **Settings → App updates**. On a narrow window, open the sidebar to find Settings, then scroll down inside the settings dialog. Enable GitHub update checks and select **Check for updates**. Wait for download and verification. Supported launchers restart after a 30-second notice, waiting for typing/sending and saving your draft; an active Auto merge run may defer the restart. Confirm **v0.1.0.dev21** in App updates afterwards. If the app says the update applies on the next launch, close it normally and reopen it from the Start menu.

**With the installer:** Download the **same Setup.exe** above, close Bongo Cat Chat, and install into the **existing folder**. Uninstalling first is unnecessary; conversations, drafts, and settings are preserved. If Setup says the app is running, close the app and run Setup again.

### Optional: Auto merge items

**Skip this section if you only want chat.** Auto merge accepts inspected game file combinations; support for every clean installation or other mod combination has not been verified.

1. Close the game's manual merge screen. In the app sidebar, choose **Auto merge items → Connect to game**.
2. Select **Characters / hats / bongos** or **Emotes / UI themes**.
3. Enter a limit or choose **Set to maximum**. **Connecting, choosing a group, and setting a maximum do not consume items.**
4. Select **Start auto merge** to begin. It uses the original duplicate selector, preserves one per type, consumes ten materials for one exchange, and confirms its result before requesting the next exchange.
5. **Stop** prevents the next request; it cannot cancel an accepted exchange. Closing the panel does not stop a run.

Favorite/event protection follows the game's current settings. Reopening or reconnecting never starts a run automatically. Unknown outcomes are not retried. Explicit connection loads an app-owned module into the running game without changing installed game files or Auto Chest. A previous module may require you to restart the game yourself before reconnecting; the app does not restart the game. ### Troubleshooting, records, and removal

- **Cannot find the app:** Search for **Bongo Cat Chat** in the Windows Start menu.
- **Waiting for a connection:** Check Steam sign-in, the running Bongo Cat game, and in-game lobby membership, then refresh the app's connection status.
- **Compatibility error:** Check that the app is **dev21**. A newer game update or a different file set may need another app update. Report the exact message.
- **Only Auto merge fails:** Its compatibility requirements differ from chat. Close the manual merge screen and check the error. Do not repeatedly press Start to resolve a connection failure.
- **Update check fails:** Enable GitHub checks in Settings, or use Setup.exe to update the existing folder.
- **Reporting a problem:** Include the app version, Windows version, exact error, and the step that failed. Do not post chat contents, Steam IDs, or lobby entry codes. [Report an issue](https://github.com/misosiruda/bongo-cat-chat/issues).

Received conversations, drafts, and join/leave notices are kept locally for **30 days** by default. Offline or discarded messages cannot be recovered. In-game cat visibility and app chat blocking are separate; use the participant menu or **Settings → Chat blocking** to hide chat.

Uninstall through **Windows Settings → Apps → Installed apps → Bongo Cat Chat → Uninstall**; Windows 10 calls the page **Apps & features**. Records and settings remain after uninstalling. Use the app's history deletion controls before uninstalling if you want to delete conversation records.
