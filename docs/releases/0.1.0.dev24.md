# Bongo Cat Chat 0.1.0.dev24

Bongo Cat의 게임 로비 채팅을 별도 창에서 읽고 보내는 Windows 앱입니다. **dev24에서는 다른 고양이에게 나만 보는 별명을 붙일 수 있습니다.** 상대방은 앱을 설치할 필요가 없습니다.

**[Windows 설치 파일 다운로드 · BongoCatChat-0.1.0.dev24-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev24/BongoCatChat-0.1.0.dev24-windows-x64-Setup.exe)**

처음 설치하거나 직접 업데이트할 때는 이 파일 하나만 받으세요. GitHub의 **Assets**에도 같은 이름으로 표시됩니다. [English instructions](#english)

## 처음 설치하고 로비에 연결하기

1. **Windows 10 또는 11 64비트(x64)** PC에 Steam과 Bongo Cat을 준비하세요. Python이나 Git은 필요 없습니다.
2. 위 설치 파일을 내려받아 **다운로드** 폴더에서 더블클릭하세요. 앱이 이미 열려 있다면 먼저 닫으세요.
3. **다음 → 개인정보 처리 안내 → 다음**을 누릅니다. **GitHub 업데이트 확인 및 다운로드 허용**을 켜면 이후 앱에서 업데이트를 받을 수 있습니다. 이 선택은 앱 설정에서 바꿀 수 있습니다.
4. 기본 폴더에 **설치 → 마침**을 누르세요. **Steam 로그인 → Bongo Cat 실행 → 게임 안에서 로비 참여** 후 Windows 시작 메뉴에서 **Bongo Cat Chat**을 실행합니다.
5. 앱에 현재 로비 이름과 참여자 수가 표시되면 연결된 것입니다. 입력창이 활성화되면 **Enter**로 보내고 **Shift + Enter**로 줄을 바꿉니다. **설정 → 언어**에서 한국어와 English를 고를 수 있습니다.

## 상대에게 별명 붙이기

채팅창 상단의 **참여자 수 → 상대방 옆 ⋯ → 별명 설정**을 누르세요. 동명이인은 편집창의 게임 이름과 Steam ID로 구분할 수 있습니다. 원하는 별명을 **32자 이내**로 입력하고 **저장**하면 내 화면의 참여자 목록, 기존 대화와 검색 결과, 입·퇴장 안내, 반응 이름표에 반영됩니다.

별명은 **이 PC의 내 Steam 계정**에 저장됩니다. 상대가 게임 이름을 바꾸거나 다른 로비에서 다시 만나도 같은 Steam ID로 기억합니다. 게임과 상대방의 화면에는 원래 이름이 표시됩니다. 별명을 바꾸려면 같은 메뉴를 열고, 원래 이름으로 돌아가려면 입력란을 비우고 저장하세요.

## 기존 사용자가 업데이트하는 방법

- **앱에서 업데이트**하려면 **설정 → 앱 업데이트**에서 GitHub 업데이트를 허용하고 **업데이트 확인**을 누르세요. 다운로드와 검증이 끝나면 앱의 재시작 안내를 따릅니다. 별명 편집 중이면 창을 닫은 뒤 카운트다운이 시작됩니다. 적용 후 설정에서 **v0.1.0.dev24**를 확인하세요.
- **설치 파일로 업데이트**하려면 Bongo Cat Chat을 닫고 위 Setup.exe를 기존 설치 폴더에 실행하세요. 대화·초안·설정은 보존됩니다. dev23에서 별명을 사용하기 위해 게임을 다시 시작할 필요는 없습니다.

## 연결 문제와 로컬 기록

- **로비가 보이지 않으면** Steam 로그인, 게임 실행, 게임 안의 로비 참여를 확인한 뒤 앱에서 연결 상태를 새로고침하세요. **별명 설정**은 현재 참여자 목록에서 다른 사람의 메뉴를 열어야 나타납니다.
- **Windows에서 게시자를 확인할 수 없다고 나오면** 위 GitHub 릴리스에서 받은 파일인지 확인하세요. 이 개발판의 Windows 설치 파일은 Authenticode 미서명입니다. 앱은 자동 업데이트를 적용하기 전에 별도의 Ed25519 서명을 확인합니다.
- **기록을 정리하려면** 앱 설정에서 로비 또는 계정 대화를 삭제하세요. 받은 대화는 기본 30일간 보관하고, 별명은 직접 지울 때까지 기억합니다. Windows **설정 → 앱 → 설치된 앱**에서 Bongo Cat Chat을 제거할 수 있습니다. 제거 후에도 로컬 기록과 설정이 남습니다. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev24/docs/privacy-policy.md)
- 문제가 계속되면 버전, Windows 버전, 실패한 단계와 오류 문구를 알려 주세요. 대화 원문·Steam ID·로비 코드는 제외해 주세요. [문제 제보](https://github.com/misosiruda/bongo-cat-chat/issues)

아이템 자동 합성과 상자 자동 개봉은 선택 기능입니다. 별명을 쓰는 데 두 기능의 연결이나 시작은 필요 없습니다. [자동 합성 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev24/docs/item-auto-merge.md) · [상자 자동 개봉 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev24/docs/auto-chest.md)

## English

Bongo Cat Chat lets you read and send Bongo Cat lobby messages in a separate Windows window. **dev24 adds private nicknames for other players.** Other players can use the game as usual.

**[Download the Windows installer · BongoCatChat-0.1.0.dev24-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev24/BongoCatChat-0.1.0.dev24-windows-x64-Setup.exe)**

Download just this Setup.exe to install or update. You can also find it under **Assets**.

### Install and connect

1. Use a **Windows 10 or 11 x64** PC with Steam and Bongo Cat installed. No developer tools are required.
2. Open the installer from **Downloads**. Close Bongo Cat Chat first if it is running. The installer is in Korean. Select **다음 (Next)**, read the privacy notice and select **다음** again.
3. Choose whether to allow update checks and downloads from GitHub. Keep the default folder, then select **설치 (Install) → 마침 (Finish)**.
4. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**. Open **Bongo Cat Chat** from the Windows Start menu. Wait for the lobby name and participant count. When the message field is enabled, press **Enter** to send or **Shift + Enter** for a new line. Choose English or Korean under **Settings → Language**.

### Set a private nickname

Select the **participant count → ⋯ beside another player → Set nickname**. Check the in-game name and Steam ID, enter up to **32 characters**, and select **Save**. The nickname appears in your participant list, chat history, search results, join/leave notices and reaction labels. It stays with that Steam ID across lobbies, restarts and changes to the player's in-game name. Only your Steam account on this PC sees it. Open the same menu to edit it, or clear the field and save to restore the original name.

### Update or troubleshoot

- In **Settings → App updates**, enable GitHub update checks and select **Check for updates**. Follow the restart prompt after verification and confirm **v0.1.0.dev24**. You can also close the app and run the installer into the existing folder to keep your history, drafts and settings. Upgrading from dev23 for nicknames does not require a game restart.
- If the lobby is missing, check Steam sign-in and in-game lobby membership, then refresh the connection. Open the menu for another current participant to see **Set nickname**.
- This development installer is **not Windows Authenticode-signed**. If Windows shows an unknown-publisher warning, verify that the file came from the GitHub release linked above. The app verifies automatic updates with a separate Ed25519 signature.
- Received chat is kept locally for 30 days by default. Use Settings to delete chat history and **Set nickname** to remove a saved nickname. Uninstall from **Windows Settings → Apps → Installed apps**. Uninstalling preserves local data. [Privacy policy](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev24/docs/privacy-policy.en.md)

The nickname tests use synthetic players and an offline app window. Live-lobby and other-PC acceptance for nicknames are still pending.
