# Bongo Cat Chat 0.1.0.dev27

**상자·합성 연결 실패의 원인과 다음 조치를 구분해 안내해요.** 게임 응답이 늦으면 기존 연결을 잠시 다시 확인하고, 폴더·권한·연결 기록·모듈 검사 오류를 모두 게임 재실행으로 안내하던 문제를 수정했어요.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev27/BongoCatChat-0.1.0.dev27-windows-x64-Setup.exe)** · [English installation guide](#english)

## 처음 설치할 때

- **Windows 10/11 64비트(x64), Steam, Bongo Cat**이 필요해요. Python·개발 도구·관리자 권한은 필요하지 않아요.
- 다운로드할 파일은 **`BongoCatChat-0.1.0.dev27-windows-x64-Setup.exe`** 하나예요. `Source code` ZIP은 소스이고, `bongo-cat-chat-windows-x64.zip`은 앱 업데이트용이에요.

1. 실행 중인 Bongo Cat Chat이 있으면 종료하고 Setup.exe를 실행해요.
2. **다음 → 개인정보 처리 안내 확인 → 다음**으로 진행해요.
3. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요. 해제해도 Steam 채팅은 사용할 수 있어요.
4. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
5. Steam에 로그인하고 Bongo Cat을 실행해 **게임 안에서 로비에 참여**해요. 시작 메뉴에서 **Bongo Cat Chat**을 실행해요.
6. 앱의 연결 상태와 로비를 확인하고 채팅해요. **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿔요.

앱 언어는 **설정 → 언어 / Settings → Language**에서 한국어·English를 선택할 수 있어요. 설치 마법사는 한국어로 표시돼요. 상자 자동 개봉과 아이템 자동 합성은 선택 기능이며 채팅을 쓰기 위한 필수 설정이 아니에요.

## 기존 설치를 업데이트할 때

**설정 → 앱 업데이트 → 업데이트 확인**을 누르고 준비 완료 안내에 따라 앱을 다시 시작해요. GitHub 업데이트 통신을 꺼 뒀다면 켜거나, 앱을 종료하고 위 Setup.exe를 **기존 설치 폴더에** 실행해요. 먼저 제거할 필요 없이 대화·초안·설정·별명을 보존해요. 적용 후 설정에 **v0.1.0.dev27**이 표시되는지 확인해요.

자동화 진행 중이거나 결과를 기다리는 동안에는 앱의 자동 업데이트 재시작을 보류해요. 저장한 **앱 실행 시 자동 개봉 시작** 설정은 유지되며, 켜 둔 경우 앱을 다시 열면 저장된 시작 동작이 적용될 수 있어요.

**dev26에서 업데이트했다는 이유만으로 게임을 다시 실행할 필요는 없어요.** 이번 변경은 앱의 연결 확인·오류 분류와 안내이며 게임 내부 모듈 코드는 바꾸지 않았어요. 이전 모듈이 종료됐거나 호환되지 않는 경우, 초기화·중지 결과가 미확인인 경우에는 화면 안내에 따라 결과를 확인하고 게임과 앱을 **한 번 완전히 종료**한 뒤 다시 연결해요. 같은 오류가 반복되면 재실행을 반복하지 말고 앱 버전·안내 문구·오류 코드를 알려 주세요.

## 연결되지 않을 때

| 표시되는 상황 | 확인할 내용 |
| --- | --- |
| 게임 응답 지연 | 게임이 최소화돼 있다면 창을 표시하고 잠시 후 **게임에 연결**을 다시 눌러요. 최소화가 모든 실패의 원인이라는 뜻은 아니에요. |
| 폴더·파일 접근 거부 또는 디스크 공간 부족 | 현재 Windows 계정의 폴더 권한이나 사용자 폴더가 있는 드라이브의 여유 공간을 확인해요. 게임 재실행으로 안내하지 않아요. |
| 다른 앱이 이미 연결 중 | 중복 실행한 채팅 앱을 닫고 다시 연결해요. |
| 미지원 경로·모듈 검사 실패·기록/응답 형식 오류 | 개발 확인이 필요한 오류예요. 앱 버전·안내 문구·오류 코드를 알려 주세요. |
| 이미 요청한 개봉 결과 미확인 | 게임에서 결과를 먼저 확인해요. 앱은 같은 소비 요청을 다시 보내지 않아요. |

연결 기록 폴더나 `session.json` 전체를 공유할 필요는 없어요. 연결 토큰·대화 원문·Steam ID·로비 코드는 제보에서 제외해 주세요. 기록이나 ledger를 삭제해 연결 제한을 해제하지 않아요.

## 변경 내용과 확인 범위

- 기존 연결의 응답을 최대 5초 다시 확인해, 응답이 잠시 늦었다는 이유만으로 곧바로 재실행 안내로 넘어가지 않게 했어요.
- 저장 경로·권한·공간·기록 충돌·모듈 검사·연결 호환성·응답 오류를 구분하고, 상자와 합성 화면에 같은 설명과 오류 코드를 표시해요.
- 사용자가 확인할 환경 문제와 개발 확인이 필요한 문제를 나눴어요. 재실행이 필요한 경우에는 한 번 조치한 뒤 반복되면 제보하도록 안내해요.
- 모의 게임·파일 IPC·Windows bootstrap·Qt 화면으로 연결, 소비 보호, 오류 안내를 검증했어요. 실제 상자 개봉·아이템 합성·포인트 소비 시험이나 사용 중인 게임/설치 변경은 하지 않았어요.

제보 사용자 PC의 실제 원인은 아직 확정하지 않았어요. 최초 연결의 렌더링 의존 제거, 링크 경로 지원, 실제 최소화·장시간 사용 검증은 별도 작업이에요. [사용자 조치와 개발 항목](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev27/docs/auto-chest.md#사용자-조치와-개발에서-해결할-항목) · [검증 기록](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev27/docs/product-validation.md)

이 개발판은 Windows **Authenticode 미서명**이에요. 공식 GitHub 릴리스에서 받은 파일인지 확인해요. 자동 업데이트는 별도 Ed25519 서명을 검증해요. 받은 대화는 기본 30일간 이 PC에 저장되며 앱 제거 후에도 기록과 설정은 남아요. [개인정보 안내](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev27/docs/privacy-policy.md)

## English

**dev27 distinguishes chest/merge connection failures and explains the appropriate next step.** Delayed responses are checked again, and storage, permission, record and module inspection errors no longer all request a game restart.

**[Download BongoCatChat-0.1.0.dev27-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev27/BongoCatChat-0.1.0.dev27-windows-x64-Setup.exe)**

### First installation

You need **Windows 10/11 x64, Steam and Bongo Cat**. Python, developer tools and administrator privileges are not required. Download only the Setup.exe above; the source ZIP is source code, and `bongo-cat-chat-windows-x64.zip` is for the app updater.

1. Close any running Bongo Cat Chat and launch Setup.exe.
2. The installer is in Korean. Choose **다음 (Next)**, read the privacy notice, then choose **다음 (Next)**.
3. Choose whether to allow **GitHub 업데이트 확인 및 다운로드 허용 (GitHub update checks and downloads)**. Chat still works if you turn this off.
4. Confirm the install folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**. Open **Bongo Cat Chat** from the Start menu.
6. Check the connection and lobby in the app, then chat. **Enter** sends; **Shift + Enter** inserts a line break. Choose English in **설정 → 언어 / Settings → Language** if needed.

Automatic chest opening and item merging are optional. They are not required to use chat.

### Updating an existing installation

Use **Settings → App updates → Check for updates**, then follow the app restart prompt. If GitHub update access is disabled, enable it or close the app and run Setup.exe into the **existing install folder**. Uninstalling first is unnecessary. History, drafts, preferences and nicknames are preserved. Confirm **v0.1.0.dev27** in Settings.

Active automation or pending/unverified results postpone automatic update restart. Saved **Start automatic chest opening when the app launches** consent is preserved and may start the configured automation when the app relaunches.

**Updating from dev26 alone does not require restarting the game.** This release changes the app's connection checks, error classification and messages; the in-game module source is unchanged. A stopped/incompatible older module or unconfirmed initialization/stop may still require checking pending results and fully closing the game and app **once**. If the same error returns, report the app version, message and error code instead of repeating restarts.

### Connection troubleshooting

- **Delayed game response:** If the game is minimized, restore it, wait briefly and choose **Connect to game** again. Minimization is not a confirmed cause of every failure.
- **Storage access denied or disk full:** Check the current Windows account's folder permissions or free space on the user-folder drive.
- **Another app is connected:** Close duplicate chat app instances and reconnect.
- **Unsupported paths, module inspection or malformed records/responses:** These need developer investigation. Report the app version, message and error code.
- **Unverified chest opening result:** Check the result in the game first. The app does not resend the consumption request.

Do not share the entire connection folder or `session.json`; it contains a connection token. Exclude chat text, Steam IDs and lobby codes from reports. Do not delete records or ledgers to bypass a connection guard.

Validation uses mock game/IPC, Windows bootstrap and Qt UI tests. No real items, chests or points were consumed, and running game/user installations were not modified. The reported user's root cause remains unconfirmed. Removing the initial render dependency, supporting linked paths and live minimized-window/endurance acceptance remain separate work.
