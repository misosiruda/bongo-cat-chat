# Bongo Cat Chat 0.1.0.dev33

**내 상자 개봉 응답이 늦어도 자동 개봉이 계속돼요.** 응답을 30초 넘게 기다리면 **개봉 응답 지연**이 표시돼요. 게임이 성공이나 실패를 알려 주면 다음에 준비된 상자를 자동으로 열어요. 다시 시작을 누를 필요가 없어요.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev33/BongoCatChat-0.1.0.dev33-windows-x64-Setup.exe)** · [English installation guide](#english)

## 기존 설치를 업데이트할 때

1. 상자나 합성을 사용 중이면 중지하고 진행 중인 요청의 결과를 게임에서 확인해요. dev32에서 이미 **개봉 결과 확인 필요**가 떴다면 이 단계에서 결과를 확인해요.
2. 상자 또는 합성으로 게임에 연결했던 경우 **Bongo Cat과 Bongo Cat Chat을 모두 한 번 완전히 종료**해요. 새 게임 실행에서 dev33의 연결 모듈을 사용할 수 있어요.
3. 위 설치 파일을 기존 설치 폴더에 실행해요. 대화·초안·설정·별명은 보존돼요. 앱 업데이트를 사용한다면 **설정 → 앱 업데이트 → 업데이트 확인**에서 받아도 돼요. 개봉이 진행 중이거나 결과가 미확인인 동안에는 앱의 자동 재시작이 보류돼요.
4. Bongo Cat을 실행하고 로비에 참여한 뒤 시작 메뉴에서 Bongo Cat Chat을 열어요. 설정에서 **v0.1.0.dev33**을 확인해요. 저장해 둔 **앱 실행 시 자동 개봉 시작**과 상자 종류·대기 시간이 적용돼요. 기존 도우미가 감지되면 전환 안내를 따라요.

## 처음 설치할 때

Windows 10/11 x64, Steam과 Bongo Cat이 필요해요. **`BongoCatChat-0.1.0.dev33-windows-x64-Setup.exe`** 한 개를 받으세요. 업데이트용 ZIP은 앱이 사용해요.

1. Setup.exe를 실행해 **다음**을 누르고 개인정보 안내를 읽어요. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요.
2. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
3. Steam에 로그인하고 Bongo Cat에서 로비에 참여해요. 시작 메뉴에서 Bongo Cat Chat을 열고 연결된 로비를 확인해요. **Enter**로 채팅을 보내고 **Shift + Enter**로 줄을 바꿔요.
4. 상자 자동 개봉을 사용하려면 사이드바에서 **상자 자동 개봉**을 열고 상자 종류·대기 시간을 저장한 뒤 게임에 연결해 시작해요. 다른 사람의 상자를 열면 내 포인트가 사용돼요. 아이템 자동 합성은 별도 선택 기능이에요.

## 응답을 기다리는 동안

같은 개봉을 다시 요청하지 않아요. 응답이 오기 전에 직접 **중지**하면 늦게 도착한 결과만 기록해요. **개봉 결과 확인 필요**가 표시되면 게임에서 결과를 확인해요. 결과 처리나 기록에 실패한 경우에는 자동 개봉을 중단해요. 이 상태가 반복되면 앱을 닫기 전에 **버그 제보 → 수집한 진단 보기**에서 확인한 내용을 복사하거나 GitHub에 등록할 수 있어요.

모의 게임에서 121초 늦은 실패 응답과 늦은 성공 응답 뒤 다음 상자를 여는 동작, 중복 응답 무시, 수동 중지를 확인했어요. 실제 게임의 장시간 개봉과 포인트 소비 시험은 수행하지 않았어요. Windows 설치 파일은 Authenticode 미서명 개발판이며 앱은 자동 업데이트의 Ed25519 서명을 검증해요. ## English

**Automatic chest opening now continues after a delayed response for your own chest.** After 30 seconds the panel shows **Chest response delayed**. Once the game reports success or failure, the next eligible chest opens automatically.

**[Download BongoCatChat-0.1.0.dev33-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev33/BongoCatChat-0.1.0.dev33-windows-x64-Setup.exe)**

### Updating

Stop active chest opening or merging and check any pending result in the game. If dev32 already shows **Chest result needs checking**, check that result first. If you connected chest or merge automation, fully close both Bongo Cat and Bongo Cat Chat once so the next game session loads the updated module. Run Setup.exe into your existing installation folder, or use **Settings → App updates → Check for updates**. Pending actions can postpone an automatic app restart.

Launch the game, join your lobby and open Bongo Cat Chat from Start. Confirm **v0.1.0.dev33** in Settings. History, drafts, nicknames and preferences are preserved. If you enabled automatic chest opening at launch, your saved options apply. Follow the takeover prompt if a previous helper is detected.

### First installation

Use Windows 10/11 x64 with Steam and Bongo Cat. Download the Setup.exe linked above. The app uses the ZIP for automatic updates.

1. Open Setup.exe and choose **다음 (Next)**. Read the privacy notice and choose whether to allow GitHub update checks and downloads.
2. Confirm the folder and choose **설치 (Install) → 마침 (Finish)**. The default folder is `%LOCALAPPDATA%\Programs\BongoCatChat`.
3. Sign in to Steam, join a lobby in Bongo Cat and open Bongo Cat Chat from Start. Check the connected lobby. Press **Enter** to send a message or **Shift + Enter** for a new line. To change language, open **설정 → 언어 / Settings → Language**.
4. To use automatic chest opening, open it from the sidebar, save your chest types and delay, then connect and start. Opening another player's chest spends your points. Item merging is optional.

### While waiting for a result

The app waits for the original request. If you select **Stop**, it records a late response and leaves automation stopped. If processing or saving the result fails, the panel shows **Chest result needs checking**. Check the result in the game. If it happens again, open **Report a bug → View collected diagnostics** before closing the app. You can copy the diagnostics or submit them on GitHub.

Synthetic game tests covered late success and failure, a 121-second wait, duplicate replies and a manual stop. Long-running live gameplay and real point consumption were outside the test scope. This Windows development installer is Authenticode-unsigned. The app verifies Ed25519 signatures for automatic updates.
