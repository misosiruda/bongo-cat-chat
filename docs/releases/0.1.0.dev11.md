# 0.1.0.dev11 개발판

Bongo Cat과 다른 Steam 게임을 함께 실행할 때 로비를 찾지 못하던 문제를 수정했다.

- Steam 친구 게임 정보가 다른 게임을 표시해도 Bongo Cat의 로비 탐색을 시작한다.
- 실행 중인 Bongo Cat에서 현재 로비를 직접 읽고 Steam 자기 참여를 대조한다. 친구 게임 정보는 탐색 전 초기 표시의 보조 정보로만 사용한다.
- 다른 게임 표시가 바뀌어도 확인된 Bongo Cat 연결과 작성 중인 초안을 유지한다.
- 실제 로비 읽기 실패·계정/프로세스 변경·자기 참여 해제는 계속 차단한다. 탐색 실패 시 Steam 연결을 유지하며 15초 뒤 재시도한다.

## 설치와 업데이트

`BongoCatChat-0.1.0.dev11-windows-x64-Setup.exe`로 설치한다. dev10 실행기로 시작했고 업데이트 통신이 허용된 앱은 다운로드 완료 후 30초 안내와 정상 종료·재시작을 거쳐 적용한다. dev9 이하에서는 다운로드 후 앱을 직접 다시 실행해야 한다.

기존 Ed25519 공개키와 데이터·실행기 스키마를 유지한다. 데이터 마이그레이션은 없다. Windows Authenticode/SignPath 게시자 서명은 없는 개발판이며 Windows 경고가 남을 수 있다. 업데이트 서명은 Windows 게시자 인증과 별개다.

## 검증 범위

사용자가 Bongo Cat과 Marvel’s Spider-Man Remastered를 동시에 실행한 상태에서 실제 Steam 친구 게임 정보가 스파이더맨을 반환함을 확인했다. 수정 전 작업자는 10초 동안 로비를 찾지 못했고, 수정 후 작업자는 **0.5746초**에 Bongo Cat 로비를 확인한 뒤 **30.4313초** 동안 연결을 유지했다. 송신·채팅 본문 조회·게임 변경 없이 읽기 전용으로 비교했다.

다른 게임·빈 정보·오래된 로비 정보, 연결과 초안 유지, 로비·계정·프로세스 경합, 메모리 읽기 실패와 자기 참여 해제, 탐색 재시도를 회귀 검사한다. [제품 검증 기록](../product-validation.md#2026-10-15-복수-steam-게임-실행-시-로비-탐색-수정)에서 합성 검사와 실제 게임 검증을 구분한다.

소프트웨어 렌더링 조건에서 실제 NSIS 통합 검사를 포함한 로컬 전체 테스트 **417개**가 통과했다. 기본 GPU 조건에서 관찰한 Qt 설정창 시간 초과는 별도 기록하며, 이번 수정으로 해당 GPU 경로를 고쳤다고 주장하지 않는다.

실제 메시지 송수신·상대 화면, 두 게임의 추가 실행/종료 전환, 순정 설치·다른 PC·장시간 인수는 이번 수정의 검증 범위에 포함하지 않는다.
