# 0.1.0.dev14 개발판

게임에서 받은 이모티콘 아이템과 야옹 반응을 채팅창 아래에서 올라오는 고양이 파티클로 표시한다. 대화 기록에 반응이 쌓이지 않고, 누가 보낸 반응인지 외형과 닉네임으로 확인할 수 있다.

## 변경 사항

- 발신자의 실제 스킨·모자와 게임 이모티콘 아이템 아이콘 또는 울음 말풍선을 함께 표시한다. 게임에 설치된 리소스를 읽으며 게임 그림을 배포물에 포함하지 않는다.
- 반응은 아래에서 위로 올라와 2.2초 후 사라진다. 같은 이용자의 반복 반응도 각각 표시하며 횟수로 합치지 않는다. 화면이 가득 차면 초과 반응을 버리고 뒤늦게 재생하지 않는다.
- 고양이 아래의 닉네임은 한 줄, 최대 112×22px·11px 글자로 표시하고 긴 이름은 말줄임표로 줄인다.
- 반응을 대화 기록·검색·읽지 않음·새 메시지 알림에 추가하지 않는다. 입력과 스크롤을 유지하고 숨김·로비 이동·검색·창 비표시 상태의 오래된 반응을 제거한다.
- 움직임 줄이기 설정에서는 낮은 위치에서 서서히 나타났다 사라진다. dev13의 기본 고양이 프로필 수정도 유지한다.

## 설치와 업데이트

`BongoCatChat-0.1.0.dev14-windows-x64-Setup.exe`를 사용한다. 기존 업데이트 피드·Ed25519 공개키와 대화·초안·설정·실행기 스키마를 유지한다. dev10 이상 실행기로 시작한 설치본은 업데이트 준비 후 기존 입력·저장 보호 절차에 따라 자동 재시작한다.

Windows Authenticode/SignPath 게시자 서명이 없는 개발판이다. 업데이트 manifest의 Ed25519 서명은 Windows 게시자 인증과 별개다.

## 검증 범위

설치된 게임 빌드 `25936063`에서 채널 6의 아이템 ID 형식과 실제 아이콘 참조를 정적으로 확인했다. 합성 수신으로 반복·폭주·만료·숨김·연결 변경·기록과 알림 제외를 검사하고, 실제 Qt/QWebChannel 및 Edge의 제품 UI에서 상승·제거·닉네임 크기·좁은 화면·다크·움직임 줄이기를 확인했다. 상세 결과는 [제품 검증 기록](../product-validation.md#2026-10-21-고양이-반응-파티클)에 있다.

실사용 로비로 시험 메시지나 이모티콘을 전송하지 않았다. 실제 자연 수신과 게임 화면 대조, 순정 게임·다른 PC·장시간 사용은 미검증이다. 소스 검사·PR 병합과 최종 파일의 서명·공개 배포·설치 업데이트 검증은 각각 구분한다.
