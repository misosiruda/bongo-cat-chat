# Bongo Cat Chat 0.1.0.dev31

**게임 업데이트 후 상자·합성 연결에 나타나는 `unsupported_automation_features` 오류를 수정해요.** 게임 build **26538670**의 상자 표시 설정 변경을 검토하고 지원 조합을 추가했어요. 기존 게임 지원과 소비 보호는 유지해요.

**[Windows 설치 파일 다운로드](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev31/BongoCatChat-0.1.0.dev31-windows-x64-Setup.exe)** · [English installation guide](#english)

## 이번 업데이트에서 바뀐 점

- 게임에 일반 상자 표시 설정이 추가되면서 기존 앱의 상자 기능 검사와 달라졌어요. 상자·합성은 공통 호환성 검사를 사용하므로 두 화면 모두 연결이 차단될 수 있었어요.
- 검토한 새 기능 조합을 추가했어요. 합성·인벤토리 기능 지문은 이전 지원 조합과 같아요.
- 기존 지원 조합도 유지해요. 기능·의존성 검사를 끄지 않으며 알 수 없는 변경과 실행 중 모듈 불일치는 계속 차단해요.
- 사용자 시작·저장한 자동 시작 선택, 기존 도우미 전환 확인, 결과 미확인 보호와 소비 명령 재전송 금지는 그대로예요.

## 처음 설치할 때

**Windows 10/11 64비트(x64), Steam, Bongo Cat**이 필요해요. Python·개발 도구·관리자 권한은 필요하지 않아요. 받을 파일은 **`BongoCatChat-0.1.0.dev31-windows-x64-Setup.exe`** 하나예요. `Source code`는 소스이고 `bongo-cat-chat-windows-x64.zip`은 앱 업데이트용이에요.

1. 실행 중인 Bongo Cat Chat이 있으면 종료하고 Setup.exe를 실행해요.
2. **다음 → 개인정보 처리 안내 확인 → 다음**으로 진행해요.
3. **GitHub 업데이트 확인 및 다운로드 허용** 여부를 선택해요. 해제해도 Steam 채팅과 수동 버그 제보는 사용할 수 있어요.
4. 설치 위치를 확인하고 **설치 → 마침**을 눌러요. 기본 위치는 `%LOCALAPPDATA%\Programs\BongoCatChat`이에요.
5. Steam에 로그인하고 Bongo Cat을 실행해 **게임 안에서 로비에 참여**해요. 시작 메뉴에서 **Bongo Cat Chat**을 실행해요.
6. 앱의 연결 상태와 로비를 확인하고 채팅해요. **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿔요.

언어는 **설정 → 언어 / Settings → Language**에서 한국어·English를 선택할 수 있어요. 상자 자동 개봉과 아이템 자동 합성은 선택 기능이며 채팅에 필수인 설정은 아니에요.

## 기존 설치를 업데이트할 때

**설정 → 앱 업데이트 → 업데이트 확인**을 누르고 준비 완료 안내에 따라 앱을 다시 시작해요. GitHub 업데이트 통신을 꺼 뒀다면 켜거나, 앱을 종료하고 위 Setup.exe를 **기존 설치 폴더에** 실행해요. 먼저 제거할 필요 없이 대화·초안·설정·별명을 보존해요. 설정에서 **v0.1.0.dev31**이 표시되는지 확인해요.

자동화 진행 중이거나 결과를 기다리는 동안에는 자동 업데이트 재시작을 보류해요. 저장한 **앱 실행 시 자동 개봉 시작** 선택은 유지되므로 켜 둔 경우 앱 재실행 후 저장된 시작 동작이 적용될 수 있어요.

이 오류만으로 게임을 재설치할 필요는 없어요. 업데이트 후 상자·합성 화면에서 다시 연결해요. **이전 연결 모듈이 게임에 이미 로드돼 있거나 게임 재실행 안내가 나오면**, 진행 중인 결과를 확인하고 게임을 완전히 종료한 후 다시 실행해요. 앱은 실행 중인 구버전 모듈을 교체하지 않아요.

## 오류가 계속될 때

1. 앱 버전이 dev31인지 확인해요. 이후 게임 업데이트로 같은 오류가 생기면 새 지원 검토가 필요할 수 있어요.
2. **앱을 닫기 전에** 상자·합성 화면의 **버그 제보**, 또는 **설정 → 문제 해결 → 버그 제보**를 눌러요.
3. **수집한 진단 보기**로 내용을 확인하고 **GitHub에서 제보하기**를 눌러요. 브라우저에서 로그인하고 상황을 덧붙여 **등록**해야 접수가 완료돼요. GitHub 계정이 없으면 **진단 복사**로 전달할 수 있어요.

제보는 공개되므로 개인 정보를 추가하지 마세요. 진단 미리보기만으로 전송하지 않으며 제보 버튼은 재연결·개봉·합성을 시작하지 않아요. 연결 폴더·토큰·원본 로그를 공유하거나 ledger를 삭제할 필요가 없어요. 파일 누락·읽기 실패 등 **다른 오류**가 나오면 해당 안내를 따라 주세요.

## English

**dev31 fixes `unsupported_automation_features` when connecting chest opening or item merging after the game update.** It adds reviewed support for Bongo Cat build **26538670**, including its chest visibility setting changes, while retaining previous support and consumption safeguards.

**[Download BongoCatChat-0.1.0.dev31-windows-x64-Setup.exe](https://github.com/misosiruda/bongo-cat-chat/releases/download/v0.1.0.dev31/BongoCatChat-0.1.0.dev31-windows-x64-Setup.exe)**

### What changed

The game added a visibility setting for ordinary chests, changing the chest feature fingerprint. Chest opening and merging share compatibility validation, so this could block both panels. The reviewed new combination is now supported; merge and inventory fingerprints match the previous combination. Feature checks, dependency checks, loaded-module checks, explicit start/saved auto-start choices, helper handover confirmation and unknown-result safeguards remain in place. Potentially delivered consumption commands are not resent.

### First installation

You need **Windows 10/11 x64, Steam and Bongo Cat**. Python, developer tools and administrator privileges are not required. Download only Setup.exe above; `Source code` is source, and `bongo-cat-chat-windows-x64.zip` is for the app updater.

1. Close any running Bongo Cat Chat and launch Setup.exe.
2. The installer is in Korean. Choose **다음 (Next)**, read the privacy notice, then choose **다음 (Next)**.
3. Choose whether to allow **GitHub 업데이트 확인 및 다운로드 허용 (GitHub update checks and downloads)**. Chat and manual bug reporting still work if this is disabled.
4. Confirm the install folder and choose **설치 (Install) → 마침 (Finish)**. The default is `%LOCALAPPDATA%\Programs\BongoCatChat`.
5. Sign in to Steam, launch Bongo Cat and **join a lobby in the game**. Open **Bongo Cat Chat** from the Start menu.
6. Check the connection and lobby, then chat. **Enter** sends; **Shift + Enter** inserts a line break. Select English in **설정 → 언어 / Settings → Language** if needed.

Chest opening and merging are optional, not prerequisites for chat.

### Updating

Use **Settings → App updates → Check for updates** and follow the app restart prompt. If GitHub update access is disabled, enable it or close the app and run Setup.exe into the **existing install folder**. There is no need to uninstall first; history, drafts, preferences and nicknames are preserved. Confirm **v0.1.0.dev31** in Settings.

Active automation and pending results postpone automatic update restart. Saved **Start automatic chest opening when the app launches** consent remains enabled if you previously selected it, and may start the configured automation after relaunch.

This error alone does not require reinstalling the game. Reconnect from the chest/merge panel after updating. **If an older bridge is already loaded or the app requests a game restart**, check pending results, completely close the game and reopen it. The app does not replace an already loaded bridge.

### If the error persists

Confirm dev31 is installed. A later game update may require another compatibility review. Before closing the app, choose **Report a bug** in the chest/merge panel or **Settings → Troubleshooting**. Review **View collected diagnostics**, then choose **Report on GitHub**, sign in and submit the issue. Opening the browser alone does not submit it. Without a GitHub account, use **Copy diagnostics**.

Issues are public; do not add personal information. Previewing alone does not send diagnostics. Reporting does not reconnect or start automation. Do not share connection folders, tokens or raw logs, or delete ledgers to bypass safeguards. For a different error, such as a missing or unreadable file, follow that error's guidance.

### Validation and limits

**305 focused local tests passed**, along with bridge compilation/member resolution against current game metadata, packaged feature validation and isolated offline renderer checks. Both reviewed profiles and rejection of unknown feature/dependency combinations were tested. The public candidate goes through separate Windows CI and the release workflow.

No real chests, items or points were consumed, and no running game files or loaded modules were replaced. Live connection, minimized/long-duration operation and other-PC acceptance remain separate. Archived IL/current metadata comparison is not proof of whole-game semantic equivalence. [Compatibility evidence](https://github.com/misosiruda/bongo-cat-chat/blob/v0.1.0.dev31/docs/automation-feature-compatibility.md#2026-11-10-build-26538670-지원)

This development installer is **not Windows Authenticode-signed**. Download it from the official GitHub release. Automatic updates verify separate Ed25519 signatures. Received messages are kept locally for 30 days by default; uninstalling preserves records and settings.
