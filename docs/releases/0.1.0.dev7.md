# 0.1.0.dev7 개발판

2026-10-14 사용자가 요청한 고양이 프로필 모자 위치 수정의 릴리스 후보다. 배포 여부와 설치 자산은 [릴리스 페이지](https://github.com/misosiruda/bongo-cat-chat/releases/tag/v0.1.0.dev7)에서 확인한다. 이전 공개판은 `0.1.0.dev6`이다.

## 포함한 수정

[PR #11](https://github.com/misosiruda/bongo-cat-chat/pull/11)의 모자 수정과 [PR #12](https://github.com/misosiruda/bongo-cat-chat/pull/12)의 설정 UI 수정을 포함한 `845c2649fe180e03d7ef0b109955d921e69ae06b`를 기준으로 한다. 몸통·모자·앞발을 같은 좌표에 겹치던 합성을 설치된 게임의 로비 프리팹 기준으로 바꿨다. 몸통에 대한 모자의 상대 위치와 몸통 → 모자 → 앞발 순서를 반영하고, 높은 모자가 잘리지 않도록 전체 영역을 정사각형 프로필에 맞춘다.

설정창의 제목과 닫기 버튼은 고정되고 내용만 스크롤한다. 다시 열면 삭제 확인과 스크롤 위치를 초기화한다. 설정·참여자 창의 배경 흐림도 제거한다. 실제 제보 PC의 GPU 깜빡임 해소는 확인 필요다.

버전은 `pyproject.toml`과 `src/bongo_chat/__init__.py` 모두 `0.1.0.dev7`로 올린다. 다른 작업 브랜치의 미병합 변경은 포함하지 않는다. 게임 리소스는 이용자의 설치에서 읽으며 배포물에 넣지 않는다.

## 설치와 업데이트

- 새 설치: 릴리스의 `BongoCatChat-0.1.0.dev7-windows-x64-Setup.exe`를 실행한다.
- 자동 업데이트를 지원하는 기존 설치: 설정에서 업데이트를 확인하거나 주기적 확인을 기다린다. 새 버전 다운로드가 준비되면 다음 앱 실행 때 적용된다.
- `dev1`: 자동 업데이트가 없어 설치 파일을 한 번 실행해야 한다.

기존 업데이트 공개키, `bootstrap_schema=1`, `data_schema=1`, 저장소 형식은 유지한다. 앱이 받는 일반 GitHub Release 채널로 게시하더라도 제품 상태는 개발판이다. 서명된 업데이트 ZIP·manifest·Ed25519 서명·SHA-256 목록·기존 제3자 고지를 설치 파일과 함께 제공한다.

다운로드·서명·후보 화면 검사가 실패하면 기존 버전을 유지한다. 적용 직후 시작 실패 시 이전 버전 선택으로 복구하는 기존 동작을 사용한다. 설치기는 낮은 버전으로의 덮어쓰기를 거부하므로 게시 후 결함 수정은 더 높은 버전으로 배포한다. DB 마이그레이션은 없다.

## 검증 범위

모자 수정의 원본 검사와 화면 대조는 [제품 검증 기록](../product-validation.md)에 있다. 릴리스 검사는 격리된 설치와 합성 대화 데이터로 수행하며 게임 송신·로비 이동·실사용 앱의 재시작을 포함하지 않는다.

소스 후보는 별도 Python 3.13 가상 환경에서 검사했다. 제3자 패키지 버전은 dev6 빌드 환경과 일치하고 `pip check`도 통과했다.

| 검사 | 결과와 대상 |
| --- | --- |
| `python -B -m pytest -q` | 모자 수정이 병합된 `abc8dbc` + dev7 버전에서 174개 통과 |
| `python -B -m pytest -q tests/test_desktop.py` | 설정 UI까지 반영한 `845c264` + dev7 버전에서 18개 통과. 변경 없는 나머지 검사는 위 결과 재사용 |
| `python -B tests/browser_check.py --browser <Chrome.exe> --output <격리 폴더>` | 설정 레이아웃 6개 조합·모달 갱신 12개 표본, JavaScript 오류 0. 최초 실행은 테마 선택 직후 라디오 상태 검사에서 실패했고 같은 코드의 재검사는 통과 |
| 버전·모듈 경로 검사 | 소스·배포 메타데이터·`pyproject.toml`이 모두 dev7이며 해당 워크트리의 모듈을 가져옴 |

전체 검사에서는 offscreen GPU context 경고가 관찰됐다. 최신 Qt UI 검사는 `QT_QPA_PLATFORM=offscreen`, `QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu` 환경이다. 브라우저 최초 실패의 정확한 원인은 확정하지 않았으며 재검사 통과를 간헐적 문제가 해결됐다는 근거로 확대하지 않는다. 패키지·공개 다운로드·업데이트 적용 결과는 실제 게시한 릴리스의 검증 항목과 구분한다.

순정 게임·다른 PC·일반 GUI 장시간 안정성·백신·전원 손실 시험은 남아 있다. Windows Authenticode 서명은 없으며, 자동 업데이트의 Ed25519 서명과 구분한다. 소스 라이선스와 게임 개발사의 승인 상태는 이번 릴리스에서 변경하지 않는다.
