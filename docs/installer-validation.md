# Windows 설치 검증

기준일: **2026-10-14**, 작업 기준 `main` **3c5fd93**. 아래 최초 네이티브 설치 검사는 **0.1.0.dev4** 산출물에 대한 기록이다. 이후 수정·검사는 별도로 구분한다. 같은 개발 PC에서 수행한 검사이며 순정 게임이나 개발 도구 없는 다른 PC의 인수 결과가 아니다.

## 산출물

- 한국어 NSIS 설치 프로그램: `BongoCatChat-0.1.0.dev4-windows-x64-Setup.exe`
- 파일 크기: **251,380,393바이트**
- SHA-256: `b56b64b484ea2b66439c3d2e2b18986d40f1933efe936a511c57225641060f83`
- 전체 앱·Qt·Python을 동봉하며 설치 과정의 런타임 다운로드 없음
- NSIS **3.13** 공식 ZIP 사용. 내려받은 도구 ZIP의 SHA-256은 `ba63dffc4410ee89193e1cb5a41989991bd77c61068da17e3156d136b7b0b3d8`
- Windows Authenticode 서명 없음. 업데이트 자산의 Ed25519 서명과 구분함

## 자동 검사

전체 소스 검사 **108개 통과** 후, 바로가기 충돌 방어와 경로 검사 성능을 보완했다. 보완 후 영향 범위인 `tests/test_packaging.py`의 **10개가 다시 통과**했다. 검사는 Windows 기본 PowerShell과 실행 불가능한 소형 합성 파일을 사용한다.

검사 범위는 한글·공백 경로, 설치·같은 버전 재설치·제거, 이전 버전에서의 교체와 다운그레이드 거부, dev1 구조 전환, 실행 잠금 중 설치·제거 차단, 실제 파일 공유 잠금으로 교체 실패를 유발한 뒤 기존 버전 복구, 불완전한 묶음·무관한 폴더·데이터 폴더 거부, 재분석 지점 차단, 바로가기 충돌 거부와 제거다. 대화 데이터와 설치 루트의 별도 파일 보존도 검사했다.

실제 묶음에서는 파일마다 조상 경로를 중복 검사하는 성능 문제를 발견했다. 루트 조상은 한 번 확인하고, 하위 디렉터리는 각 항목의 재분석 속성을 확인한 뒤 방문하도록 수정했다. 이 수정 전의 진행 중 검사는 중단하고 최종 설치 파일로 다시 검사했다. 게임·Steam·사용자 앱 프로세스를 종료하지 않았다.

## 실제 설치 파일 검사

위 dev4 SHA-256의 설치 파일과 내장 제거 EXE를 실행했다. 제품 이름의 현재 사용자 등록을 사용했고, 마지막에는 실제 앱을 설치한 상태로 남겼다. 앱 실행은 별도 합성 DB를 사용하는 `--offline --smoke-report`로 제한했다.

| 항목 | 결과 |
| --- | --- |
| 전체 앱 설치·시작 메뉴·Windows 제거 등록 | 통과. 설치 위치·버전·제거 EXE 확인 |
| 설치한 실행기로 실제 Qt 화면 초기화 | 통과. `renderer=true`, 콘솔 오류 없음, `steam_connected=false` |
| 같은 버전 재설치 후 실행 | 통과 |
| 설치 실행 잠금 중 설치·제거 | 모두 종료 코드 20으로 거부. 소유 프로세스 강제 종료 없음 |
| 내장 제거 프로그램 실행 | 통과. 앱 파일·업데이트 캐시·자기 등록·바로가기 제거 |
| 대화·초안·설정 보존 | 합성 SQLite 행을 설치 전후·재설치 후·제거 후·최종 실행 후 비교해 동일 |
| 설치 폴더의 별도 파일 보존 | 제거 후 합성 sentinel만 남음 |
| 제거 후 신규 설치·재실행 | 통과. 최종 앱 버전 0.1.0.dev4 |

개발 도구 경로를 PATH에서 빼고 앱을 실행했으나, 개발 도구가 설치되지 않은 다른 PC 시험과 동일시하지 않는다. 네트워크 업데이트나 실제 채팅 송수신을 이 시험에서 수행하지 않았다. 기존 자동 업데이트 검사는 [별도 기록](update-validation.md)을 따른다.

## 화면 확인의 범위

소형 `Installer Test` 묶음의 한국어 설치 위치 화면·폴더 선택을 관찰했고, 사용자가 해당 시험용 묶음을 실제 설치했다. 이후 그 파일이 실행 불가능한 합성 파일임을 확인하고 내장 제거기로 정리한 뒤 실제 전체 앱을 설치했다. 시험용 묶음을 일반 이용자용 파일로 전달하지 않는다.

최종 설치 파일의 추가 GUI 확인은 사용자의 Esc 입력으로 중단됐다. 최종 마법사의 모든 화면·배율·접근성 동작을 확인했다고 보고하지 않는다. 위 실제 EXE 설치·제거·앱 실행 검사는 GUI 자동 조작과 별도로 완료했다.

## 출하 전 보완

최초 설치 도중 실패했을 때 잠금 파일·빈 폴더가 남아 재설치를 막는 문제를 수정했다. 파일 공유 잠금으로 복사 실패를 유발하고 다음 설치가 성공하는지 검사했다. 설치·제거의 사전 검사와 잠금 획득 사이에 다른 업데이트가 활성 버전을 바꾼 경우도 재확인해 중단한다. 해당 설치 검사 **13개 통과** 후, 게임 업데이트 대응을 포함한 `0.1.0.dev5` 전체 소스 검사 **135개 통과**를 확인했다. 합성 파일·오프스크린 Qt·실제 PowerShell 검사이며 새 설치 EXE의 실행과 구분한다.

## dev5 최초 수정판 설치 확인

- 파일: `BongoCatChat-0.1.0.dev5-windows-x64-Setup.exe`
- 크기: **251,372,718바이트**
- SHA-256: `0a2ba38cf69c2d79f6c3495cbf0a85325676c9b31376de5f2500df7ac27a652f`
- 사용자가 지정한 기존 설치 위치에 실제 Setup EXE로 dev4 → dev5 교체 성공. Windows 제거 등록과 시작 메뉴 대상 확인
- 활성 dev5·이전 dev4 보관 확인. 설치된 실행기·앱 EXE·지원 목록·UI·제거 스크립트가 검사한 빌드와 동일한 바이트임을 확인
- 설치된 실행기의 오프라인 Qt 검사: dev5, `renderer=true`, 콘솔 오류 없음. 합성 대화·초안·설정 행 보존
- 기존 실제 대화 SQLite 파일들의 설치 전후 해시 일치. 사용자 대화 DB로 검사 앱을 실행하지 않음
- dev5 묶음의 별도 실제 게임 읽기 연결: [호환성 검증](game-update-compatibility.md). 송신·게임 조작 없음

dev5에서는 교체·실행 검사를 수행했다. 위 dev4의 전체 네이티브 제거·재설치 표와 합치지 않으며, dev5 제거 엔진의 실패 경로는 13개 PowerShell 검사에 포함된다. 원본은 `research/private/2026-10-14-compatibility/`에 보관한다. 일반 공개 릴리스에 게시한 파일은 아니다.

## 자동 리뷰 후 제거 실패 경로 수정

PR #6의 최초 코드·보안 리뷰는 `f0a0b8e`에서 완료됐다. 코드 리뷰의 바로가기 제거 실패 지적을 실제 파일 공유 잠금으로 재현했다. 수정 전에는 종료 코드 40이 반환됐지만 앱과 표식은 이미 삭제되어 제거를 다시 실행할 수 없었다.

바로가기 조회·삭제를 앱 구성원 삭제보다 먼저 수행하도록 변경했다. 조회가 실패해 대상 경로가 비어 있는 경우도 중단한다. 영향 범위인 `tests/test_packaging.py`의 **15개가 49.24초에 통과**했다. 전체 135개 결과는 이전 동일 앱 코드의 검사로 재사용하며, 전체 검사를 다시 실행한 것으로 세지 않는다.

별도 시험 식별자를 사용하는 실제 NSIS 설치·제거 EXE와 실행 불가능한 소형 합성 앱으로 조회 실패·삭제 실패 두 경우를 확인했다. 둘 다 코드 40에서 앱·표식·제거 등록을 보존했고, 잠금 해제 후 재시도는 코드 0으로 완료됐다. 시험용 설치·등록·바로가기는 모두 제거했다. 일반 사용자 앱의 제거를 반복한 검사는 아니다.

최종 설치 파일은 같은 앱 버전 **0.1.0.dev5**, 크기 **251,372,994바이트**, SHA-256 **`a449af09852b6b29b3cf382d7069876642c6823b1aa95107409878ac009d9b88`**이다. 앱 실행 파일은 그대로 두고 제거 엔진을 반영해 다시 묶었다. 사용자 설치 위치에 같은 버전 재설치를 완료했으며, 설치된 실행기의 오프라인 Qt·실제 대화 파일 해시·합성 기록 보존 검사가 다시 통과했다. 이전 dev4 선택도 보존했다. 외부 리뷰 완료는 최초 커밋의 증거이며 이 후속 수정의 외부 재승인이라고 표현하지 않는다.

## 기능별 호환성 검사 포함 dev6

2026-10-14 사용자의 업데이트 동작 정정에 따라 기능 검사기를 포함한 `0.1.0.dev6`을 빌드했다. 전체 DLL 지문 방식과 차이는 [게임 업데이트 대응](game-update-compatibility.md)에 기록한다. Mono.Cecil 0.11.6의 고정 패키지·DLL 해시를 확인해 검사기와 MIT 고지를 묶었고, 실행 시 사용자가 도구를 설치하거나 컴파일하지 않는다.

최종 Setup은 **251,537,106바이트**, SHA-256 **`a5619c34927c4ec5bba874d4f18ddde6a97df672030d6c0921a8a305172531fc`**이다. 별도 실행 파일의 오프라인 화면·실제 게임 읽기 전용 연결을 확인한 뒤 기존 사용자 설치에 적용했다. 설치된 실행 파일·기능 계약·검사기·라이브러리가 시험한 묶음과 일치했고, 설치된 실행기의 오프라인 화면도 종료 코드 0으로 통과했다. dev5 선택과 실제 대화 파일 해시를 보존했다. 실제 게임 송신은 하지 않았다.

동시에 여러 Qt 검사를 실행한 중간 시험에는 GPU context 오류 후 종료가 한 번 있었다. 같은 파일의 단독 재검사는 통과했으며, 이 결과를 정상 GUI의 장시간 안정성 인수로 확대하지 않는다. 검사 수치와 한계는 [dev6 근거](evidence/2026-10-14-feature-compatibility.json)에 구분한다. Windows 코드 서명·다른 PC·첫 공개 릴리스는 미완료다.

## 첫 공개 설치 파일 (2026-10-14)

사용자 요청으로 [v0.1.0.dev6](https://github.com/misosiruda/bongo-cat-chat/releases/tag/v0.1.0.dev6)에 위 dev6 Setup을 그대로 게시했다. 설치 파일의 크기 **251,537,106바이트**와 SHA-256 **`a5619c34927c4ec5bba874d4f18ddde6a97df672030d6c0921a8a305172531fc`**는 변경되지 않았다. GitHub에 올라간 자산의 서버 해시를 대조하고 인증 없이 전체 설치 파일을 다시 내려받아 같은 해시를 확인했다.

함께 게시한 업데이트 ZIP은 설치 파일과 구분한다. 공개 다운로드·이전 실행기를 통한 다음 실행 적용은 [업데이트 검증](update-validation.md), 식별정보 없는 게시 근거는 [릴리스 기록](evidence/2026-10-14-public-release.json)에 있다. 기존 문단의 "첫 공개 릴리스 미완료"는 게시 전 검사 시점의 상태이며, Windows 코드 서명과 다른 PC 인수는 계속 미완료다.

## 남은 인수

- 개발 도구 없는 별도 Windows PC의 설치·실행·제거
- 순정 게임 설치·지원 빌드 확장과 실제 게임 연결
- 최종 마법사 전체 화면, 배율·키보드 탐색·설치 중 취소
- Windows 코드 서명·브라우저 다운로드 후 SmartScreen·백신 영향
- 전원 손실·강제 종료·디스크 부족의 실제 설치 복구
- 별도 Windows PC에서 게시된 설치 파일 설치 및 이후 버전의 실제 자동 업데이트
