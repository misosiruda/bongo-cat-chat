# 고양이 반응 파티클

2026-10-21 사용자 요청에 따른 dev14 소스 구현이다. [dev14 릴리스 노트](releases/0.1.0.dev14.md)에 변경 사항과 검증 범위를 기록한다.

## 표시 동작

발신자의 현재 닉네임도 고양이 아래 이름표에 함께 표시한다. 글자 크기는 11px, 이름표는 최대 너비 112px·높이 22px의 한 줄이며 긴 이름은 말줄임표로 표시한다. 글자 수를 기준으로 자르지 않아 한글·영문 이름에도 같은 화면 상한이 적용된다. 닉네임은 텍스트로 표시하고 별도 툴팁·클릭 동작 없이 반응과 함께 사라진다.

게임에서 받은 클릭 울음과 이모티콘 아이템을 현재 로비의 대화 영역 아래에서 위로 띄운다. 발신자의 현재 스킨·모자를 합성한 고양이와 울음 말풍선 또는 실제 아이템 아이콘이 함께 움직이고 2.2초 안에 사라진다. 고양이는 기존 프로필과 같은 정지 외형이며 게임의 봉고 장식·동작 전체를 복제하지 않는다.

같은 발신자의 반복 입력도 별개 파티클이다. 횟수 배지나 `×N`으로 합치지 않는다. 반응은 메시지 목록·SQLite·검색·미저장 기록·새 메시지 표시·작업 표시줄 깜빡임·Windows 토스트로 전달하지 않는다. 기존 클릭 울음 기록의 숨김 정책도 유지한다. 정확히 같은 울음 문구를 직접 입력한 경우와 자동 클릭 울음은 게임 패킷만으로 구분할 수 없다.

대화 스크롤 바깥의 겹침 레이어에 표시하며 입력·클릭을 가로채지 않는다. 화면 폭에 따라 동시에 4~12개까지 표시하고 초과분은 버린다. 사용자별 제한이나 재생 대기열은 만들지 않는다. 움직임 줄이기 설정에서는 아래쪽에서 짧게 나타났다 사라진다. 검색·보관 로비·숨겨진 창에서는 반응을 재생하지 않는다.

## 확인한 게임 계약

설치 게임 빌드 `25936063`을 파일 읽기와 Steam 아이템 정의 조회로 확인했다. 게임 어셈블리를 실행하거나 수정하지 않았다.

- `SteamMultiplayer.SendEmote`는 아이템 정의 번호를 십진수 문자열로 바꿔 `Channel=6`, `Message`에 담는다. `OnLobbyChatMsg`의 대응 분기는 번호를 파싱해 `OnEmoteReceived`로 전달한다. 일반 문장과 클릭 울음은 `Channel=3`이다.
- `EmoteSpawner.SpawnMultiplayerEmote`는 해당 번호의 `SteamItemRuntime.Icon`을 표시한다. 런타임 생성자는 아이템 이름에서 ASCII 공백을 지우고 `Icon`을 붙여 스프라이트를 찾는다.
- 앱은 Steam 정의의 `tags`에서 `itemslot:emote` 또는 `itemslot:consumable`을 확인하고 `name`으로 같은 아이콘 이름을 구성한다. 실제 조회 표본은 `927`의 반짝임, `903`의 로켓, `456`의 새우, `457`의 화난 얼굴이었다. 숫자만 일치하는 모자나 상자는 표시하지 않는다.
- 설치된 `sharedassets0.assets`와 `resources.assets`에서 UnityPy로 PNG를 메모리에 만든다. 아이콘·게임 DLL을 앱에 복제해 배포하거나 원격 아이콘 URL을 불러오지 않는다. 알 수 없거나 중복된 이미지 이름, 지원 범위를 벗어난 이미지, 외형 조회 실패에는 대체 그림을 꾸며내지 않고 해당 반응을 생략한다.
- `feature-contract.json`에 다섯 번째 `reactions` 계약을 추가했다. 채널 6의 분기·패킷·아이템 번호·아이콘 연결 코드가 달라지면 기존 호환성 정책에 따라 연결을 보류한다. 네 개의 기존 계약 해시는 유지된다.

## 수신과 수명

콜백 소유 기간 안에 패킷을 복사한 뒤 `decode_event`에서 메시지와 반응을 분리한다. 현재 계정·로비·generation, 참여자 및 비숨김 집합의 기존 수신 경계를 그대로 거친다. 새 연결·숨김 해제 직후의 이전 콜백을 새 반응으로 재생하지 않는다.

`ReactionAssets`는 최대 12개까지 비동기 이미지 준비를 기다리되 수신 후 1.2초가 지나면 폐기한다. 매번 현재 프로필·숨김·연결을 다시 검사한다. 이미지 준비 지연으로 첫 반응이 생략될 수 있으며, 준비된 뒤 지난 반응을 재생하지 않는다. 별도의 반응 송신·아이템 사용 또는 소비 API는 없다.

`ChatService`의 메모리 전용 목록도 최대 12개다. UI의 정규 조회가 한 번만 소비하며 전달 직전에도 유효기간과 숨김 상태를 확인한다. 로비 변경 때 폐기한다. 화면에서는 식별자 중복을 제거하고 `animationend` 또는 2.4초 정리 타이머로 요소를 제거한다. 숨김·퇴장·연결 단절·검색·방 이동·창 숨김은 표시 중인 요소도 제거한다.

## 검증

- 합성 패킷: 채널 6의 문자열 번호·범위 검사, 잘못된 타입·부호·선행 0·Unicode 숫자 거절, 기존 27개 언어 울음과 일반 문장의 분리, 콜백 해제.
- 서비스·자원: 동일 발신자 개별 반응, 식별자 중복 제거, 최대 수량·만료·숨김·퇴장·세대 전환·연결 신선도, 실제 자원 필요 조건, DB·수신 영수증·revision·새 메시지 상태 불변.
- 실제 Qt HTML/QWebChannel/Controller: 합성 반응 5개를 고양이+아이템으로 표시하고 제거, 알림 호출 0회, 기록 수와 초안 보존.
- Edge 제품 UI: 합성 이용자와 실제 설치 게임에서 읽은 고양이·반짝임·로켓 이미지. 반복 6개, 순간 100개/최대 12개, 390px 화면 최대 5개, 상승 방향, 만료 후 대기 반응 없음, 60개 메시지·스크롤·초안 보존, 숨김·검색·다크·움직임 줄이기, JS 오류 0건.

재현 명령은 `.venv/Scripts/python.exe -m pytest -q`와 `.venv/Scripts/python.exe tests/browser_reaction_check.py --channel msedge`다. 브라우저 검사는 기본적으로 합성 PNG를 사용한다. `--assets`에 로컬 게임 이미지 JSON을 지정한 추가 검사와 화면 캡처는 Git에서 제외된 `artifacts/reactions/`에 보관했다. 이 자료에 실제 이용자의 이름·ID·채팅은 넣지 않았다.

실제 로비에서 타인이 사용한 아이템의 자연 수신과 게임 화면 대조, 순정 게임의 별도 PC, 설치판 교체·공개 배포는 이번 검증에 포함하지 않는다. 실사용 로비로 시험 메시지나 이모티콘을 보내지 않았다.
