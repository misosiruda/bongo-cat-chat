## dev10 실제 설치본 자동 재시작 검증 (2026-10-15)

위 소스 검사 이후 `0.1.0.dev10` Windows 실행기·앱·NSIS 설치 파일을 빌드했다. 전체 로컬 테스트 **395개 통과**(136.61초, 소프트웨어 렌더링), frozen 오프라인 화면, 묶음의 고지·의존성·아이콘 검사를 완료했다. 별도 시험 설치에서 묶음 파일 472개와 실행기·앱·제거 프로그램의 아이콘 10프레임씩을 확인했으며 설치·제거 후 합성 DB와 무관한 파일을 보존했다.

- 자동 재시작의 시작점은 이번 소스에서 버전 상수만 dev9로 낮춘 **실제 NSIS 시험 설치본**이다. 기존 공개 dev9에는 자동 재시작이 없으므로 이 두 대상을 구분한다.
- 게시 전에는 기존 운영 키로 서명한 dev10 패키지를 제품 `check_and_stage`와 로컬 자산 전송 대역으로 준비했다. 실행 중인 설치 앱이 pending의 실제 Ed25519 서명과 ZIP 해시를 재검사해 `ready`로 전환했다.

- 설치 포인터는 `active=0.1.0.dev10`, `previous=0.1.0.dev9`, 결과는 `applied`였다. 새 실행기·앱의 해시가 배포 후보와 일치했고 pending 정리와 최신 상태 재확인을 통과했다.

## 검증 범위

초기 단위·Qt 검사는 합성 데이터와 릴리스 API 대역을 사용했다. 후속 dev6 검사는 실제 공개 GitHub 다운로드와 이전 실행기의 다음 실행 적용까지 확인했지만, 일반 이용자의 별도 PC 인수는 아니다. 다른 PC·백신·전원 손실·장기 실행·Windows Authenticode 서명과 일반 배포 조건은 남아 있다. 기존 `0.1.0.dev1`이 자동 업데이트를 지원한다고 소급해 기록하지 않는다.
