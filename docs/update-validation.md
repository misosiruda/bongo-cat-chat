## 검증 범위

단위·Qt 검사는 합성 데이터와 릴리스 API 대역을 사용한다. 공개 GitHub 릴리스 게시·일반 이용자 다운로드는 아직 검증하지 않았다. 다른 PC·백신·전원 손실·장기 실행·Windows Authenticode 서명과 일반 배포 조건도 남아 있다. 기존 `0.1.0.dev1`이 자동 업데이트를 지원한다고 소급해 기록하지 않는다.
