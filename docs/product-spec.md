# 제품 요구사항

상태: 2026-10-12 합의와 10월 13일 사용자 보완 요구사항. 제품 UI·저장·프로필 연동을 [Windows 개발판](windows-app.md)에 구현했다. [제품 검증 기록](product-validation.md)의 확인 범위와 미검증 항목을 구분한다. 디자인 원본은 [새 메신저 시안](design/README.md)이며 시안의 예시 데이터는 제품에서 사용하지 않는다.

개발판 정책 확정: 숨김 중 새 상대 메시지는 저장하지 않고 기존 기록은 표시에서 제외한다. 숨김 조회 실패 시 상대 대화 표시·신규 저장을 보류하며 현재 로비가 검증된 송신은 유지한다. 연결 자체가 미확인·오래됨이면 송신도 차단한다. 기록·초안은 30일 보관하며 직접 삭제를 제공하고 내보내기는 후속으로 둔다. 결정 근거는 [D-013~015 및 D-021](decisions.md)에 있다.

## 1. 해결할 문제

Bongo Cat의 로비 채팅은 게임 화면에 잠시 나타난 뒤 사라진다. 사용자는 지나간 대화를 다시 확인하기 어렵고, 게임 안에서 문장을 입력하는 방식도 불편하다고 설명했다.

사용자가 원하는 것은 게임의 기존 대화에 참여하면서 메신저나 Discord처럼 목록 형태로 읽고 입력할 수 있는 별도 프로그램이다. 여기서 Discord는 UI와 사용성의 참고 대상이다. Discord 서버·봇·계정과의 연동을 요청한 것은 아니다.

## 2. 사용자와 사용 조건

- 1차 대상: Windows에서 Steam Bongo Cat을 실행하고 기존 로비에 참여한 이용자.
- 상대방: 원래 게임 채팅만 사용해도 된다. 별도 프로그램 설치를 요구하지 않는다.
- 배포 목표: 불특정 Bongo Cat 이용자에게 무료로 배포하고 개발자에게 안내한다.
- 현재 검증 조건: Steam 로그인, 게임 실행, 현재 계정의 로비 참여가 모두 있는 상태.
- 다른 Steam 게임과 Bongo Cat을 동시에 실행할 수 있어야 한다. Steam 친구 목록에 보고되는 게임이 달라도 로컬 Bongo Cat의 현재 로비를 기준으로 연결한다. Bongo Cat 자체의 복수 인스턴스는 별도 지원 범위다.
- 게임을 종료한 채 메신저만 사용하는 방식은 별도 연구 대상으로 남긴다.

## 3. 주요 사용자 흐름

### 연결

1. 앱을 실행하면 Steam과 게임의 연결 가능 여부를 확인한다.
2. Steam이 Bongo Cat 로비를 보고하고 자기 참여가 확인되면 방과 초안 입력을 먼저 제공한다. 다른 게임 또는 빈 정보가 보고돼도 게임의 현재 로비·숨김 정보 탐색을 시작하며 화면에 진행 상태를 구분한다.
3. Bongo Cat 프로세스의 현재 로비와 Steam 자기 참여 검증이 끝나야 송신을 활성화한다. 친구 게임 정보가 달라져도 이 로비와 연결 구간·초안을 유지한다. 숨김 사전은 비숨김이 확인된 사용자부터 반영하며 미확인 상대의 대화·프로필·신규 저장은 보류한다. 숨김 지연만으로 검증된 송신을 막지 않는다.
4. 로비가 바뀌면 새 로비의 대화 화면으로 전환하고, 이전 기록은 별도 기록으로 유지한다.

앱이 사용자 대신 임의의 로비를 만들거나 참여하는 동작은 첫 제품 범위가 아니다. 자동 감지·구간 전환은 구현했으며 실제 로비 이동·재연결 인수는 남아 있다.

기본 목표는 게임의 로비 변경을 자동으로 따라가는 것이다. 새로고침은 상태 재확인을 위한 보조 동작으로 둔다. 전환 중에는 보내기를 제한하고, 이전 방의 초안·늦게 도착한 메시지가 새 방에 섞이지 않게 한다. 이미 API를 호출한 메시지는 원래 대상의 결과로 남기며 새 방으로 자동 재전송하지 않는다.

### 읽기

1. 다른 이용자가 원래 게임에서 메시지를 보낸다.
2. 앱이 해당 로비의 채팅 이벤트와 본문을 수신한다.
3. 발신자, 본문, 앱의 수신 시각을 목록에 표시한다.
4. 저장된 기록은 로비별로 다시 읽고 검색할 수 있다.

고양이를 눌렀을 때 나오는 자동 울음은 대화에서 제외한다. 현재 게임의 27개 언어 울음 문구와 본문 전체가 일치하는 신규 수신은 저장하지 않으며, 기존 기록도 대화·검색에서 숨긴다. 대소문자·앞뒤 공백·Unicode 정규화만 무시하고 문장 일부가 일치한다는 이유로 숨기지 않는다. 게임에는 자동 울음 식별자가 없어 같은 문구만 직접 입력한 메시지도 숨겨진다. [D-022](decisions.md#d-022-고양이-클릭-울음을-대화에서-제외한다)

발신자의 Steam 식별자 수신은 확인했다. 표시 이름은 Bongo Cat에 보이는 이름과 같게 하고, 프로필 이미지는 해당 사용자가 게임에서 사용하는 고양이 외형과 동기화하는 것이 사용자 요구사항이다. 2026-10-13 [이름·모자·스킨 조회와 정지 이미지 샘플 생성](profile-sync-validation.md)을 확인했으며, 제품 화면 대조·로비 전환·조회 실패 처리는 미검증이다. Steam 프로필 사진 조회만으로 게임 고양이 동기화를 완료했다고 판단하지 않는다. 발신 시각이 원래 데이터에 들어 있지 않으므로 수신 시각을 발신 시각처럼 표시하지 않는다.

**개별 사용자 숨김은 Bongo Cat에서 설정하고, 채팅 앱은 그 상태를 자동으로 따라야 한다.** 앱에 별도 숨김·해제 버튼이나 독립적인 수동 숨김 목록을 두지 않는다. 게임에서 숨긴 사용자의 메시지는 앱의 대화·검색·미리보기·알림·읽지 않은 수에서 제외하고, 게임에서 해제하면 그 변경도 반영한다. 이미 저장된 메시지도 화면 노출에서 제외하되 영구 삭제와 숨김 중 저장 여부는 별도 정책이다.

게임 내부 캐시를 외부에서 읽는 실험 경로를 확보했고, 같은 이용자의 실제 숨김·해제 전환을 감지했다. 게임 파일 수정·DLL 주입·메모리 쓰기는 없었으나 내부 구조에 의존한다. **필수 요구사항의 제품 구현·호환성 검증은 미완료**다. 지원 환경에서 조회 경로를 확보하지 못하면 미충족으로 기록하며 앱 자체 숨김으로 대체하지 않는다. 미확인 상태의 처리와 저장 정책은 [엣지 케이스 문서](edge-cases.md)에서 구분한다.

### 보내기

1. 사용자가 프로그램의 입력창에 문장을 입력한다.
2. 앱은 내 메시지를 즉시 목록에 표시하고 `전송 중` 상태를 붙인다.
3. 현재 계정과 대상 로비를 다시 확인한 뒤 한 번 송신한다.
4. API 결과에 따라 전송 상태를 갱신한다.
5. 자기 메시지가 수신 이벤트로 돌아오면 기존 행에 반영한다. 새 행을 중복 생성하지 않는다.

`전송됨`은 송신 API의 수락을 의미한다. 상대방의 화면 표시나 읽음 확인을 의미하지 않는다. 결과가 불명확한 상황에서는 자동 재전송하지 않는다.

## 4. 화면 구성안

차분한 메신저 디자인을 유지하며 Python/PySide6 Qt WebEngine을 개발판 런타임으로 선택했다. 아래는 기능 배치 기준이다.

| 영역 | 내용 | 필요한 동작 |
| --- | --- | --- |
| 연결 상태 | Steam·게임·현재 로비 상태 | 연결 끊김 안내, 송신 가능 여부 표시 |
| 대화 목록 | 현재 로비와 기록이 있는 로비 | 현재 대화·보관 기록 구분, 로비별 전환, 사이드바 접기·펼치기 |
| 메시지 영역 | 게임 표시 이름·고양이 프로필, 본문, 수신 시각, 내 메시지 상태 | 스크롤, 복사, 날짜 구분, 새 메시지 표시 |
| 입력 영역 | 텍스트 입력과 보내기 | 한글 IME, 길이 안내, 전송 중·실패 피드백 |
| 검색 | 저장된 대화의 본문 검색 | 결과 시각과 로비 확인, 해당 메시지로 이동 |
| 기록 설정 | 저장 위치와 보관 상태 | 저장 활성 상태 안내, 내보내기·삭제 정책 제공 |

사용자가 과거 메시지를 읽는 중에는 새 메시지가 와도 스크롤을 유지한다. 개발판은 Enter 전송·Shift+Enter 줄바꿈·Ctrl+K 검색을 사용하고 30일 보관한다. 알림·자동 실행은 추가 결정이 필요하다.

2026-10-14 스크롤 기준: 위쪽 끝에서 이전 대화를 자동으로 이어 불러오고 실제 기록의 처음에 도달하면 이전 기록 버튼을 숨긴다. 읽던 메시지와 화면 내 위치를 유지하며 최신 메시지 도착·방 복귀·검색 해제 시 같은 픽셀 높이의 다른 메시지로 이동하지 않는다. 대화 영역 아래에 고정된 이동 버튼으로 최신 메시지에 도달할 수 있고, 수동으로 최신 메시지까지 내려가도 새 메시지 표시가 사라진다. 과거 구간에서도 신규 수신을 표시하며, 내 전송 후에는 최신 구간과 전송 상태를 보여 준다. 검색 결과에서는 대상 뒤의 대화를 이어 읽을 수 있어야 한다.

### 2026-10-13 화면 피드백

- 사이드바 접기·펼치기를 제공한다. 접으면 대화 영역을 넓히고 펼치기 버튼은 항상 남긴다. 선택한 방, 검색어, 작성 중인 문장은 유지한다. 데스크톱에서는 방 아이콘만 남기는 구성을 제안하며, 접힘 선호는 앱 재실행 후에도 유지하는 방향으로 설계한다.
- 메시지와 내 계정 영역에는 Bongo Cat에서 보이는 이름을 사용한다. 내 메시지도 게임 이름을 표시하고 `나`를 보조 표식으로 붙인다. 사용자의 실제 식별·숨김 기준은 이름이 아닌 계정 식별자다.
- 프로필에는 게임 속 고양이를 사용한다. 스킨·착용 장식의 반영 범위, 정적 썸네일 생성 방법, 변경 감지 방법은 기술 검증 대상으로 둔다. 현재 시안의 고양이 아이콘은 실제 게임 이미지를 가져온 결과가 아니다.
- 이름·외형을 읽지 못하거나 변경 중인 경우에도 본문 수신을 막지 않는다. 임시 이름·기본 고양이와 조회 상태를 표시하고, 이전 로비·다른 계정의 늦은 조회 결과를 적용하지 않도록 설계한다. 과거 메시지에 당시 프로필을 유지할지 최신 프로필을 적용할지는 별도 결정한다.

## 5. 첫 제품에 포함할 요구사항

| ID | 요구사항 | 인수 기준 |
| --- | --- | --- |
| FR-01 | 현재 로비에 대한 수신 | 다른 계정이 게임에서 보낸 문장이 앱에 정확히 나타남 |
| FR-02 | 기존 게임으로 송신 | 앱에서 보낸 문장이 별도 프로그램을 설치하지 않은 상대방 게임에 나타남 |
| FR-03 | 프로그램 내부 자기 메시지 표시 | 입력한 문장이 즉시 나타나고 자기 수신 이벤트로 중복되지 않음 |
| FR-04 | 로컬 대화 저장 | 앱 재실행 후 이전에 저장한 기록을 조회할 수 있음 |
| FR-05 | 기록 조회와 검색 | 기록이 있는 로비와 수집 기간이 명확하며 검색 결과로 이동할 수 있음 |
| FR-06 | 로비 자동 추적과 경계 유지 | 변경을 감지해 대상을 갱신하고 미호출 송신을 중지함. 이전 요청·초안·수신을 새 방으로 자동 재지정하지 않음 |
| FR-07 | 실패 상태 설명 | Steam 종료·권한 문제·전송 결과 불명·저장 실패를 구분함 |
| FR-08 | 게임 파일 무수정 | 설치·실행·종료 후 게임 파일이 바뀌지 않고 기존 게임 동작이 유지됨 |
| FR-09 | 게임의 개별 사용자 숨김 자동 반영 | Bongo Cat에서 숨김·해제한 상태를 읽어 대화·검색·미리보기·알림·읽지 않은 수에 반영함. 앱에 독립 숨김 조작을 두지 않으며 조회 경로 미확보 시 미충족으로 판정함 |
| FR-10 | 사이드바 접기·펼치기 | 접으면 대화 영역이 넓어지며 다시 펼칠 수 있음. 선택한 방·검색어·초안과 접힘 선호가 유지됨 |
| FR-11 | 게임과 같은 표시 이름 | 같은 계정의 이름이 게임 화면과 일치함. 이름 변경·동명이인·조회 지연에 발신자 식별과 숨김 대상이 바뀌지 않음 |
| FR-12 | 게임 고양이 프로필 동기화 | 게임 무수정으로 외형을 가져오는 경로와 이미지 표시를 검증함. 고양이 변경 후 확정한 반영 범위에서 갱신되며 조회 실패·이전 로비 응답을 구분함 |
| FR-13 | 라이트·다크·시스템 테마 | 두 테마에서 같은 기능과 배치를 제공하고 설정을 기억함. 시스템 선택 시 운영체제 변경을 따라가며 전환해도 선택한 대화·검색어·스크롤·초안이 유지됨. 텍스트·포커스·고양이 프로필의 가독성을 각각 확인함 |
| FR-14 | 고양이 클릭 울음 제외 | 확인한 27개 언어의 울음 문구를 신규 수신·저장에서 제외하고 기존 기록·검색·미저장 화면에서도 숨김. 해당 문구를 포함하는 일반 문장과 기록 페이지 순서는 유지함 |
| FR-15 | 업데이트 자동 다운로드·재시작 | 새 실행기로 시작한 설치본이 검증된 업데이트 준비 후 30초 안내·입력/송신 대기·초안 저장을 거쳐 자동 재시작함. 저장 실패·미저장 기록·업데이트 통신 해제 시 보류하며 서명/후보 검사 실패 때 기존 버전과 기록을 유지함 |

FR-01·02의 통신 경로는 PoC로 일부 확인했지만, 제품 UI를 포함한 전체 인수 기준을 통과한 것은 아니다.

FR-09는 게임을 숨김 상태의 기준으로 삼는 확정 요구사항이다. 실제 숨김·해제 감지를 확인한 메모리 조회 후보의 제품 채택 여부와 호환성, 앱 전체 적용을 확인해야 한다. 이전 시안의 앱 자체 수동 숨김 제안은 철회했다. 게임의 전체 채팅 끄기·자동 고양이 숨김·언어 필터는 개별 숨김과 별도로 적용 정책을 결정한다.

FR-10부터 FR-12는 사용자 요청을 반영한 제품 요구사항이다. 와이어프레임의 접기 동작과 예시 이름·고양이 표시는 제품 구현 또는 실제 동기화의 완료 증거가 아니다. FR-12의 데이터·이미지 후보 경로는 별도 실험으로 확인했으며 최종 제품 표시와 갱신 검증은 남아 있다.

FR-13은 2026-10-13 사용자 요청이다. [데스크톱 메신저 디자인](design/README.md)에 두 테마와 시스템 기본값을 적용한다. 브라우저 시안의 테마 전환 검증은 향후 Windows 앱의 운영체제 연동·설정 저장 완료와 구분한다.

## 6. 제외한 기능

- 게임 안의 내 캐릭터 위에 별도 말풍선을 표시하는 기능.
- 게임 DLL 수정, 게임 내부 플러그인 설치, 게임 프로세스에 코드 주입.
- 별도 메시지 서버, 클라우드 백업, 여러 기기 동기화.
- 프로그램 실행 전·오프라인 동안의 대화를 복구한다고 보장하는 기능.
- 읽음 표시, 상대방 화면 표시 완료를 자동 판정하는 기능.
- 이미지·첨부파일·음성·Discord 봇 연동.
- 게임에 없는 메시지 수정·삭제 기능을 상대방에게도 적용하는 기능.
- 상자 열기, 탭 수, 보상, 아이템 등 채팅 이외의 게임 동작.

이모지의 데이터 왕복은 시험했으나 게임 화면 지원은 확인하지 않았다. 첫 제품은 일반 텍스트를 기준으로 검증하며 이모지·이모티콘 호환을 홍보하지 않는다.

## 7. 기록의 의미

대화 기록은 이 앱이 실제 수신한 시점부터 수집한 로컬 기록이다. 앱을 종료하거나 수신이 끊어진 구간은 완전한 대화 기록으로 취급하지 않는다. 누락 가능한 구간을 사용자에게 표시하는 방안을 설계한다.

게임에서 말풍선이 사라지더라도 이미 저장한 기록을 다시 볼 수 있는 것이 핵심 가치다. Steam이나 게임이 모든 과거 메시지를 영구 보관한다는 가정에 의존하지 않는다.

## 8. 완료 판정

첫 제품 완료는 화면 시안이나 자체 루프백 성공으로 판정하지 않는다. 순정 게임 환경의 실제 다른 계정과 송수신하고, 재실행 후 기록 복구, 한글 입력, 로비 변경, 오류 상태, 자기 메시지 중복 방지까지 확인해야 한다. 세부 시험은 [개발·검증 계획](roadmap.md)을 따른다.
