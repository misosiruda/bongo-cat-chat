# 게임 숨김과 독립적인 채팅 차단

2026-10-28 사용자 요청에 따른 후속 소스 변경이다. 공개 설치본 반영과 실제 게임 로비 인수는 별도다.

## 사용 방법

- 게임에서 다른 고양이를 숨겨도 Bongo Cat Chat의 대화와 프로필은 표시한다. 게임 화면에 내 고양이만 남겨 두고 기존 로비 채팅을 이용할 수 있도록 수신 필터를 분리한다.
- 상단 참여자 목록은 **고양이 · 이름 · ⋯** 한 줄로 표시한다. 상대의 **⋯ → 채팅 차단 / 차단 해제**를 선택한다. Steam ID와 Steam 프로필 열기는 메뉴 안에 표시하며 차단 중인 상대는 목록에 작은 `차단됨` 표시를 붙인다. 긴 이름은 목록에서 말줄임하고 메뉴에서 전체 이름을 확인한다.
- **설정 → 채팅 차단**에서 SteamID64를 직접 입력하거나 저장된 차단 목록을 해제한다. 대상이 현재 로비에 없어도 관리할 수 있다.
- 차단은 이 기기의 로그인 Steam 계정별로 저장한다. 닉네임 변경, 로비 이동, 앱 재실행 후에도 유지한다. 다른 PC로 동기화하거나 Steam·게임의 차단 설정을 변경하지 않는다.
- 차단은 수신 표시 정책이다. 내 로비 메시지는 기존처럼 해당 로비로 전송되며, 차단한 상대가 내 메시지를 받지 못하도록 만드는 기능은 아니다.

## 기록과 알림

차단한 상대의 기존 메시지는 모든 보관 로비의 대화·검색·읽지 않은 표시에서 제외한다. 새 메시지는 서비스에서 폐기해 DB에 저장하지 않으며 알림과 반응 효과도 표시하지 않는다. 차단 해제 시 30일 보관 기간 안의 기존 기록은 다시 표시하지만 차단 중 버린 메시지는 복원하지 않는다. 차단 변경 전 수신해 IPC나 반응 이미지 준비가 늦어진 이벤트도 해제 뒤 재생하지 않는다.

차단 목록은 자동 만료하지 않는다. 로비 기록 삭제·현재 계정 기록 전체 삭제·30일 정리로 지워지지 않는다. 해제 버튼으로 목록에서 제거한다. 제거 프로그램의 기존 데이터 보존 정책을 따른다.

## 구현과 저장

`blocked_users(account TEXT, steam_id TEXT, name TEXT, PRIMARY KEY(account,steam_id))`를 기존 SQLite에 추가한다. `name`은 차단 시 확인한 이름이며 이름을 모르는 직접 입력은 빈 문자열이다. 기존 schema version 1에 `CREATE TABLE IF NOT EXISTS`로 추가하며 기록·초안·설정 데이터를 변환하지 않는다.

Steam ID는 UI→QWebChannel→서비스→DB 전 구간에서 문자열로 유지한다. 기존 프로필 URI 검증과 동일하게 양의 ASCII 십진수·선행 0 금지·uint64 상한을 검사하고 자기 계정 차단, bool이 아닌 상태, 다른 계정의 오래된 요청을 거절한다. 저장 성공 뒤에만 메모리와 화면 정책을 변경한다. 쓰기 실패 시 이전 정책을 유지하며, 계정 전환 시 목록 읽기에 실패하면 상대 수신·표시를 보류한다.

작업자는 게임의 숨김 사전을 호출하지 않는다. 검증된 게임 로비와 Steam 참여자 교집합, 연결 세대, 전환 직후 콜백 비우기, 2.5초 연결 신선도 검사는 유지한다. `ChatService`가 현재 계정 차단 목록을 적용한다. 보관 기록 조회는 현재 로비 구성원에 한정하지 않고 저장 계정과 차단 목록으로 필터링한다. 게임 미실행 상태의 전체 상대 기록 열람은 여전히 지원하지 않는다.

게임 로비를 찾기 위한 기존 공통 Mono 메타데이터·관리 도메인 검증과 기능 호환성 계약은 유지한다. 캐시 루트가 이 검증에 쓰이는 것과 개별 고양이 숨김 값을 채팅 정책에 사용하는 것은 별개다. 게임 파일 수정·DLL 주입·메모리 쓰기를 추가하지 않는다.

## 호환성과 복귀

새 테이블은 기존 데이터에 대한 삭제·변환이 없다. 이전 버전은 추가 테이블을 사용하지 않으므로 코드 복귀 시 기록은 유지되지만 앱 차단 정책은 적용되지 않고 이전 게임 숨김 연동 동작으로 돌아간다. 게임에서 숨긴 상대를 앱 차단 목록으로 자동 이전하지 않는다. 이 변경은 게임 숨김과 무관하게 채팅을 보려는 요청에 따른 것이다.

2026-10-28 최초 출하 요청에서는 PR 검수·병합만 진행하고 공개 배포를 보류했다. 이후 사용자가 #37·#38을 포함한 배포를 요청해 dev17 릴리스를 준비한다. [로비 입·퇴장 안내 PR #37](https://github.com/misosiruda/bongo-cat-chat/pull/37)의 병합이 향후 배포 선행 조건이다. #37 병합 커밋 e35456f를 반영해 입퇴장 안내에도 게임 숨김 대신 앱 차단을 적용했다. 현재 구성원에서 빠진 상대의 퇴장 안내와 보관 기록에도 같은 차단 목록을 적용하며, 이름 확인을 기다리던 입장 후보와 차단 중 관찰한 지연 표본을 해제 뒤 재생하지 않는다. 기능 PR에서는 버전·태그·업데이트 manifest·공개 설치본을 갱신하지 않았으며, 배포 준비와 실제 게시 결과는 [dev17 릴리스](releases/0.1.0.dev17.md) 및 GitHub Release에서 구분한다.

## 검증 범위

`tests/test_blocking.py`는 합성 ID로 저장·재열기·로비 이동·계정 분리·기록 삭제와 만료·동명이인·숫자 정밀도·잘못된 입력·자기 차단·읽기/쓰기 실패·지연 이벤트·실제 Qt 브리지와 화면 조작을 검사한다. 기존 수신·알림·반응·프로필·검색 검사도 새로운 차단 정책에 맞춘다. 실행 결과와 실제 게임 미검증 범위는 [제품 검증 기록](product-validation.md)에 기록한다.
