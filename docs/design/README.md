# 데스크톱 메신저 디자인

2026-10-13 사용자가 선택한 방향은 **차분하고 세련된 데스크톱 메신저**다. 기존 와이어프레임의 기능 구조를 유지하면서 대화 중심의 배치, 고양이 프로필, 절제된 보라색, 라이트·다크 테마를 적용한다.

[미리보기 열기](index.html). 정적 HTML·CSS·JavaScript로 만든 디자인 프로토타입이며 제품 런타임 선택을 확정하지 않는다. 로컬 파일로도 열 수 있다. 모든 이름·대화·연결 상태는 예시이며 Steam이나 게임에 연결하거나 메시지를 보내지 않는다.

## 기준 이미지와 구성

이 디자인에서 실제 Windows 개발판의 `src/bongo_chat/ui/`를 만들었다. 제품 화면은 QWebChannel을 통해 실제 연결·기록을 사용하며 이 폴더의 예시 이름·대화·그림을 사용하지 않는다. 시안의 38개 UI 검사는 디자인 증거로 유지하고, 제품의 검사는 [별도 기록](../product-validation.md)으로 구분한다.

- [라이트 시안](assets/desktop-concept.png)
- [다크 시안](assets/desktop-concept-dark.png)
- [원본 고양이 일러스트](assets/cat-avatars.png): 위 시안을 바탕으로 별도 생성한 4종. 실제 게임 이미지·사용자 외형이 아니다.
- [앱 아이콘과 파비콘](app-icon.md): 원작 아이콘의 고양이에 보라색 말풍선을 더한 제품 공통 아이콘. 마스터·출력 규격·참조 출처·생성 프롬프트를 기록한다.

이미지는 내장 imagegen으로 생성했다. 구현에서는 화면 이미지를 배경으로 붙이지 않고 글자·검색·입력·메뉴를 HTML 요소로 만든다. 앱은 사이드바와 대화 영역의 두 열로 구성하고 참여자 정보와 설정은 필요할 때 연다.

[이미지 생성 요청 원문](generation-prompts.md)도 함께 보관한다.

## 시각 규칙

| 역할 | 라이트 | 다크 |
| --- | --- | --- |
| 대화 배경 | `#ffffff` | `#1b1d25` |
| 사이드바 | `#f6f7f9` | `#15171e` |
| 본문 | `#252832` | `#e7e9f0` |
| 보조 글자 | `#5f697d` | `#adb4c8` |
| 구분선 | `#e9eaef` | `#30333f` |
| 받은 말풍선 | `#f0f1f4` | `#272a35` |
| 내 말풍선 | `#efedf8` | `#353044` |
| 강조·보내기 | `#8178bb` | `#a59ad9` |

- 한글은 Noto Sans KR을 우선하고, 읽을 수 없으면 설치된 한글 시스템 글꼴을 사용한다. 글꼴 파일 외 앱 데이터 요청은 없다.
- 본문·이름·시간·보조 문구의 크기와 굵기를 분리한다. 큰 화면의 여백을 유지하면서 좁은 창에서는 최소 글자 크기를 보장한다.
- 패널을 여러 겹의 카드로 감싸지 않는다. 얇은 구분선, 둥근 말풍선과 입력창으로 영역을 구분한다.
- 아이콘은 같은 선 두께·크기 체계를 사용한다. 고양이 그림만 색과 개성을 가진다.
- 창이 좁으면 사이드바를 서랍으로 전환한다. 접기·펼치기 버튼과 입력창은 계속 접근할 수 있어야 한다.
- 모션은 짧은 상태 전환에 한정하며 모션 감소 설정을 따른다.

## 테마

라이트·다크·시스템 선택을 제공하며 기본값은 시스템이다. 두 테마의 배치·기능은 같다. 시스템 선택 중에는 운영체제 테마 변경을 따라가고, 직접 고른 테마와 사이드바 접힘은 브라우저 로컬 설정에 보관한다. 고양이 원본 이미지를 반전시키지 않는다.

## 시안과 구현의 비교 기준

라이트·다크 기준 이미지와 최종 브라우저 화면을 각각 1,536×1,024에서 대조했다. 사용자가 선택한 것은 디자인 방향이며 이 미리보기는 그 방향을 구체화한 제안이다.

| 비교 항목 | 기준 이미지 | 구현과 조정 |
| --- | --- | --- |
| 배치 | 약 367px 사이드바, 대화 영역, 하단 입력창 | 같은 두 열과 고정 입력창 유지. 작은 창에서는 대화 영역 확보를 위해 서랍으로 전환 |
| 글자 | 제목·이름·본문·시각의 단계 구분 | 한글 Noto Sans KR로 구현. 제목 32px, 본문 21px를 기준으로 창 너비에 따라 축소 |
| 색 | 흰색·옅은 회색 또는 차콜, 절제된 보라색 | 같은 팔레트 유지. 시안의 미세한 이미지 질감은 단색으로 구현하고 보조 글자 대비를 보강 |
| 문구 | 로비·이름·5개 메시지·입력 안내 | 기본 화면 문구와 메시지 순서 유지. 제품 화면 밖에 예시임을 알리는 미리보기 도구 추가 |
| 고양이 | 새싹·식빵·보라 모자·복숭아색 고양이 | 별도 생성한 투명 원본을 사용. 그림의 세부 선은 다르며 실제 게임 외형 동기화는 제품 구현 사항 |
| 간격·아이콘 | 여유 있는 메시지 간격, 얇은 선 아이콘 | 메시지 간격을 기준 화면에 맞춰 조정. 검색·접기·새로고침·보내기는 실제 SVG 버튼으로 구현 |
| 상호작용 상태 | 정적인 빈 입력창과 보내기 버튼 | 빈 입력창에서는 보내기를 비활성화하므로 시안보다 옅게 표시. 포커스·검색 강조·설정 창을 추가 |

일반 화면의 초기 로비명·참여자 수·이름·시간·대화 본문·검색·입력 안내 문구를 기준 이미지와 대조했다. 기본 문구의 삭제나 순서 변경은 없으며, 상태 선택 도구와 클릭 후 피드백은 동작 검토를 위한 추가다. 설정·참여자 창과 좁은 창 배치는 정적 기준 이미지에 없는 보완 설계다.

## 미리보기에서 확인할 동작

- 사이드바 접기·펼치기. 선택한 대화·검색어·초안 유지.
- 현재 대화 검색과 강조 표시, 결과 없음 상태. `Ctrl/Cmd + K`로 검색에 접근.
- 예시 메시지 입력. Enter 전송과 Shift+Enter 줄바꿈을 구분하고 한글 조합 중 Enter는 전송하지 않음.
- 현재 로비와 읽기 전용 보관 기록 전환. 대화별 초안을 입력 즉시 보관.
- 게임에서 숨긴 상황을 선택하면 같은 예시 사용자의 메시지·검색 결과·참여자 표시에서 제외. 앱 안에는 사용자 숨김·해제 버튼을 두지 않음.
- 로비 이동·연결 끊김 상황에서는 보내기를 비활성화. 새로고침은 미리보기의 연결 상태만 바꾸며 실제 게임을 조작하지 않음.
- 설정에서 테마 변경, 참여자 목록 열기·닫기, 키보드 포커스와 좁은 창 배치.

화면 위 미리보기 도구는 제품 UI와 분리된 상태 선택기다. `?presentation=1`은 기준 이미지와 비교하기 위해 이 도구만 감춘다.

초안은 브라우저에서 허용할 때 대화별 최대 4,000자까지 보관한다. 이 수치는 미리보기의 메모리·저장 한도이며 Bongo Cat의 전송 제한이 아니다. 새로 추가한 예시 메시지는 현재 창의 메모리에만 있으며 새로 열면 초기 대화로 돌아온다. 화면의 대화 보관 안내는 제품 디자인 예시이며 실제 대화 DB 저장을 구현한 것이 아니다.

## 제품 구현으로 남은 것

Steam 송수신, 실제 게임 이름·외형 적용, 숨김 조회 어댑터 연결, 로비 자동 추적, 대화 DB와 알림·내보내기 정책은 이 미리보기에 연결하지 않았다. [기술 검증](../profile-sync-validation.md)으로 확인한 조회 경로와 UI 동작 검증은 구분한다. 실제 송신 없이 디자인과 조작 방식을 검토하는 단계다.
