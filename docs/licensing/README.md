# 라이선스 결정

2026-10-14 소유자가 **MIT — 상업적 재사용과 비공개 수정본 배포 허용**을 선택했다. [루트 LICENSE](../../LICENSE)와 `pyproject.toml`에 반영했다. 제안문은 선택 시 검토한 문안의 기록이다. 외부 게시·기존 릴리스 교체는 이 로컬 변경과 별개다.

## 선택한 조건

자체 작성 코드·문서는 **MIT**를 사용한다. 무료 배포와 공개 개발에 사용할 수 있고, 다른 사람이 상업적으로 재사용하거나 수정본의 소스를 공개하지 않고 배포하는 것도 허용한다. 저작권·허가 고지는 유지해야 한다. [선택 전 제안문](LICENSE-MIT.proposed.txt), [OSI 원문](https://opensource.org/license/mit).

수정본을 배포하는 사람에게도 소스 제공 의무를 요구하려면 **GPL-3.0-only**가 대안이다. 두 라이선스 모두 상업적 이용을 허용한다. “비상업용만”, “재판매 금지” 같은 제한을 붙이면 같은 OSI 라이선스가 아니며 SignPath 신청 조건도 다시 검토해야 한다. [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html).

## 적용할 경계

- 권장 저작권 표기: `Copyright (c) 2026 Bongo Cat Chat contributors`.
- Git 이력에서 동일 공개 GitHub 계정에 연결된 작성자 이름 두 가지를 확인했다. 이는 모든 권리의 소유·고용 계약·외부 기여를 법적으로 증명하지 않는다. 소유자는 자신의 코드에 라이선스를 부여할 권한을 확인한다.
- 외부 라이브러리·런타임은 각 원래 라이선스를 유지한다. 자체 코드가 MIT여도 Qt/Chromium 등의 고지·소스 제공 의무는 없어지지 않는다.
- 게임 이름·상표·설치된 게임에서 읽은 그림·Steam/게임 바이너리에 프로젝트 라이선스를 부여하지 않는다. 해당 파일들은 저장소와 배포물에 넣지 않는다.
- 루트 `LICENSE`와 `pyproject.toml`의 MIT 표기를 추가했다. 원격 저장소의 라이선스 표시는 이 변경이 게시된 뒤 확인한다.
- GPL을 선택하더라도 FMOD 문제나 타사 고지·소스 준비가 자동 해결되지는 않는다.

의존성의 실제 검토와 신청 차단 사유는 [라이선스 검토](../license-review.md)에 기록한다.
