# 배포·개인정보 검토

기준일: 2026-10-12. 무료 배포는 사용자 목표이며, 현재는 문서와 기술 검증 단계다. 개발자에게 안내하거나 배포 조건을 확인한 상태는 아니다. 이 문서는 배포 전에 결정할 사항을 정리하며, 허용 여부에 대한 법률 판단을 확정하지 않는다.

## 배포 방향과 현재 상태

| 항목 | 현재 방향·상태 | 남은 일 |
| --- | --- | --- |
| 이용자 대상 | 기존 Bongo Cat 채팅을 사용하는 Windows 이용자 | 지원 OS·Steam·게임 실행 조건 확정 |
| 가격 | 무료 배포 목표 | 배포 채널과 운영 범위 결정 |
| 소스 공개 | 미정. 초기 GitHub 저장소는 비공개 | 공개 여부와 라이선스 결정 |
| 개발사 관계 | 서드파티 기획. 공식 승인·협력 관계 없음 | 기능과 동작 방식 안내, 필요한 조건 확인 |

무료 이용, 소스 공개, 의존 파일 재배포는 각각 결정할 문제다. 아직 `LICENSE` 파일을 추가하지 않았다. 개발자에게 안내했다는 사실도 별도의 승인이나 조건 합의를 의미하지 않는다.

## 연동과 의존성 확인

PoC는 설치된 게임의 Steam API DLL을 별도 프로세스에서 로드하고 같은 Steam 계정의 로비 채팅 API를 호출했다. 앱 ID와 관찰한 게임 메시지 포맷을 사용한 동작이다. API의 존재와 한 PC에서의 성공만으로 일반 배포 적합성이 확인되지는 않는다.

배포 전에 다음을 확인한다.

- 별도 프로그램에서 해당 앱 ID와 Steam API를 사용하는 방식에 적용되는 조건
- 설치된 DLL 참조와 DLL 동봉 배포 각각의 기술적 조건·이용 조건
- Steam과 게임의 업데이트에 따른 인터페이스·메시지 포맷 변경 대응
- 게임 이름·아이콘·이미지의 표시 범위와 출처
- 사용한 라이브러리·런타임의 라이선스와 고지 사항
- 개발자에게 설명한 범위와 실제 배포 기능의 일치 여부

기술 참고 문서는 [Steamworks API 개요](https://partner.steamgames.com/doc/sdk/api)와 [ISteamMatchmaking API](https://partner.steamgames.com/doc/api/ISteamMatchmaking)다. 실제 배포에 적용되는 계약·정책은 별도로 확인할 대상이며, 기술 문서 링크를 승인 근거로 사용하지 않는다.

현재 프로젝트는 공식 게임 로고·게임 바이너리를 배포하지 않는다. `Bongo Cat Chat`은 작업 이름이며, 배포 이름과 공식 제품으로 오인하지 않게 하는 소개 문구는 출시 전에 확정한다.

## 대화 기록의 범위

기록 기능의 대상은 사용자가 참여한 로비에서 앱이 실제로 수신한 채팅과 앱에서 작성한 자기 메시지다. 앱 실행 전이나 연결이 끊긴 구간의 대화를 모두 복원할 수 있다고 안내하지 않는다.

다음은 구현할 정책의 제안이다. 현재 동작하는 설정 화면이나 저장 기능은 없다.

- 기록이 시작되는 조건과 저장 위치를 사용자가 알 수 있게 한다.
- 현재 수신·저장 상태와 수신 공백 구간을 구분한다.
- 저장 중지, 선택 기록 삭제, 전체 기록 삭제를 제공할 범위를 결정한다.
- 보관 기간과 기본값을 확정한다. 무기한 보관을 묵시적인 기본값으로 정하지 않는다.
- 내보내기 파일에 타인의 대화와 식별정보가 포함될 수 있음을 표시한다.
- 계정이 바뀔 때 기존 계정의 대화·초안을 새 계정의 화면에 섞지 않는다.
- 닉네임 변경·동명이인을 처리할 식별자를 선택하고 필요한 범위만 저장한다.
- 로컬 DB·백업 파일의 접근 범위와 암호화 필요성을 검토한다.

Steam 사용자 ID나 닉네임을 저장할 필요가 있다면 목적과 보관 범위를 명시한다. 단순 해시로 바꿨다는 이유만으로 식별 가능성이 사라졌다고 표현하지 않는다. 수신한 비채팅 이벤트나 게임 인벤토리 정보를 대화 기록에 함께 저장할 필요는 없다.

클라우드 동기화, 중앙 수집 서버, 다른 메신저 전달, 분석용 원격 전송은 확정 요구사항이 아니다. 향후 추가한다면 로컬 기록과 별도의 범위로 설계·안내한다.

## 화면 표시와 사용자 제어

채팅 본문과 닉네임은 신뢰하지 않는 외부 입력으로 처리한다. HTML이나 스크립트처럼 보이는 문자열도 텍스트로 표시한다. 본문의 명령·링크가 프로그램 동작이나 파일 실행을 자동으로 유발하지 않도록 한다.

2026-10-13 정적 분석에서 게임의 개별 숨김은 내부 캐시와 캐릭터 비활성화로, 전체 채팅 끄기와 언어 필터는 말풍선 표시 전에 처리되는 경로를 확인했다. 현재 PoC는 이 설정을 읽지 않는다. 실제 숨김 상태의 API 수신·외부 UI 반영은 시험하지 않았으며 자동 연동 경로도 확보하지 못했다.

게임의 개별 사용자 숨김·해제를 앱에 자동 반영하는 것이 확정 요구사항이며, 출시 전 동기화 경로와 실제 동작을 시험한다. 앱 자체 숨김 조작은 제공하지 않는다. 게임의 사용자 숨김과 Steam 계정 차단을 같은 설정으로 간주하지 않는다. 기존·새 대화와 검색·미리보기·알림·읽지 않은 수에서 숨김을 반영하며 내보내기에서도 노출 정책을 일치시킨다. 기존 기록 삭제와 숨김 중 저장 여부는 별도로 결정하며, 숨겼다는 이유만으로 원문이 삭제되거나 수집이 중단됐다고 안내하지 않는다. [정책 쟁점과 검증 순서](edge-cases.md)

자기 메시지의 전송 표시에는 “API 접수”, “자체 수신 확인”, “결과 불명”의 차이를 반영한다. 상대가 읽었다는 신호는 확인되지 않았으므로 읽음 상태를 만들지 않는다. 자동 재전송은 중복 발언을 만들 수 있으므로 기본 송신 흐름에 넣지 않는다.

## 저장소와 진단 자료 관리

Git에 포함하는 자료:

- 요구사항, 설계, 결정과 검증 기록
- 사용자 테스트 문장과 식별정보를 제거한 결과 수치
- 향후 자체 작성 제품 소스와 공개 가능한 테스트 데이터

Git에서 제외하는 자료:

- 원본 수신 로그, 로비 ID·입장 코드, Steam 사용자 ID와 식별 가능한 해시
- 다른 이용자의 대화 원문과 닉네임이 노출된 캡처
- 로컬 대화 데이터베이스·내보내기·설정·인증 정보
- 게임·Steam DLL, 컴파일된 연구 모듈과 다운로드한 분석 도구

기존 원본 자료 20개는 `research/private/2026-10-12/`에만 보관한다. `archive-manifest.json`은 복사본 해시를 검증하기 위한 로컬 파일이며 함께 Git에서 제외한다. 적용하지 않은 말풍선 시험 소스가 이 보관본에 있다는 사실은 제품 기능 채택을 뜻하지 않는다.

향후 진단 로그는 연결 상태·오류 코드·버전 중심으로 설계한다. 본문과 식별정보를 기본 로그에 남기지 않고, 필요한 진단 수집 범위와 전달 방법을 별도로 정한다. 저장소를 공개할 때는 현재 파일뿐 아니라 Git 이력과 첨부 자료도 확인한다.

## 개발자에게 안내할 내용

아래는 안내 준비 항목이다. 아직 메시지를 작성해 발송하거나 답변을 받은 상태가 아니다.

1. **목적:** 기존 로비 채팅을 편하게 읽고 입력하며, 앱이 받은 대화를 로컬에서 다시 보는 무료 보조 프로그램.
2. **호환 방식:** 기존 이용자는 프로그램 설치 없이 게임 채팅으로 참여. 별도 프로세스에서 Steam 로비 채팅 API 사용.
3. **제품 범위:** 일반 텍스트와 로컬 기록부터 시작. 게임 파일 패치와 게임 내 자기 말풍선 연결은 제외.
4. **현재 증거:** 한 PC의 기존 패치 환경에서 송수신 확인. 상대방 표시는 사용자 확인이며 순정 설치·장기 운용 검증은 남아 있음.
5. **확인할 조건:** 연동 방식과 앱 ID 사용, 의존 파일 취급, 이름·이미지 표시, 무료 배포에 요구되는 조건.
6. **기술 질문:** 공식 채팅 연동 경로 또는 지원 계획, 메시지 형식·길이 제한, 차단·필터 설정, 업데이트 호환성 안내 방법.
7. **데이터 처리:** 실제 수신한 대화의 로컬 보관 범위와 삭제·내보내기 방향. 서버 전체 기록이나 오프라인 대화 복원은 약속하지 않음.

개발자 회신이 있으면 받은 날짜·조건·적용 범위를 별도 결정 기록으로 남긴다. 의사소통 채널과 실제 전달 문구는 발송 작업에서 확정한다.

## 설치·삭제와 장애 대응

채택한 설계는 게임 파일에 변경을 가하지 않으므로 프로그램 종료·삭제에 게임 패치 복구 단계를 두지 않는다. 이 동작은 실제 설치 패키지로 검증해야 한다. 기존 Auto Chest Opener 등 다른 작업의 설치 상태는 이 프로그램이 변경하지 않는다.

삭제 시 대화 데이터까지 지울지는 사용자가 알 수 있게 선택하거나 명확한 정책으로 안내한다. 프로그램 제거를 이유로 기록을 알리지 않고 지우거나, 반대로 삭제 요청 후 숨겨진 사본을 남기지 않도록 설계한다.

게임 업데이트로 연동이 깨지면 오류를 알리고 송신을 중지한다. 알려지지 않은 메시지 형식을 추측해 전송하거나 실패 메시지를 자동 반복하지 않는다. 검증된 버전과 현재 버전을 구분할 방법을 마련한다.

## 일반 배포 전 확인할 항목

- [ ] 순정 설치와 별도 상대 PC에서 송수신 확인
- [ ] 게임·Steam·앱 실행 순서와 종료·재연결 동작 확인
- [ ] 게임 파일을 변경하지 않는 설치·실행·삭제 확인
- [ ] 개발자 안내 내용과 배포 조건 확인 결과 기록
- [ ] 의존 파일 이용·재배포 조건 및 필요한 고지 확인
- [ ] 배포 이름·소개·이미지와 소스 라이선스 결정
- [ ] 기록 보관·삭제·내보내기·계정 분리 정책 확정 및 구현
- [ ] 차단·음소거·내용 필터의 외부 UI 동작 확인
- [ ] 진단 로그와 공개 저장소·이력의 식별정보 검사
- [ ] 지원 환경·알려진 한계·업데이트 실패 시 동작 문서화
